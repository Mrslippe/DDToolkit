# 企划图标（需求 6，B3）

往这个目录里丢一个 `<slug>.svg`（或 `.png` / `.webp`），左栏那条 V 的企划徽章就会自动变成图标
—— **不需要改任何代码**（`src/utils/groupBadge.ts` 用 `import.meta.glob` 在构建期扫这个目录）。

## 文件名（`slug`）怎么定

`groupSlug()` 的规则：**小写**，把"非字母数字汉字"的字符折成一个连字符，首尾连字符去掉。

| 企划名 | 文件名 |
|---|---|
| `VirtuaReal` | `virtuareal.svg` |
| `NIJISANJI EN` | `nijisanji-en.svg` |
| `Hololive` | `hololive.svg` |
| `虚研社` | `虚研社.svg`（汉字直接留在文件名里，不转拼音 —— 那只会让"该叫什么名"变成猜谜） |

## 没有素材时

徽章退成**文字胶囊**（企划名本身，超长省略、hover 出全名）—— 这是"素材还没制作"时的
默认形态，不是占位 hack：库里 210 个企划名，一个个做图标是长期活。
所以**这个目录可以是空的**，徽章照样工作。

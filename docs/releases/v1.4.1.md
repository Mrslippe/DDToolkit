# DDtoolkit v1.4.1

个人向 VTuber 帖子 / 账号证据归档工具。本版在 v1.4.0 之上加了 **数据分析工作台的对比分析**。

> v1.4.0 → v1.4.1：**名单 CSV 导出** + **对比页签**（多主播重叠 / 帖子评论重叠）。
>
> ⚠️ **无数据库迁移**；`raw` 存储仍是 gzip（读取层兼容旧的 `*.json`）。

## 📄 名单导出 CSV

- 名单工具条「标签筛选」右侧新增 **导出 CSV**；
- **走服务端导出**：与页面完全同口径（同一个 `_compute`、同一套排序 / 标签过滤 / 场次清单），一次给全量（上限 5000 人）；
- UTF-8 BOM + CRLF（Excel 双击不乱码），列序固定；文件名 `{主播}-{日期}-{页签}.csv`。

## 🔍 对比页签

- 页签行最右新增「对比」，与四个分析页签用分隔符区分；**同步当前分析口径**（同一主播 / 窗口 / 区间）；
- **多主播模式**：2–6 个 V 的两两重叠矩阵，点格子下钻（共享数 / Jaccard / lift / **BH 校正** p / 层级迁移）；
- **帖子评论模式**：粘贴视频/动态链接或 BV 号，抓评论区（主楼 + 楼中楼），按评论数排行，再与核心度名单做重叠；
- 缺分析结果的主播会给出「还没有分析结果 → 采集并分析」的确认入口。

# DDtoolkit v0.9.2

个人向 VTuber 帖子 / 账号证据归档工具 —— 定时抓取 B 站与微博动态、账号统计并归档到本地 SQLite，桌面端浏览与管理。

> 本版是 **v0.9.1 的修复版**：修掉了「直装版首次运行卡在启动幕」「B 站扫码登录确认后无反应」两个阻断级问题，并完成一轮界面反馈整改。

## 🐛 关键修复

- **直装版（NSIS）首次运行卡在启动幕** —— 安装包把后端 onedir 的 `_internal/` 目录打平，exe 找不到 Python 运行时即静默退出。改为 Tauri 资源的数组形式（保留目录层级），安装包布局与新校验步骤写入发布手册。
- **B 站扫码登录：手机确认后应用无反应** —— 轮询读的是响应外层 `code`（恒为 0），把「未扫码」误判成「已确认」→ 拿空回调地址 → 取不到凭据 → `nav` 返回 -101。改读 `data.code`（86101 未扫码 / 86090 待确认 / 0 已确认 / 86038 已失效），并补上回调 URL 查询串 + 重定向链 + cookie jar 三路凭据提取（含同名多域 `SESSDATA` 冲突）。
- **首启失败不再无声**：启动幕显示等待秒数、`tauriBootstrap` 失败落错误态；后端 uvicorn 的 bind 失败等异常连 traceback 写入 `sidecar.log`；首次运行的迁移日志不再被 alembic 的日志配置吞掉。
- **顶栏轮询链在开发态 StrictMode 双挂载下断裂**（左栏直播徽标永不刷新）—— 轮询自愈。

## 🎨 界面

- **窗口右缘滚动条 / 宽度跳动 / 滚轮位移**：展示页滚动层改用 OverlayScroll、文档层禁止滚动；直播日历与粉丝趋势卡片 `min(870px, 100%)` 自适应（网格列宽改 `minmax(0,1fr)`）；列表页工具行允许换行。
- **首次启动自动弹出登录浮窗**，并明确说明「账号凭据仅保存在本机 `.env`，不上传任何服务器，也不接触账号密码」。
- **接入用户设计 LOGO**（猫脸）：顶栏 / 启动幕 / 站点图标 / 桌面端图标（含安装包、任务栏、多尺寸 ICO）。
- **视图定序**：卡片 → 列表 → 档案 → 档案卡（四个同级视图）；移除左栏与右栏光条中未接线的占位图标。
- 直播日历 / 粉丝趋势卡片标注数据来源（收录时自动回填 + 定时同步，无需手动触发）。

## 📦 资产

- `DDtoolkit_0.9.2_x64-setup.exe` — Windows NSIS 安装包（用户级安装）
- `DDtoolkit-portable-win64.zip` — 便携版（解压即用，含后端 onedir）

数据目录：安装版 `%APPDATA%\com.ddtoolkit.app`；便携版可设 `DDTOOLKIT_DATA_DIR` 自定义。

> ⚠️ 从 v0.9.1 升级请**先卸载旧版再安装**（旧安装目录残留了被打平的后端文件）。

## 🔧 技术栈

- 后端：Python 3.14 + FastAPI + SQLAlchemy 2.0 + SQLite(WAL) + APScheduler + Alembic（迁移链 e007）
- 前端：Vite + React 18 + TypeScript + Tailwind v4 + ECharts 6 + Radix
- 桌面壳：Tauri v2（拉起后端 + 注入空闲端口 + Job Object 看门狗杀进程树）

# DDtoolkit v1.1.1

个人向 VTuber 帖子 / 账号证据归档工具 —— 定时抓取 B 站、微博、小红书与抖音的帖子与账号统计并归档到本地 SQLite，桌面端浏览与管理。

> v1.1.0 → v1.1.1 是**一个小补丁版**（`devlog/375`、`devlog/376`）。用户能看到的只有一件：
> **浏览器扩展随应用一起安装** —— 直装版在 `<安装目录>\extension\`、便携版在 `DDtoolkit\extension\`，
> 应用里「设置 → 登录 → 浏览器扩展」把**路径**显示出来并给一个「打开目录」+ 装法三步。
> 其余是发布工具链与文档的自查修补（不影响使用）。**数据库无迁移**（仍是 f009），覆盖安装即可。

## 🧩 浏览器扩展现在随应用一起安装

v1.1.0 的扩展只活在仓库里 ⇒ 只下载 Release 的新用户**根本装不上**（浏览器只接受"商店"或
"本地目录 + 开发人员模式"两种来源，双击 `.crx` 从 Chrome 75 / Edge 起就被禁）。现在：

- **直装版**：安装目录里的 `extension\`（卸载时一并删除）；
- **便携版**：解压目录里的 `DDtoolkit\extension\`；
- 应用里「设置 → 登录 → 浏览器扩展」新增一行 **扩展目录**：显示绝对路径、「打开目录」按钮、
  以及装法三步（`edge://extensions` → 开发人员模式 →「加载解压缩的扩展」→ 选那个目录）；
- 扩展本体没变（同一份 `manifest.json` / `src` / `icons`，图标与桌面图标同源），
  产物里**不含** `test/`（那是 `node --test` 的用例，不该进安装包）。

> ⚠️ **仍然需要"开发人员模式"**：Edge 可能提示"请停用开发人员模式扩展"。
> 要彻底去掉这一步只有**上架商店**（Edge Add-ons / Chrome Web Store）—— 那件事仍在待定
> （设计案 P4：需要开发者账号、隐私政策与 `cookies` 权限用途说明，且以后每次更新都走审核）。
>
> ⚠️ 如果你此前是**从仓库目录**加载的扩展，改从安装目录加载后扩展 id 会变（id 由载入路径推出）
> ⇒ 需要在扩展设置里**重贴一次**配对 token（应用数据目录里的凭据不受影响，不用重新扫码/登录）。

## 🔧 维护者侧（不影响使用）

- **发货链补齐四条机器判据**：NSIS 脚本里必须有 `oname=extension\…` 的行、便携 zip 里必须有
  `DDtoolkit/extension/manifest.json`、`npm run tauri:build` 必须先跑 `stage:extension`、
  壳能解析出扩展目录（并且"空目录不算扩展"——判据是 `manifest.json` 在不在）；
- **发布脚本三处修补**：打包前的一致性复核带上 `build` 组（否则发布机上 preflight 与打包**互相
  打架**、必停）、日志/回显里的 token 一律抹成 `***`、缺更新签名私钥时**开跑前**就停
  （原先要等 7 分钟构建跑完才报）；
- **`collect:release` 只收本次版本的安装包**（`tauri build` 的产物目录不自清，上次的旧包曾被一起
  收进 `dist-release/`，verify 判"旧版本残留"，发布停在最后一公里）；
- 顺带订正 README 与 `docs/ops/PERF.md` 里已漂的测量值（版本表 1.0.2 → 1.1.x、
  安装包 45 MB / 便携 53 MB、pytest **1233** / vitest **1076** / `cargo test` **67**）。

## 📦 资产

- `DDtoolkit-portable-win64.zip` — 便携版（解压即用，含后端 onedir 与 `extension\`）

## ⚠️ 升级说明

- **数据库无迁移**（仍是 **f009**），覆盖安装即可；
- **使用须知按"声明版本"判断** —— 本版不会再让你确认一次（本版没有改声明正文）；
- 装完这一版，安装目录里就会出现 `extension\`；扩展的装法与排查见那个目录里的 `README.md`；
- v1.1.0 的行为都保留：MSE 播放内核、抖音总开关默认关、通知中心、轻资产固化等。

## 🔧 技术栈

- 后端：Python 3.14 + FastAPI + SQLAlchemy 2.0 + SQLite(WAL) + APScheduler + Alembic（迁移链 **f009**）
- 前端：Vite + React 18 + TypeScript + Tailwind v4 + ECharts 6 + Radix
- 桌面壳：Tauri v2（托盘 + 拉起后端 + 注入空闲端口 + Job Object 进程看门狗）
- 浏览器扩展：MV3（纯 JS + `chrome.cookies`，无构建步骤，随安装包/便携版一起分发）

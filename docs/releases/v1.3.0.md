# DDtoolkit v1.3.0

个人向 VTuber 帖子 / 账号证据归档工具 —— 定时抓取 B 站、微博、小红书与抖音的帖子与账号统计并归档到本地 SQLite，桌面端浏览与管理。

> v1.2.0 → v1.3.0 是**一个功能版**（`devlog/447`–`494`，46 篇）：**正文表情包**、
> **录播在应用内播放**、**直播场次类型**、**日期时刻选择器换成项目日历**、**多平台按名字搜人**，
> 外加日历性能与一批手感修复。
>
> ⚠️ **本版有数据库迁移**（`f012` → **`f017`**，五条）：首次启动自动迁移，**迁移前会自动备份**到
> `<数据目录>/backups/`。覆盖安装即可，不需要手动做任何事。

## 💬 正文表情包：真的画出图来了（需求 5）

- **解析换源**：原先从上游载荷里只能认出约 **28%** 的表情，改成读 B 站自己那份表情清单 ⇒ **99%**
  （`devlog/483`）。认不出来的仍按原文显示方括号，不会变成破图；
- **两类大小**：与 B 站一致 —— 官方小表情与文字同高，**大表情（贴纸）默认 40px**，
  判据用载荷自带的 `size` 字段（不是"官方还是自定义"，实测那条例外有 812 个，`devlog/485`）；
- **可调**：设置 → 外观 → **「大表情大小」**滑杆（24–64px，默认 40），下方给了一段图文混排示例；
- **不只正文**：帖子卡片标题、**纯文字封面**、详情窗标题也画表情（三处共用同一个渲染器）；
- 表情图统一走图片代理（直连会被图床 403）—— 这条路径的坑修过三次（`devlog/484`）。

## 📺 录播：入口搬到封面，能直接在应用里看（需求 3）

- 「找录播」先给**候选**、命中率是先量过的（`devlog/464`），不再猜；
- 入口从右列那行文字**搬到封面**（hover 出现 ▶ / ＋），封面点开是灯箱（`devlog/478`）；
- 点 ▶ **在应用内播放**：按 BV 号取流 + 播放器（`devlog/479`）；
- 也可以在**独立的无边框播放器窗**里播（设置 → 外观 → 「录播用独立播放器窗」，**默认关** ——
  不改变主窗播放这条老路，`devlog/480`）。

## 🗓️ 直播日历：类型、性能、以及一个能用的日期选择器

- **场次类型落库**（迁移 `f016`/`f017`）：写这一行就定稿这一行，按类型查询/统计改直查索引
  （`devlog/467`/`471`）；类型体系里**「健身」换成「助眠」**（真机上那类几乎没有证据，`devlog/468`）；
  数据视图多了「场次类型」卡、日历支持按类型筛；
- **收益卡**（`devlog/452`）、**手动记录场次与录播地址**（`devlog/454`）；
- **性能**：第一次打开日历要等的那一下（读端点不该写库，`devlog/473`）、切视图那 150ms
  （退场窗口里抢跑一发，`devlog/474`）、启动期那 485ms（只在真需要补时才扫，`devlog/475`）；
- **日期时刻选择器**：原生弹层换成项目自己的日历（滚轮列，`devlog/477`）；
- 修掉「日历弹窗只有遮罩、看不见小窗」（`devlog/476`）与详情窗头部的编辑铅笔被挤到正中央、
  词云 hover 提示与鼠标对不上（`devlog/491`）。

## ⚡ 省盘：B 站封面取数加图床规格（`devlog/492`）

封面固化时按图床规格取图（`@672w_378h.webp`，**不带裁剪**）—— 本机真库实测同一张封面降到
**0.1%–14%**（14 MB 的降到 13.8 KB、3.27 MB 的降到 30 KB）。已固化的旧封面不会自动变小，
新抓到的从此都是小的；动图（.gif，占 6.7%）会变成单帧。

## ⚠️ 升级说明

- **数据库有迁移**：`f012` → **`f017`**（五条：场次录播地址 / 企划归属 / 录播账号 / 场次类型 /
  场次身份键）。首次启动自动迁移，**迁移前自动备份**到 `<数据目录>/backups/`；
  迁移失败会把坏库隔离并用空库继续启动（状态见 `/healthz` 与「设置 → 关于」的体检）；
  不放心的话可以先手动复制整个数据目录再升级；
- **使用须知不会再让你确认一次**：本版没有改声明正文（`NOTICE_VERSION` 仍是 `2026-10-06`）；
- 数据目录与 v1.2.0 相同：默认 `%APPDATA%\com.ddtoolkit.app`，也可以在「设置 → 关于」里迁移到其他盘；
- v1.2.0 的行为都保留：单推模式、背景取景与背景视频、左栏自定义排序、浏览器扩展随包、MSE 播放内核、
  抖音总开关默认关、轻资产固化等。

## 🔧 技术栈

- 后端：Python 3.14 + FastAPI + SQLAlchemy 2.0 + SQLite(WAL) + APScheduler + Alembic（迁移链 **f017**）
- 前端：Vite + React 18 + TypeScript + Tailwind v4 + ECharts 6 + Radix
- 桌面壳：Tauri v2（托盘 + 拉起后端 + 注入空闲端口 + Job Object 进程看门狗）
- 浏览器扩展：MV3（纯 JS + `chrome.cookies`，无构建步骤，随安装包/便携版一起分发）

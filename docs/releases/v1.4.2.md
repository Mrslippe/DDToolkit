# DDtoolkit v1.4.2

个人向 VTuber 帖子 / 账号证据归档工具。本版在 v1.4.1 之上重做了**数据分析工作台的结果区**，
并把"分析结果"从页面状态升级为**每个主播一份、写盘可恢复的结果包**。

> v1.4.1 → v1.4.2：**结果包**（切回主播直接铺上次结果）+ **任务浮窗/顶栏进度** + **对比页改读结果包**。
>
> ⚠️ **无数据库迁移**；`raw` 存储仍是 gzip（读取层兼容旧的 `*.json`）。
> ⚠️ 新增数据产物 `数据根/_packages/*.json.gz`（每个主播一份分析结果，gzip，百 KB 量级）。

## 📦 结果包：分析结果不再"切走就丢"

- 每个主播一份结果包，**写盘**存放；切回该主播时**直接铺出上次的结果**，并把滑杆窗口与日期区间
  一起跳回那份结果对应的位置；
- 结果区标题会标明「缓存 MM-DD HH:MM」，与"刚算出来的"区分开；
- 重新选时间段分析 = **整包覆盖**，覆盖前会弹确认（写明将覆盖哪一组区间/窗口）；
- **命中结果包时不再读盘**：`/ranked`、分页、对比都直接从包里取（毫秒级，不再等几十秒重算）。

## 🪟 任务浮窗 + 顶栏进度

- 点「采集」/「分析」后弹出任务浮窗：阶段 / 翻页 / 吞吐 / ETA / **逐场标题**（含成功、失败原因、单场耗时）；
- 右下角 取消 / 完成 / 分析；抓取中途后两个按钮置灰；关掉浮窗**不影响任务**；
- 顶栏出现进度胶囊（「采集弹幕 · 某主播 12/75 场」），点它重新打开浮窗；
- 任务发起/结束时**立即**刷新通知，不再等下一拍轮询。

## 📊 结果区与对比页

- 未分析时是**完整的空态骨架**（标题 + 读数胶囊 + 页签 + 单张空态卡 + 名单卡），采集/分析进行中
  布局不变，只在顶部多一条很细的进度线（左标"采集/分析/读取进度"、右标百分比，结束后渐隐）；
- 图表卡恢复入场动画；切页签不再让卡片闪屏，也不再偷偷发起重算；
- **对比页改为卡片布局**（选择主播 / 重叠矩阵 / 配对详情 / 评论交集），对比的**基本单位是各自的结果包**；
  两份包区间不同时：交集人数照常显示，但 Jaccard / lift / 富集**标灰并注明不可比**。

## 🔒 隐私开关

- 设置 → 外观新增「隐藏昵称，改显示 uid」：工作台里的昵称一律换成 uid
  （名单、详情、搜索、贡献榜图例、评论交集表）；只改界面显示，导出 CSV 不受影响。

# DDtoolkit v1.4.0

个人向 VTuber 帖子 / 账号证据归档工具。本版重点是**数据分析工作台**：采集链路重做、分析模型收敛、
结果区图表改版，并补齐了可观测性与测试分层。

> v1.3.0 → v1.4.0 是**一个功能版**（`devlog/651`–`692`）：采集吞吐与完整性、图表动画、
> 名单与标签口径、三层测试、文档整合。
>
> ⚠️ **无数据库迁移**；但 `raw` 存储格式改为 `*.json.gz`（读取层同时兼容旧的 `*.json`）。

## 📥 采集链路

- **磁盘 -90%**：`raw` 改写 gzip（实测 9.1%），退役死字段 `pl`；
- **修掉每场最多缺 5,000 条**：首次大页 200k + 以 `total` 为准 + 大页与翻页结果合并去重；
- **成功率**：重试指数退避 + ±30% 抖动、按状态码分类（4xx 只重试 408/429）、超时按记录数自适应（120–600 s）、任务级补采；
- **并发固定 1**：实测上游对同一 IP 的整场抓取没有并发收益（57.1 s → 66.6 s）；
- **进度可视化**：阶段 / 翻页 / 吞吐 / ETA / 逐场状态 + 落盘回读校验。

## 📊 分析模型与前端

- 新增 `msh`（64 位 simhash）与 `stats.bp` 破坏性行为画像（精确复制、延迟中位数、目标数、间隔变异系数、版本号）；
- 标签收敛为 **10 条**，独轮车三档（none / suspected / confirmed）；
- 图表恢复 **ECharts 原生入场动画**：可见性门控 + 数据指纹重建，切页签/翻页各播一次、不重播；
- 饼图 HTML 图例（颜色 + 名称 + 数值）、昵称不再被裁、付费三色轴修复、坐标点逐点弹出；
- 采集进度面板细化；滑轨记住视野位置。

## 🧪 测试与文档

- **三层测试**：L1 合成夹具（不随数据变）/ L2 真实快照（重采必重录）/ L3 不变量（C1、Σ 一致性、池占比、coverage≥95%、付费轴）；
- 分析模型文档整合到 `docs/analysis-model/`（6 份），删除过期文档与旧快照；
- 七海纳入样本清单与黄金值。

## 升级说明

覆盖安装即可。旧的 `raw/*.json` 不需要迁移，读取层会先找 `*.json.gz` 再回落 `*.json`。

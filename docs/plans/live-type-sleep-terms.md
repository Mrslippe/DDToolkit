## 一、先看实测：这个类**几乎没有现成的标题证据**

真机库 8,515 条有标题的场次，逐词命中（只读副本，2026-10-12）：

| 候选词 | 命中 | 例子 |

| 助眠 / 哄睡 / 白噪音 / 音声 / 伴睡 / 耳骚 / 冥想 / 陪聊 / 安眠 / 睡眠 / asmr | **各 0 条** | — |
| 晚安 | 6 | `(¦3[▓▓] 晚安` · `晚安提问箱喵` |
| 早睡 | 7 | `小匹一会早睡` · `唱唱歌早睡` |
| 睡（已排除 睡过头/没睡/睡衣/睡醒/午睡） | **75** | `下雨天睡觉` · `聊一会会儿睡！` — ⚠️ 大半是「聊到睡」的杂谈，不是助眠内容 |

**结论**：助眠这个词表**起不出一版"能命中东西"的**——
- 明确指向助眠的词（助眠/哄睡/白噪音/ASMR/音声/伴睡/耳骚/冥想）在 8,515 场里**一次都没出现**；
- 带「睡」的 75 条里，多数是「聊到睡」的杂谈（判成助眠反而是错的）；
- **真正有量的同义信号是「工作音」（28 条）** —— 那是"陪你干活/陪你待着"的陪伴型直播，
  与助眠同族（低刺激、无需互动、可挂后台），但**它不是助眠**。

## 二、三处必须先定的边界

### ① 「电台」不能跟着搬

现有 `RADIO` 词条里**混着助眠词**，而 `radio`（电台）这个词本身在库里有 **181 条**命中：

```
RADIO: 电台 3.0 · asmr 3.0 · 晚安 3.0 · 伴睡 3.0 · 陪聊 3.0 · 谈心 3.0 · 哄睡 3.0 · 助眠 3.0 …
```

如果助眠把 `晚安/伴睡/哄睡/助眠/asmr` 一并拿走，那么**同样一个标题会同时命中两类**，
谁赢取决于加权与 `TITLE_CATEGORY_PRIORITY` 的并列顺序 —— 这种"看起来能跑、实际靠巧合"
的分工正是本仓反复吃亏的地方。建议的切法：

| 归 `radio`（节目感） | 归 `sleep`（陪伴/助眠） |
|---|---|
| 电台 · 陪聊 · 谈心 · 朗读 · 轻音乐 | **工作音** · 晚安 · 早睡 · 助眠 · 哄睡 · 白噪音 · ASMR · 音声 · 伴睡 |

### ② 带「睡」的词要不要

`睡` 单字命中 75 条，抽样看**多数是杂谈**（`聊一会会儿睡！`、`通宵没睡低气压碎碎念中……`）。
建议**只收「早睡」这种明确的**，不要收单字 `睡` —— 收了会把一批杂谈误判成助眠
（而那批场次今天判成 `chat` 是对的）。

### ③ 现有的「健身」那批（58 条标题命中 / 21 条已落库）

删掉 `fitness` 后它们会重新判，逐类看：

| 长相 | 条数（约） | 删掉健身之后会变成 | 对不对 |
|---|---|---|---|
| `健身鹮` / `健身环` / `一起健身环` | 约 20 | 落回 `live` 中性（标题里没有别的信号） | ⚠️ **`健身环` 其实是游戏**（Switch 健身环大冒险）—— 删掉健身反而**修好了**这三条 |
| `来运动！` / `坚持运动不做蓝狗day1` / `锻炼使我快乐` | 约 25 | 落回 `live` 中性 | 中性是诚实的（工具不知道他们在干嘛） |
| `一起看纪录片《肥宠瘦身》` | 1 | `watch`（"纪录片"不在词表，可能仍落中性） | 待观察 |
| 分区命中（`运动`/`体育`/`舞蹈` 分区） | 见 `AREA_RULES` | 分区那档也要同步删掉健身 | 必须一起改，否则"标题不认、分区认" |

⚠️ 真机**已落库**的 `fitness` 是 **21 场**（分区/标题两路合计）。按用户口径 3
（**改规则不回填老数据**），这 21 场会一直挂在库里、读取时降级成中性显示。

## 三、待你拍的三件事

1. **词表**（§二的切法）：`sleep` 收 `工作音 / 晚安 / 早睡 / 助眠 / 哄睡 / 白噪音 / asmr / 音声 / 伴睡`，
   `radio` 保留 `电台 / 陪聊 / 谈心 / 朗读 / 轻音乐`。**要不要收「放松 / 治愈」**？
   （16 条，但两词都太泛：「打游戏治愈狂躁症」会误伤）
2. **那 21 场旧 `fitness`**：破例跑一次重判（只针对这一批），还是让它们自然老去（读取时中性）？
3. **「工作音」算不算助眠**：28 条，是这批里唯一有量的信号。如果算，助眠这个类才立得住；
   如果不算（它更像 `radio` 或中性 `live`），那么助眠这个类**在真机上会长期是空的** ——
   那样的话「换掉健身」这个决定只是换了个标签，没有换来可用性。

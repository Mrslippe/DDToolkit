窗口是一块**透明**画布，边界看不见浅灰底 + 虚线标出（显示 → 画布标注）
窗口**裁切**超出它的绘制（阴影/内容一起切）显示 → 模拟窗口裁切
拖动移动的是**窗口**（OS 级）拖动画布；屏幕边缘会**停住**
面板高由**内容**决定（通知条数）滑块 + 「内容变化」按钮
跨屏：按**指针所在显示器**算允许范围（本轮定的 b）两块屏并排，指针在哪块就以哪块为界

拖动中样式：
怎么玩：在任意一条上按住 350ms 再拖（与线上一致；只点一下不会进拖动）。 指针扫过别的行时，被拖的那条会逐格换位——这正是线上实现的行为。 每条列表里第二条是"选中"态（左缘 3px 竖条），把选中的那条拖起来看看两套语言会不会打架。

A · 现状

opacity:.55 + 浅粉底。整行变淡 ⇒ 读起来像"禁用"；头像和名字一起被弄淡。

B · ★ 定版：纯投影 + 略微放大

scale(1.03)（transform-origin:left，免得左缘竖条被裁） + 0 6px 16px 投影 + z-index:1。拿起用过冲缓动 --ease-pop，松手回落到 --ease-standard。内容一点不淡。

C · 只有内环

去掉投影。用来判断投影到底有没有用——如果 C 和 B 看起来差不多，那投影就该省掉。

D · 虚线外框

呼应"把这一格框出来"。⚠️ 但本仓的基调是零圆角零描边（发丝线 + 底色承担形状）， 虚线框是新造一种视觉词汇。

E · 环 + 投影 + 轻微虚化

想同时"抬起"和"半透明"时的折中。opacity:.82 比现状轻得多—— 用来判断"虚化"这件事本身值不值得留。

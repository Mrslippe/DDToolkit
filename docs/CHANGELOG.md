# 更新日志

## v1.4.0 — 2026-10-27

### 采集链路
- **磁盘 -90%**：`raw` 改写 `.json.gz`（实测 9.1% 体积）；退役死字段 `pl`
- **分页补齐**：首次大页 200k + 以 `total` 为准 + 结果合并去重，修掉"每场最多缺 5,000 条"
- **成功率**：重试指数退避 + ±30% 抖动、按状态码分类、超时按记录数自适应（120–600 s）
- **任务级补采**：失败场次整轮后再试一次
- **并发固定 1**：实测上游对同一 IP 的并发**整场抓取**无收益（57.1 s → 66.6 s）
- **进度**：`phase/page/pages/records/throughput/eta_s/sessions_detail`，前端显示阶段、翻页、吞吐、ETA 与逐场状态；落盘后回读校验

### 分析模型
- 新增 `msh`（64 位 simhash）与 `stats.bp` 破坏性行为画像（精确复制、`lag_med`、`targets`、`interval_cv`、版本号）
- 标签体系收敛为 **10 条**，独轮车三档（none/suspected/confirmed）
- 七海纳入主播样本清单与黄金值

### 前端
- 结果区图表：ECharts **原生入场动画**、可见性门控、数据指纹重建（不再重播/漏播）
- 饼图改为 HTML 图例（颜色 + 名称 + 数值）、昵称不再被裁
- 付费构成三色轴修复（样式曾被误删）
- 出席页时滞图：拆 line + scatter，坐标点逐点弹出
- 采集进度面板细化；滑轨视野位置保持

### 测试
- 三层结构：**L1 合成夹具（不随数据变）/ L2 真实快照 / L3 不变量（C1、Σ 一致性、池占比、coverage≥95%、付费轴）**
- 后端 fan：全部通过（基线数量见 `scripts/docs_gate.py` 输出）

### 文档
- 分析模型文档整合到 `docs/analysis-model/`（6 份），删除过期旧文档、旧快照 CSV 与无引用流程图

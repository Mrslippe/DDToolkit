# 状态胶囊 · 动效设计规格（灵动岛式形变）

> **这是什么**：一份**设计规格**，不是实现说明。R38（顶栏状态胶囊的形变动效）与后续的
> 「桌面独立控件」两个批次共用它 —— 尺寸、时间轴、不变量都定在这里，代码只负责实现。
>
> **来源**：用户 2026-09-17 口径 —— 「希望顶栏状态胶囊能够像灵动岛那样拥有优雅灵动的动画，
> 例如向中间收起和展开，为之后我想做的桌面独立控件做准备」。
>
> **现状基线（2026-09-17 快照）**：**它说明的是"为什么要改"的起点，不是当前状态** ——
> 当前状态看 **`docs/UI-MAP.md` A1-a（唯一真源）**；R38 批 1（2026-09-24）已改动其中若干处，
> 逐条纠正见 §12.1。快照内容：`components/StatusIsland.tsx` 四态
> `idle`（只有绿点、**无容器**）/ `pill` / 展开面板 `.si-panel`（portal + fixed，`si-panel-in` 220ms）
> + 计数徽章 `si-pop-in` 180ms + 文案 key 重放淡入 `.si-text.pill-text-fade`；
> 优先级 `alert > progress > report > message`；reduced-motion 已有 `si-panel-in-fade` 先例。
>
> **风格取向**：借 iOS 灵动岛的**形变语法**（连续、内容滞后、同心圆角），
> 用 Fluent 的**节奏**（快、克制、无过冲）—— 桌面用户对弹跳的容忍度远低于手机。

---

## 0. 一句话原则

> **形随内容变（shape follows content），但只在内容真的变了的时候。**

灵动岛之所以高级，不是动画多，而是"同一块东西在长大/收拢"，眼睛始终跟着同一个锚点。
它是 iOS 上唯一的注意力中心；而我们的胶囊只是 40px 顶栏中间的一个信息位 —— 所以
**借它的语法，不借它的存在感**。

## 1. 三条硬约束（验收时先看这三条）

| # | 约束 | 为什么 |
|---|---|---|
| 1 | **空闲完全静止** | 循环动画 = 注意力税。空闲时连"呼吸"都不要（空闲轮播已下线，方向一致） |
| 2 | **动的只有胶囊自己，顶栏不动** | 胶囊居中、左右对称展开 ⇒ 天然不推邻居。这条让"展开不挤动右栏"的既有不变量继续可守 |
| 3 | **动画服务于连续性** | 每一次形变都要有"同一个锚点"：状态点 `si-dot` 全程不位移、不缩放 |

## 2. 动效令牌（先收词表，再谈动作）

起始状态是几处零散时长（**处数与数值见 §12 更正表** —— 本节原文写的"三处"是错的，别照抄）。建议收敛成一组令牌，桌面控件将来直接复用：

| Token | 值 | 用在哪 | 依据 |
|---|---|---|---|
| `--motion-fast` | **140ms** | 文案淡入淡出、计数徽章 pop | 状态类信息超过 ~150ms 就开始显得拖沓 |
| `--motion-base` | **220ms** | 胶囊折叠/展开、面板入场 | 与现有 `si-panel-in` 一致，体感"跟手但不慌" |
| `--motion-slow` | **320ms** | 跨级形变（两段式的第二段） | 位移大才配得上更长时间 |
| `--ease-standard` | `cubic-bezier(0.22, 1, 0.36, 1)` | 进入 / 展开 | 全站运动语言保持一致。**2026-09-24 批 1 起 `.si-panel` 也用它** —— 此前那条曲线是 `cubic-bezier(.22,.61,.36,1)`（**全站唯一的异类**），见 §12.1 |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 收起 / 离场 | 离场要干脆，不带缓出的迟疑 |
| `--ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | 大块面积（面板） | 面积越大越要"前快后慢" |

## 3. 三条编排规则（比数值更重要）

1. **形变先行、内容后到**（content lags the container）：容器开始形变后 **60ms**，
   新文案才淡入。一起动会有"挤在一起"的廉价感。
2. **离场比入场快**：撤离 **80–100ms**，且与容器回缩**同时开始** —— 否则眼睛会觉得"它赖着不走"。
3. **时长由距离决定，而不是由状态决定**：同一种状态变化在不同宽度下幅度不同，
   追求"位移/时长"恒定（位移大给更多时间），而不是所有情况都用同一个时长。

## 4. 「向中间收起 / 展开」时间轴

以**收起**为例（展开是它的严格逆序，内容滞后规则同理）：

| 时间 | 发生什么 | 细节 |
|---|---|---|
| 0ms | 容器开始收 | `transform-origin: center`；圆角全程保持"胶囊"（= 高度/2，**绝不出现方角中间态**） |
| 0–60ms | 旧文案先撤 | 位移 **6–8px 朝锚点方向** + 缩放 0.96 + 淡出；**只动 transform/opacity** |
| 60–180ms | 容器宽度收窄 | 单个元素做 `width` 过渡，高度固定、`overflow:hidden` + `nowrap`；**不要用 `scaleX`**（会把文字压扁） |
| 全程 | 锚点不动 | `si-dot` 不位移不缩放 ⇒ 视线有落点 |
| 收尾 | （可选）**1px settle** | 仅在大形变收尾给一次极轻的"落定"，绝不回弹 |
| 展开 | 逆序 | 容器 0–140ms 展开 → **60ms 后**新文案淡入 → 140–220ms 到位 |

## 5. 几何与同心圆角（"高级感"的两个细节）

**尺寸（顶栏宿主）**：顶栏高 40px（`--topbar-height`）·
胶囊折叠高 **24px** → 展开高 **30px** · 圆角：折叠 = 12px（= 高/2，完美胶囊）、展开 = 15px ·
面板圆角 **14px** · 面板与胶囊间隙 **6px** · 内边距水平 **10–12px** · 图标 **13–14px** ·
点击目标 ≥ **28px**（视觉可以小，命中区不能小）。

1. **同心圆角（concentric radius）**：面板内层元素圆角 = 面板圆角 − 内边距
   （例：面板 14px、内边距 8px ⇒ 内部卡片 6px）。这条是"看起来像一块材料挖出来的"和
   "两块积木叠着"的分界。
2. **禁止交叉淡入淡出文字**：`.si-text` 现在的 key 重放淡入对**同宽度**换字够用；
   但**宽度变化**时必须是「旧文案撤 → 容器变 → 新文案到位」，否则会出现两段文字叠影。

## 6. 状态梯队：只允许"相邻级"之间形变

```
① 静默（无容器，只有点） → ② 胶囊：点 + 短标签 → ③ 胶囊：点 + 标签 + 计数/倒计时 → ④ 展开面板
```

- **相邻级** = 一次形变（≤ `--motion-base`）。
- **跨级**（例如后台任务完成，从静默直接弹面板）= **两段式**：先 140ms 成形为胶囊，
  再 220ms 展开 ⇒ 观感是"它长大了"，而不是"突然出现一块板"。
- **一次只动一件事**：优先级最高的那条做形变对象，其余进计数徽章。

## 7. 两种宿主：现在就把两套材质定下来（为桌面控件铺路）

桌面控件会**浮在任意壁纸上**，现在不定、将来就得重做：

| | 顶栏宿主 `bar` | 桌面控件宿主 `widget` |
|---|---|---|
| 底 | 浅粉底 + 粉字（改前：与顶栏同族） | **深底 + `backdrop-filter: blur(20px) saturate(1.4)`** + 1px 高光内边 |
| 文字对比 | 沿用现有 | ≥ 4.5:1（亮/暗壁纸都要过） |
| 折叠尺寸 | 高 24 / 内容自适应 | **200 × 40** |
| 展开尺寸 | 面板 14px 圆角、宽自适应 | **280 × 面板高**（先按更小设计，向大适配更容易） |
| 待机 | 完全静止 | **完全静止**（桌面上的循环动画是注意力黑洞） |
| 窗口 | 顶栏内联 | 无边框 + 置顶 + 可拖动 + 位置持久化（`utils/shellState` 同款做法） |

> ⚠️ **"展开尺寸 280 × 面板高"这一行是到 R38 批 5d 才真正实现的**（devlog/183，2026-09-24）。
> 在那之前它只是**规格里的字**：窗口尺寸写死 200×40、没有 resize 通路，
> 于是面板 `top = 46` 落在 40px 高的窗口外 —— **用户从来没看见过小窗里的面板**。
>
> 现在由三处共同保证（改任何一处都要看另外两处）：
> ① `utils/widgetWindow.ts` 的 `widgetExpandGeom`（几何，29 条单测）；
> ② Rust `resize_widget_window`（通路，`set_size` + `set_position` 一起）；
> ③ `.widget-shell[data-flip='up']` 与 `StatusIsland.place()`（方向，两处必须一致）。
> 现状细节看 `UI-MAP.md` §A1-a-w2。

## 8. 组件契约（宿主无关是硬要求）

```tsx
<StatusCapsule state={state} density="bar" | "widget" />
useStatusIsland()   // 状态机：来源 / 优先级 / ttl / 计数，与宿主无关
```

**状态机与动画都不得依赖顶栏**：将来开一个 200×40 的 Tauri 无边框小窗，
塞同一个组件就是控件本身。因此动画里不许出现"相对顶栏定位"的假设（面板锚定一律相对胶囊自身）。

## 9. 反模式清单（明确不做）

- ❌ 每次变化都回弹/弹性过冲（第三次就开始烦）
- ❌ 文字交叉淡入淡出、`scaleX` 压扁文字
- ❌ 动画顶栏布局（改 bar 高度、推右簇元素）
- ❌ 时长 > 500ms（状态读的是"现在"，不是"过程"）
- ❌ 无限循环动画（spinner 是唯一例外；"呼吸点"也算注意力税）
- ❌ 无信息变化的位移（hover 只允许轻微提亮，**不允许胶囊位移**）
  —— ⚠️ 2026-09-19 起「hover 展开面板」是允许的（见 §13），但**胶囊自身仍不许位移/缩放**

## 10. 不变量清单（让"优雅"可断言 —— 探针照着写）

| 不变量 | 判据 | 实装 |
|---|---|---|
| 顶栏高度恒定 | 折叠/展开/回缩三态下 `.topbar` 高度完全相同 **+ 判成因：胶囊必须 `position: absolute`** | ✅ R38 批 2 |
| 不挤动邻居 | 右簇元素 `x` 位移 **< 1px**（面板是 portal ⇒ 天然成立，要守住） | ✅ `--status-island` |
| 胶囊不裁切 | 文案 `scrollWidth ≤ clientWidth + 1` | ✅ R38 批 2 |
| **锚点稳定 / 居中** | 面板中心与胶囊中心误差 **≤1.5px**（越界被夹进视口的情况除外） | ✅ R39-C |
| 中间态合法 | **圆角 ≥ 高度/2**（`999px` 被 clamp 到半高 ⇒ 任意帧都是胶囊）。⚠️ **不采样中间帧** —— 虚拟时间下过渡不推进（`DEV-LOOP.md`），采不到；这条结构级判据等价且更可靠 | ✅ R38 批 2 |
| 可打断 | 形变途中注入新事件 ⇒ 收敛到新状态，总时长 ≤ `base + fast`（不排队、不重排） | ⛔ 待 R38 批 4 |
| reduced-motion | 只保留淡入（沿用 `si-panel-in-fade` 先例）：位移/缩放归零，**信息不减** | ✅ `--status-island` |
| **hover 四条**（R39-C） | ① 掠过（60ms 内进出）**不弹**；② 悬停 280ms 内**必弹**；③ 指针移进面板**不收**；④ 离开面板**必收**；⑤ **点击钉住**（移开也不收，Esc/点别处/条目清空才收） | ✅ `--status-island` |

## 13. 待定口径（默认值已定，随时可改）

| 口径 | **默认（本规格采用）** | 备选 |
|---|---|---|
| 形变触发 | **只在信息变化时形变**；hover 只提亮 | hover 也展开 |
| 面板材质 | **白卡 + 粉做强调**（与"顶栏是粉底"形成层级） | 浅粉同族（更像品牌控件） |
| 回弹 | **零过冲**，仅大形变收尾 1px settle | 完全静止 / 允许轻微过冲（Apple 派） |

### 13.1 2026-09-19 口径变更（用户 R39-C）

用户原话：「顶栏状态栏呼出下拉栏的逻辑**改为鼠标 hover 就呼出，离开就收起**，并且**下拉栏居中**」。
⇒ 本规格 §13 的「形变触发：hover 只提亮」**被替换**，R38 批 2 起按新口径做：

| 项 | 新口径 | 为什么 |
|---|---|---|
| 进入 | **hover 120ms 后展开** | 鼠标从顶栏扫过时弹出面板是最烦人的错法；120ms 拦得住"掠过" |
| 离开 | **200ms 后收起** | 容得下"从胶囊移进面板"这一移（指针必然要跨过间隙） |
| 点击 | **钉住**（`data-pinned="1"`）：移开也不收 | hover 是快捷方式、点击是"点开细看"；两者不能互相顶掉 |
| 收起通道 | Esc / **点面板与胶囊之外** / 条目清空 / ttl | 钉住不能退化成"只能按 Esc" |
| 锚点 | 面板**水平中心对齐胶囊中心**（越界夹进视口） | 原来是左缘对齐 ⇒ 胶囊越靠右面板越偏 |
| 键盘 | Enter/Space 切换、Esc 收起（照旧） | hover 不许成为唯一入口 |
| 胶囊自身 | **仍然不许位移/缩放**（§9 反模式不变） | 借它的语法，不借它的存在感 |

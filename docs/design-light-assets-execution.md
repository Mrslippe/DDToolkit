## 1. 范围与完成定义

### 1.1 做完长什么样

**"小、不变、反复要"的远端资源在本地有一份长期副本 + 一份索引；再要一次 = 读盘，不是再发一次请求。**

| 能力 | 改动前（2026-09-29 实测） | 做完 |
|---|---|---|
| 头像：URL 失效 | 微博签名 3h 过期 ⇒ 靠 `/img-proxy` 缓存续命（V#16 已过期 21h） | 本地兜底（`avatar_local` + 回落链）⇒ 永远画得出 |
| 头像：同一张图多个 URL | 重复下载、重复存储、账本当两个版本（两份 sha256 相同的实测样本） | 稳定键归并 ⇒ 一份 |
| 头像：用户选过的那张 | 无锚点（2026-09-29 那次覆盖后只能从迁移前备份里挖） | 选中即 pin（在账本里有行、有本地路径） |
| 帖子封面 | 每次渲染回源/走代理缓存 | 未归档帖封面固化到 `static/assets/`，列表本地优先 |
| 清理 | `img-cache` 300MB / 7 天；`static/avatars` **从不清理** | 按 kind 分账：`stats` 可见、`prune` 只删未 pin 且未被引用的 |

### 1.2 非目标

见 `docs/design-light-assets.md` §1（整站镜像 / 合并 img-cache / 改抓取频率纪律 / 给
`vtubers.avatar` 塞两种形状 / 引新依赖 —— 都不做）。

### 1.3 验收

| 只能机器判 | 只能真机判 |
|---|---|
| 同 URL 第二次抓取 **0 次图片请求** · 同图不同 URL 只存一份 · 索引有文件缺 ⇒ 自动补下 · pinned 不被 prune 删 · `avatar_local` 命中时左栏/卡片**不依赖网络**（断网渲染） | 断网启动：左栏与卡片头像仍显示 · 收进托盘期间跑的抓取完成后，封面/头像都还在 · 清理后外观不变 |

## 2. 三条必须先定死的技术决定

### 2.1 稳定键的归一化规则（`assets.key_of(url)`）

- 丢掉 **fragment**；丢掉**白名单**里的签名参数：`Expires` / `ssig` / `KID` / `sign` /
  `signature` / `token` / `x-expires` / `x-signature`（**白名单，不是黑名单**：没列进去的参数
  一律保留 —— 少归一化只是多存一份，误删参数会让不同资源撞成一个键）；
- 余下 query **按参数名排序**后重组（防参数顺序漂移造出假不同的键）；
- ⚠️ **`key` 只用于查找与去重**；回源一律用**完整 URL**（存在 `local_assets.url`）——
  这样"丢掉签名参数"永远不会让下载失败。

### 2.2 落盘与索引的先后（崩溃安全）

**先写文件、再写索引行**，且 `get()` 命中要求**文件与索引都在**：

- 文件用**临时文件 → `os.replace` 原子改名**（与 `vtuber_background` 同款，避免半截文件）；
- 反过来（先索引后文件）会在崩溃/断电后留下"索引说有一份、盘上没有"的死条目，
  而 `get()` 若信索引就会返回一个不存在的路径 ⇒ 破图。文件缺失时的行为 = **当作未命中，
  重下并重登记**（`_avatar_missing` 的老教训：只查 URL 变化会永远补不下）。

### 2.3 图片下载的限速归属

图片走的是 CDN（与 API 不同域），但**必须与平台节奏共用闸门**：复用现有平台起跑闸门
（`app/services/platforms` 的 pacer / `rl` 的冷却状态），**不新增全局并发**，
每轮下载数有上限（L3 默认 20）。⚠️ 具体函数名开工前 `read` 确认，别按本文行号改。

## 4. 停止条件（**必须停下报告**）

| # | 条件 | 为什么停 |

| 半成品债 | **高**：M5-1 的端点在裸奔、两套供数并存、`kickPoll` 还在 | 低：L0 只是文档 |

| 真机验收 | **必须你在场**（托盘场景、草稿不被冲） | 可自证（图与 URL 都验过，探针可覆盖） |
| 依赖 | 无（M5-1 已完成） | A0 → L1 →（解锁 L2/L3） |

**结论（我建议的顺序）：`A0 → L1 → M5-2 → L2/L3`。**

- **A0 无论如何先做**：它很小（一个派生字段 + 一段回落链 + 一条回填），但它是**唯一**能带走
  "这次事故"的批次，而且它的产物在 L1 里被原样吸收（不返工）；
- **L1 排在 M5-2 前面**：先止"不可逆损失"这一类血，再动"更好形态"；且 L1 不重写任何既有判据，
  风险面比 M5-2 小；
- **M5-2 排第三**：它的收益是真的（单一真源 + 已读持久化 + 删掉 `kickPoll`），但**没有时钟**，
  而且它需要你在场做真机验收 —— 放在 L1 之后，正好让"一次真机验收"同时覆盖头像与通知两条。
- **如果你更想先收口**（我更愿意把选择权交给你）：把 M5-2 提到 L1 之前也成立 ——
  差别只是"先止血"还是"先清债"。**A0 不建议往后放。**

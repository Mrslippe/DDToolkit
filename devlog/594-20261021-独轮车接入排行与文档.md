# 594-20261021-独轮车接入排行接口 + 规则落文档

用户要求：把 `v1 ∪ v2` 接进排行榜，并把规则写进文档。

## 一、接线

- `load_window` 在读 raw 时顺手把每个用户的 `(mt, mh)` 序列喂进 `spam2.Trace`，
  收尾时对池内用户做 `v1 ∪ v2` 判定，结果存在 `Window.spam`（uid → 规则名）；
- 只喂**单场 ≥20 条**的用户 —— 绝大多数人每场只有几条，没必要给他们算滑动窗口；
- `GET /fan/{v}/ranked` 每行新增 `spam` 字段（`repeat` / `sustained` / `window` /
  `cross_session`，`None` = 不是），响应新增 `spam_in_pool` 计数。

实测（星瞳 75 场）：池 252,636 → 独轮车 **1,164 人**（repeat 1,100 / sustained 37 / window 27），
`load_window` 用时 17.6 秒（含判定）。

## 二、文档

- `analysis/analysis-model.md` 新增 **§1.2.1 文本去重与独轮车**：归一化口径、三个字段、
  两版判定与并集、为什么不做瞬时爆发检测、影响量级；
- `plans/fan-model-plan.md` §4 参数表补两行（v1/v2 阈值），并说明"只标记不剔除"。

## 三、一个已知限制

`cross_session` 在 loader 里会偏少：只有单场 ≥20 条的用户才进 trace，而这条规则针对的
恰恰是"每场只发几条、但场场都来刷同一句"的人。完整版需要 `scripts/spam_v2_compare.py`
那种离线全量扫描。当前 `repeat` 规则覆盖了绝大多数情况，可接受。

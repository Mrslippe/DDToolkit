# 199-20260925-CI 落地（含一条"注释让断言假绿"的自捉）

用户口径：「按你推荐来吧」——先插 CI，再开 S1。理由是批次 1 要动 Rust，
而"干净 clone 上 `cargo test` 到底能不能跑"这件事没验过，它决定 CI 怎么写。

## 一、先验卡点，而卡点不是我以为的那个

方案里写的顾虑是 **`frontend/src-tauri/gen/` 被 gitignore**（担心干净 clone 上缺少它而失败）。
实测（把 `gen/` 删掉、touch `build.rs` 强制重跑构建脚本）：**`gen/` 会被 `build.rs` 自己重建**
（4 个文件全回来）⇒ 不是问题，不需要入库。

真正的卡点在**资源 glob**：

```
glob pattern binaries/backend/**/* path not found or didn't match any files.
```

`tauri.conf.json` 的资源 glob 指向 `binaries/backend/**/*`，而那个目录由 PyInstaller 生成、
被 gitignore ⇒ **干净 clone 上 glob 一个文件都匹配不到**，`tauri-build` 直接让 build.rs 失败。
进一步实测出**最小前置**：往 `binaries/backend/` 放**任意一个占位文件**就能通过 ——
**不需要**真跑 PyInstaller，**也不需要**前端 `dist/`。这条直接决定了 CI 的 Rust 腿只有 3 步。

## 二、先补的失败用例（`tests/test_gate.py` +5 条）

`gate.py` 的用例之外，再加一组守 CI 的：workflow 存在 / 每个 workflow 都真的执行 `uv sync` /
`requirements.txt` 真是带 hash 的导出物 / Rust 进了 CI / CI 造了那个占位文件。

## 三、反向验证咬出两条**假绿**（本批最值钱的部分）

写完先验"这些断言真的会红吗"，用一个临时脚本把 6 种破法各跑一次。结果：

| 破法 | 结果 |
|---|---|
| 删掉整个 `workflows/` 目录 | **没红** —— `for wf in files` 在空列表上不进循环 ⇒ 断言空转通过 |
| 把 `uv sync` 换成 `pip install -r requirements.txt` | 红 ✓ |
| **只把 `uv sync` 删掉、注释留着** | **没红** —— 断言在**全文**里找 `uv sync`，而注释里就写着它 |
| **只把 `cargo test` 删掉、注释留着** | **没红** —— 同上 |
| 改掉 `binaries/backend` 路径 | 红 ✓ |

两条假绿的根因是同一个：**判据被自己的说明文字喂饱了**。修法：
① 空列表显式算失败（"没有可检查的对象"不是"通过"）；
② 新增 `_run_commands()` —— 只从 `run:` 里取**真正会执行的命令**（支持单行与 `|` 块标量两种写法），
注释与说明文字一概不算。修完重跑，4 种破法**全部会红**。

⚠️ 这正是本仓反复记过的那类事故（"判据看起来在工作却永不命中"），只是这次的被测对象
从产品代码换成了 CI 配置。

## 四、改了什么

- 新增 `.github/workflows/ci.yml`（Linux）：后端 ×2 个 Python（3.12 = `requires-python` 下界，
  3.14 = 本机版本）+ 前端（tsc / eslint / vitest / 日期区间断言）。
- 新增 `.github/workflows/ci-windows.yml`：造占位文件 → `cargo test` → `uv sync` → pytest →
  `npm ci` → 前端产物构建 → PyInstaller 冻结 → **冻结 exe 冒烟**（起进程打 `/healthz`）。
- `scripts/dev_check.py` 加 `--syntax-only`：CI 需要在"没装前端依赖、没浏览器"的 job 里跑
  **唯一会编译 `scripts/`** 的那一步。**让 CI 复用它而不是在 workflow 里抄一段 `python -c`**。
- **明确写下 CI 里跑不了的**（探针 / 托盘 / 深休眠 / 迁移 / 更新器）：列在 workflow 文件尾与
  `DEV-LOOP` §0.6.1。写成"永远跳过的一步"比不写更糟 —— 会让人以为有覆盖。

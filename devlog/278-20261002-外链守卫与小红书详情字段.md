# 278-20261002 外链统一走 open_external；小红书详情补上封面与日期

> 用户报障（2026-10-02，附帖子详情截图）：
> ① 「小红书帖子详情无法获取图片和日期信息」
> ② 「点击查看原文窗口右上角会出现红色的报错框」（那句报错是
> `Promise shell:allow-open not allowed. Permissions associated with this command: shell:allow-open, shell:default`）

## 一、「查看原文」为什么报错、还打不开

`PostDetailDrawer` 的「查看原文」（两处：元信息行 + 转发原文）是**裸 `<a target="_blank">`**。
WebView 里 `target=_blank` 由壳接管 → 调 **`shell:allow-open`** → 而该权限**早已从
capability 删除**（S3-B，devlog/208：改用带主机白名单的自定义命令 `open_external`）⇒
Promise 被拒 → 链接打不开，界面上还冒一条内部报错。

**判据漏了它**：`openExternal.test.ts` 只扫 `plugin:shell|open` 字面量，扫不到裸锚点。

### 改法：一层**全局外链守卫**

新增 `utils/externalLinkGuard.ts`，在 `main.tsx` 里 React 之前装一次：

- 捕获阶段拦 click → 命中"绝对 http(s) 且不同源"的 `<a href>` → `preventDefault()` + `openExternal`；
- 同源/相对路径交给 SPA 路由，`mailto:`/`tel:` 一律不碰；
- 这样**平台富文本里的链接**（`dangerouslySetInnerHTML` 渲染的，挂不上 React 处理器）也一起覆盖；
- 失败**不静默**：Rust 白名单拒绝的中文原因 → toast + 问题报告（见 279）。
- 两处「查看原文」改成按钮直接调 `openExternalFromHref`（意图显式、键盘可达）。
- `sanitizePlatformHtml` 保留 `target` 只作**兜底**：万一守卫没装上，壳会拒掉导航，
  而不是把 WebView 导航走（那会丢掉整个界面）。

判据：`openExternal.test.ts` 新增 3 条（外链被拦且走命令 / 同源与 `mailto` 不接管 /
`externalHref` 只认绝对 http(s) 异源）。

## 二、小红书帖子详情：图、日期、点赞三样都在回包里，我们没取

真机回包（`/user_posted` 的一条笔记）：

```json
{"type": "normal", "note_id": "6abf…", "time": 1790929832000,
 "display_title": "走，秋天和我一起逛街咯",
 "cover": {"url": "", "info_list": [{"image_scene": "WB_PRV", "url": "…"},
                                     {"image_scene": "WB_DFT", "url": "…"}]},
 "interact_info": {"liked_count": "1036"}}
```

| 字段 | 旧实现读的 | 真回包 | 症状 |
|---|---|---|---|
| 封面 | `cover.url` | **空串**；地址在 `cover.info_list[]`（`WB_PRV`/`WB_DFT`） | 详情里没有图 |
| 发布时间 | 恒 `None`（注释误以为"列表接口不给时间戳"） | **`time`（毫秒）** | 「发布于 —」 |
| 点赞 | 顶层 `liked_count` | `interact_info.liked_count`（字符串） | 统计空 |

改法：抽出 `_cover_url()`（优先 `WB_DFT` 大图）/ `_images()`（写进 `body_json.images`，
详情窗据此渲染）/ `_ms_to_utc()`（毫秒 → naive UTC，与其它平台一致），`_to_item` 按真机形状取字段。
判据：⑫ 按真机形状断言封面/时间/点赞 + ⑫′ 缺字段不炸。

> 只做这一刀（**不拉详情接口**）：多图与完整正文要 `POST /api/sns/web/v1/feed`（带会过期的
> `xsec_token`），实测该接口可用、单帖 6 张图，属于"以后要更全"时的下一步（用户 2026-10-02 口径：
> 先修解析）。

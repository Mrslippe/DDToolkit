# 699-20261028-评论抓取服务 + 与名单的重叠端点（P3 后端）

## 服务：`app/services/bili_replies.py`

一条链路：**解析 → 抓取 → 聚合 → 落盘**。

| 环节 | 说明 |
|---|---|
| 解析 | BV / av / `bilibili.com/video/…` / `t.bilibili.com/{id}` / `opus/{id}`；短链先跟随重定向 |
| oid | 视频走 `x/web-interface/view`（拿 aid + 标题 + 评论数）；动态走 `x/polymer/web-dynamic/v1/detail`（**WBI 签名**） |
| 主楼 | `x/v2/reply?type=1|11&sort=0&ps=20&pn=N`，最多 1000 页（2 万条封顶） |
| 楼中楼 | 只对**评论数最多的前 50 条主楼**抓 `x/v2/reply/reply`，计入 `sub_cnt` |
| 限流 | 串行 + 1.2s 间隔（评论区对高频很敏感） |
| 落盘 | `<数据根>/_compare/scans/<scan_id>.json` —— **不进数据库**：一次性外部快照，和 raw/stats 同思路，省一次迁移 |
| 失败 | 统一兜成 `state.error`（不静默），`expected` 拿不满时 `partial=true` |

## 端点：`app/routers/fan_compare.py`（依赖注入式路由）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/fan/compare/scan` | `{input, with_sub}` → `{scan_id}`，后台线程跑，立即返回 |
| GET | `/fan/compare/scan/{id}` | 进度（`phase/page/fetched/expected/partial/error`） |
| POST | `/fan/compare/scan/{id}/cancel` | 取消 |
| GET | `/fan/compare/scan/{id}/users` | 评论名单（按评论数降序） |
| GET | `/fan/compare/comment-overlap` | 与某 V 核心度名单的重叠 + 超几何双侧 + Top-N 覆盖 + 分层命中 |

重叠数学抽成**纯函数** `overlap_stats(tier, strength, users, top_n)` —— 不碰网络/文件，CI 可测。

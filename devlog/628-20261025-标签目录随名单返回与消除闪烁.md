# 628-20261025-标签目录随名单返回；消除切页签闪烁

用户两条：分析完成后点标签筛选仍要等十几秒；切标签时所有卡片都在闪。

## 一、那十几秒是什么

筛选弹层的目录**单独发了一次请求**。它虽然带了 `since/until/ids`，但**没带 `window`**，
而后端计算缓存按 `(主播, 窗口, 起止, 场次清单)` 作键 —— 键不同 ⇒ 命中不了刚才那次分析，
于是**从零再算一遍**（十几秒）。

### 修法：不再发那次请求

`/ranked` 的响应里直接带上 `tag_catalog`（池内占比，因为名单里看到的就是池内比例，
不是全体观测用户的 0.0x%）。筛选器只消费这份数据，**零额外请求、零等待、也不可能不一致**。

顺带删掉了 `fanTags` 那次调用的 loading/error 状态 —— 问题从根上不存在了，
留着只是一层永不触发的代码。

## 二、闪烁源（三个叠加）

| 来源 | 现象 |
|---|---|
| 面板 `key={tab}` | 切页签 → 整个面板**重挂载** → 图表重建 |
| `.wb-tabpanel { animation: wb-fade }` | 重挂载时重播 180ms 淡入 + 位移 |
| `.wb-tabpanel.is-loading { opacity: .55 }` | 每次 `busy` 整块面板**先暗后亮** |

三处全部移除：面板不重挂载、不淡入、不降透明；`min-height` 保留（防止切页签时高度塌陷导致滚动跳顶）。
**动画只保留在表格行上**（`wb-row-enter`），因为那是唯一"内容真的换了"的地方。

## 三、验收

后端 fan 166 passed / 2 skipped；前端 1,581 passed；`tsc` 干净；`npm run build` 成功。

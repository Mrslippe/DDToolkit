# 675-20261027-切页签两次闪动、坐标点没动画

## ① 两次闪动 = 挂载了两次

上一版把 `dataStamp` 放进卡片 key 之后，切页签的时序是：

1. 用**旧数据**渲染 → 卡片挂载（第 1 次动画，刚开始就作废）；
2. 数据回来 → key 变 → 卡片**重新挂载**（第 2 次动画）。

两次挂载 = 两次闪动，也正是"动画看起来不正常"的来源。

修法：页面记住 `ranked` 属于**哪个页签**（`rankedTab`）；
`rankedTab !== tab` 时图表区只渲染一个**等高占位**（`wb-charts-pending`，无内容、无动画），
数据一到才挂载一次：

```
切页签 → 占位（约几十毫秒）→ 数据到 → 挂载一次 → 播一次动画
```

## ② 坐标点不动

ECharts 的折线动画分两层：

- **线**：`animationDuration` 控制描边；
- **数据点（symbol）**：默认跟随线一起瞬间出现，要让它依次弹出必须给 **`animationDelay`**。

之前只设了 `animationDuration`，所以只有线在动。补上：

```ts
animationDuration: 700,
animationDelay: (idx) => 120 + idx * 70,
symbolSize: 6,
```

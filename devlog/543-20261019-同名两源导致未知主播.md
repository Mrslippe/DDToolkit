# 543-20261019-「未知的主播」：同名两源

用户切到星瞳后点采集，报 `未知的主播：'星瞳_official'；可用：[弥月Mizuki, 明前奶绿, 星瞳_Official]`。

## 一、根本原因：同一个主播有两个名字

| 来源 | name |
|---|---|
| 数据目录 / 旧样本（`LEGACY_VTUBERS`） | `星瞳_Official`（**有**下划线，大写 O） |
| dev 库 | `星瞳official`（**没有**下划线） |

`/fan/vtubers` 是**两边合并**列出来的，所以前端下拉里可能有只存在于旧样本的那个名字；
而 `get_vtuber(name, db)` 只在**库**里找 ⇒ 必然扑空。

实测（改前）：

```
get_vtuber('星瞳_Official', db)  → FAIL     ← 前端发的就是这个
get_vtuber('星瞳_Official')      → ok
get_vtuber('星瞳official', db)   → ok
```

## 二、改法：两层清单都查

`get_vtuber` 先查库清单，未命中再查 `LEGACY_VTUBERS` —— 两层任一命中即返回。
全都不命中仍抛原来的错（错误信息不动）。

改后三个写法都能解析到 `pilot_v3_xingtong`。

## 三、用例

- `test_get_vtuber_falls_back_to_legacy_names`：旧样本名（不传 db）必须能解析；
- `test_get_vtuber_falls_back_when_db_pool_misses`：给 db 时两边名字都能解析
  （无 DB 环境自动 skip）。

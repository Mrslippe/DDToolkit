## 一、真凶（上一轮的假设被证实）

`show_widget_window` 是 `#[tauri::command] fn`（**同步**）——
**Tauri v2 里同步命令跑在主线程**。而 `WebviewWindowBuilder::build()` 要创建第二个 WebView2，
必须和主线程的消息泵交互。在**已有一个 webview 的进程里、于主线程同步建第二个** ⇒ **卡死**。

**一条假设同时解释了用户报的全部症状：**

| 症状 | 解释 |
|---|---|
| 小窗是个半成品（有框、没内容）| WebView2 建到一半就停了 |
| 主窗口点 ✕ / 最小化没反应 | **主线程卡死** |
| 托盘退出也杀不掉 | 同上 |
| 点开关"没任何变化" | 命令进去就再没出来 |
| 日志停在 `被调用` 那一行 | 就是卡在这里 |

**修法**：`show_widget_window` / `hide_widget_window` / `destroy_widget_window`
全部改成 `async fn` ⇒ Tauri 放到**异步运行时**执行，消息泵空出来。

> 这是本项目里第二个"**在错误线程上做窗口操作**"的 bug 家族 ——
> 主窗口那条路走的是 `setup()`（本来就在主线程、且是首次创建），所以一直没暴露。

## 二、日志里当场又暴露了下一个 bug：每行都写了两遍

```
18:03:46  show_widget_window 被调用        ← 两次
18:03:46  小窗不存在，开始创建 …            ← 两次
18:03:46  小窗已创建（200×40 无边框置顶）    ← 两次
```

**创建了两个窗口** ⇒ 这就是用户说的"按住拖动它之后原地残留了一个"。
它不是残影，是**第二个真实窗口**：初始与第一个完全重叠，一拖就分开
（截图里能看到下面那个的自检条**挤成两行** —— 200px 宽塞不下的特征）。

**根因**：`main.tsx` 的 `React.StrictMode` —— **开发模式下每个 effect 故意跑两次**
（挂载→卸载→再挂载），用来暴露副作用没清理干净的问题。而"启动时按偏好开小窗"那条
effect **既没有 cleanup、也没有幂等保护**。

**两道防线**（都需要，缺一不可）：

| # | 在哪 | 做法 | 为什么不能省 |
|---|---|---|---|
| 1 | 前端 `TopBar` | **模块级** `widgetAutoOpenDone` 标志 | 组件内 `useRef` 会跟着 StrictMode 的重挂载一起重置 ⇒ 挡不住 |
| 2 | Rust `show_widget_window` | `CREATING_WIDGET: AtomicBool` 重入保护 | **命令不幂等这件事更根本** —— 快速双击、并发调用同样会建出第二个窗口 |

> **这个 bug 是 StrictMode 帮我抓出来的**：它存在的意义正是"暴露没清理干净的副作用"，
> 而我的副作用确实没清理。**开发模式跑两遍不是"环境的怪癖"，是设计好的检查。**

## 三、六轮的复盘：我错在哪、哪一步才开始对

| 轮 | 我做了什么 | 结果 |
|---|---|---|
| 1 | 修 ACL 作用域 / 窗口外观 / 退出死角 | 真问题，但不是"看不到胶囊"的原因 |
| 2 | 修静态启动幕 / `html` 背景 | 修饰，**一行都没执行** |
| 3 | 修 `backdrop-filter` / DWM 外框 | 同上 |
| 4 | 装仪表（URL + 页面自检）| **转折点** |
| 5 | 渲染异常写进 `shell.log` | 拿到第一条完整证据 |
| 6 | **改成 async 命令** | ✅ **解决** |

**三个反复犯的错**：

1. **把噪声当信号** —— 从截图里读"粉色变透明、边框变细"当成修复生效，连错两轮。
   用户一句「实际三次修改都是一样的东西」才点破。
2. **拿不完整的证据下结论** —— 从"控制台里没有那行"推出"命令没被调用"，
   而用户只是**截早了**（探针在 +1500ms 才打印）⇒ 推错方向一整轮。
3. **在看不见的地方猜，而不先装仪表** —— 一个 200×40、置顶、无边框、**开不了 devtools**
   的窗口，**装仪表的优先级高于修任何东西**。我在第四轮才做这件事。

**唯一有效的顺序**：先把"到底发生了什么"变成可读的事实（URL / 页面自检 / 渲染异常 → `shell.log`），
再动手。前四轮之所以全废，是因为我一直在**改**，而不是在**看**。

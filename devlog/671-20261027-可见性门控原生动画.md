# 671-20261027-方案 A：可见性门控 + 原生动画

用户定案 A：**每次看到都重播一次原生动画**，但同一页签内数据刷新不重播。

## 架构（`EChart` 重写）

```
挂载 → IntersectionObserver 观察自身
   ├ 变可见 → init() + setOption(option)      ← ECharts 原生 initial animation
   ├ 变不可见 → dispose()                     ← 切回来时重新 init ⇒ 动画重播
   └ 可见期间 option 变化 → setOption({animation:false})  ← 数据刷新不重播
```

关键点：**`IntersectionObserver` 会把被 `overflow: hidden` 裁掉的轮播页判为不可见**，
所以相邻页不会在 0 宽容器里 init —— 这正是之前"动画被跳过 / 播两次"的根因。

初始化前还会等 `offsetWidth > 0`（最多重试 8 帧），确保真的布局完成。

## 删掉的东西

- 两帧「全 0 → 真值」的伪动画（`zeroed()`）；
- 饼图的 `animationType: 'scale'` 兜底；
- `run` / `playKey` 计数（不再需要手工触发重播）。

## 现在的行为

| 动作 | 动画 |
|---|---|
| 首次分析出图 | 原生播一次 |
| 切页签 | 新卡片可见 → 原生播一次 |
| 翻页 | 新页滑入 → 原生播一次；滑出页 dispose |
| 同页签重新分析（数据变） | **不播**（只更新数据） |

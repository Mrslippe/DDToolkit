# 019-20260817-v0.4.5-头像缺失补下

## 问题

全量/单 V 更新账号信息时，头像下载仅在 **URL 变化**时触发，不检查本地文件：
- 初次下载失败（当时仅 warning）或文件被删后，`avatar_path` 与磁盘不一致，
  而 URL 不变 → 永远不补下；
- 实测：4 个在管账号的 avatar_path 全部指向**不存在的文件**。

## 修复

`_fetch_one_account` 头像逻辑改为：
- URL 变化 → 下载（覆盖旧文件）；
- URL 未变但本地文件缺失（`_avatar_missing` 检查 avatar_path 对应的磁盘文件）→ **补下**；
- URL 未变且文件存在 → 跳过。

新增纯函数（含单测）：
- `_avatar_missing(acc)`：avatar_path 为空或磁盘文件不存在 → 缺失；
- `_needs_avatar_download(acc, new_avatar, file_exists)`：下载判定。

## 验证

- 实测：删除星瞳头像文件 → `POST /vtuber/1/fetch` → 自动补下 `static/avatars/401315430.jpg`（1.3MB）✓；
- 49 passed（47 + 2：下载判定、文件缺失检查）。

## 文件变更

| 操作 | 文件 |
|------|------|
| 修改 | `app/services/scheduler.py`（_avatar_missing/_needs_avatar_download + 抓取逻辑） |
| 修改 | `tests/test_services.py`（+2 用例） |

## 注意

后端需重启 uvicorn 生效；重启后任意一次抓取（全局 / 单 V）都会补齐缺失头像。

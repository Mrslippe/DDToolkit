# 644-20261025-出席浮层：改成"放大镜"式逐格重叠

用户：希望浮层从**单元格一一对应的位置**长出来，而不是整组下方冒出来。

## 做法

浮层与方块区**共用同一套几何**：20 列 × 14px + 6px 间距，两边完全一致。
hover 时把浮层定位到方块区原点（左上各减 8px 内边距补偿），
于是浮层里的第 N 格**正好压在**表里的第 N 格上 —— 视觉上是原地点开，行数变多。

数据从 40 格（2 行）扩到全部场次（75 场 = 4 行），原地向下延伸。

## 连带调整

- 默认区方块从"随列宽收缩"改回**固定 14px**：两边几何必须一致，否则重叠会错位；
- 浮层仍是 `createPortal` + `fixed`（绕开表格的 `overflow: hidden`）；
- `onMouseEnter` 取消收起 / `onMouseLeave` 收起，指针从方块移到浮层不会闪。

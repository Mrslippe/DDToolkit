# 711-20261028-工作台「隐藏昵称」：一律改显示 uid

## 需求

用户口径（原话）：**「隐藏用户昵称、一律改用 uid 显示，并在设置窗口加一个开关控制」**。
场景是演示 / 录屏 / 截图 —— 名单里挂的是真人昵称，不想露出来；而 uid 是稳定键，
换成 uid 不影响任何口径（分层、分位、贡献占比都不看名字）。

## 落点：一处开关，五处显示

| 位置 | 文件 | 隐藏后 |
|---|---|---|
| 设置窗口 | `components/AppSettingsDialog.tsx`（外观页） | `.aps-switch` 开关，默认关 |
| 名单表昵称列 | `components/workbench/RankedTable.tsx` | 主文字 = uid，副行 uid 不再重复 |
| 名单表头像兜底 | 同上 `Avatar` | 首字取 uid 首位（否则头像加载失败时漏出一个「鲸」字） |
| 成员详情抽屉 | `components/workbench/MemberDrawer.tsx` | 标题 = uid |
| 名单搜索下拉 | `components/workbench/MemberSearch.tsx` | 条目 = uid；**仍可按昵称搜**（搜在后端，隐藏的只是显示） |
| 贡献榜饼图 | `components/workbench/ResultCharts.tsx` | 图例/扇区 = uid |
| 评论交集表 | `components/workbench/CommentComparePane.tsx` | 用户列 = uid |

## 为什么是模块级 store，不是 prop

这五处分布在 `WorkbenchPage` 底下好几层，而 `WorkbenchPage` **自己不持有偏好**
（`fan_workbench` 那个开关归 `IconRail`）⇒ 做成 prop 要给每个组件加参数、给每条
已有用例补 provider，收益为零。与 `utils/groupBadgePref.ts` 同一套路：模块级现值 + 订阅。

⚠️ 与 `groupBadgePref` 的**关键差别**：那个只要给根元素挂个属性、CSS 就能整块隐藏
（不用重渲染）；这里换掉的是**文字**（连 canvas 边上的 HTML 图例也要换），CSS 做不到
⇒ 必须让组件重渲染，所以多了 `useSyncExternalStore` 一层订阅。

## 贡献榜要后端补一个字段

`_top_split()` 原来只给 `labels`（后端拼的昵称）与 `values`。前端拿不到 uid ⇒ **无法**替换成文字，
所以在 `app/routers/fan.py` 里补了 `uids`：与 `labels` **等长同序**，`其他 N 人` 那条是 `None`
（它不是某个人）。按下标配对，错一位就会"这个鲸鱼的名字配那个人的金额"。

前端拿不到 `uids`（老响应/旧快照）时**退回昵称** —— 宁可显示昵称，也不要渲染成 `undefined`。

## 两条边界（写进了设置里的 note，不静默）

1. **导出的 CSV 不受影响**：`ranked.csv` 是后端按名单口径出的数据文件，不是界面显示。
   想让导出也不带昵称，得另加参数 —— 这轮不做，但**在开关旁边明写了**，用户点导出前就知道。
2. **主播名不隐藏**：`ProfileCard` / 对比页里的主播名是要分析的对象，藏了工具就没用了。

## 验证

| 检查 | 结果 |
|---|---|
| `tests/test_fan_api.py::test_contribution_split_carries_aligned_uids` | 9 passed（`uids` 与 `labels` 等长、合计项为 `None`） |
| `utils/hideNicknames.test.ts` | 9 passed（默认关、只有 `on` 算开、根元素属性、订阅去重、`shownName`） |
| `components/workbench/hideNicknames.test.tsx` | 7 passed（表/图例真的换了、老响应退回昵称、走 `getPrefs` 真路） |
| `tsc --noEmit` / `eslint --max-warnings 0` | 无输出 |
| 前端全量 vitest | 见本轮提交 |

⚠️ 写组件用例时踩了一次自己的坑：只在用例里 `applyHideNicknames('on')` 是不够的 ——
组件挂载后 `useHideNicknames` 会去拉 `getPrefs`，**后端桩说"关"就把状态覆盖回去了**，
症状是"明明 apply 了还是露昵称"，特别像"组件忘接"。桩里那个 `prefValue` 必须一起改。

## 兜底值必须两边一致

`HIDE_NICKNAMES_DEFAULT = 'off'` 与后端 `PREFS["hide_nicknames"]` 的第一项同值（与
`group_badge` 一条纪律）。漂了之后的症状是"设置里显示开、工作台却还在露昵称"。

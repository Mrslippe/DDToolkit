# 494-20261014 企划徽章的显示开关（设置 → 外观，默认关）

> 用户口径：「把企划图标显示开关做到设置里，然后推送并发版」；追问后明确
> **形态 A（控制左栏那一整列的显示）+ 默认关**，版本号 **v1.3.0**。

## 一、这个开关关掉的是什么（先把口径写死）

**关**（默认）= 左栏每一行名字右边那个 **54px 的徽章槽位**（`.vtuber-emblem`）**完全不渲染、不占位**，
名字能占更宽；**开** = 回到 2026-10-08 那套（有图标素材画图标、没有画企划名，没企划的显示「个人势」）。

⚠️ 为什么默认关：企划图标素材**保持空缺**（用户 2026-10-14 定，`TODO.md` §5）⇒ 那一列恒为**文字胶囊**，
而池内多数还是「个人势」—— 默认占着每行 54px 并不划算。

## 二、落点：一个**用户偏好**，不是运行时设置

| 层 | 改了什么 |
|---|---|
| 后端 | `settings.PREFS["group_badge"] = ("off", "off", "on")` + `prefs_specs()` 里一条「显示企划徽章」（外观组，两档） |
| 前端 util | **新增** `utils/groupBadgePref.ts`：把状态写到 `<html data-group-badge>`（与 `emojiSize.ts` 同一套路：根元素 + CSS，不往 React 里传 —— 它是纯显示开关，组件里没有随它变化的状态） |
| 前端 CSS | `layout.css`：`html[data-group-badge='off'] .vtuber-emblem { display: none }` |
| 壳层 | `App.tsx` 挂 `useGroupBadge()`（与 `useEmojiBigSize()` 并排，启动读一次） |
| 设置窗 | 外观页一行 `.aps-switch`（用户说的是"开关"，而且它是二值偏好）+ `pickGroupBadge`（乐观生效 + 失败退回） |
| `usePrefs` | 读不到后端时的兜底值补上 `group_badge`（与后端默认一致） |

**一处刻意的 fail-open**：CSS 规则**只对 `off` 写**，不写成"只在 `on` 时显示" —— 属性没挂上时
（首帧 / 后端读不到）徽章**照常显示**，也就是"改动前的老样子"。反过来写的话，任何一次读失败
都会让左栏突然少一列。

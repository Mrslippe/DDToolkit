# 268-20260930 F2：小窗三需求（阴影照抄 · 文字居中 · 展开/收起形变）

用户三条（附截图）：① 阴影被截断 ② 文字没居中 ③ hover 展开/收起不流畅。
拍板：① 留白**先做"不挡鼠标"**再照抄样例；② 只修居中、**保 200 下限**；
③ 形变走**"窗口先到位 + 卡片跑 CSS 动画"**（OS 窗口做不了过渡）。

## 一、① 阴影：照抄样例，留白 32 → 80

阴影换成 `docs/design/widget-preview/direction.html` 的 `--shadow` / `--shadow-open` 三层，
`WIDGET_SHADOW_PAD` 由"各层 `dy + blur/2` 的最大值"算出 = **80**（折叠窗口 360×200）。
⚠️ 前提是那圈留白**只画不接**：Rust 侧子类化小窗 HWND，`WM_NCHITTEST` 落在卡片外 ⇒ `HTTRANSPARENT`
（新命令 `set_widget_card_inset(pad)` 由前端告知；`pad<=0` 完全关掉，是回退开关）。
真机手感**只能人验** ⇒ 记进 `TODO.md` §1.3。

## 二、② 居中：三段式，不是 `justify-content`

`.si-lead/.si-mid/.si-tail`（顶栏宿主下 `display: contents`，一字不变）+
小窗里 `lead/tail { flex: 1 1 0 }`、`mid { flex: 0 1 auto }` ⇒ **内容组中心 == 胶囊中心**，
且与"点/chevron 出没"无关（`justify-content: center` 会跟着内容宽偏）。
判据：探针量 `.si-mid` 中心与胶囊中心的偏差（±1px）。

## 三、③ 形变：修的是"面板先跳出来、再被窗口追上"

旧行为：窗口一次性 resize + 面板 200 宽入场 ⇒ 面板**先以胶囊宽画出来**再"啪"地跳到 400 宽。
新模型（一个任务里定下三个原点）：窗口**先**跳到展开矩形（看不见：卡片恒在 `(pad,pad)`）→
0–90ms 三段文案撤 → 90–310ms **胶囊自己**从胶囊矩形长到卡片矩形 → 宿主去掉 `data-wg-phase`：
**同一帧**里胶囊让位、面板接管（同矩形同材质 ⇒ 无缝）、内容淡入 140ms。收起是反序。

⚠️⚠️ **踩到的坑（本批最有价值的一条）**：第一版把"形变中"写成**默认**、靠 `transition-delay`
到点切终态 ⇒ **探针里什么都量不到**：`--virtual-time-budget` 下过渡**不推进**
（`getAnimations().currentTime` 恒 0，devlog/172）⇒ 面板恒 `visibility: hidden`（可命中=False）、
胶囊恒"还在场"（F1 判据红）—— 全是**尺子造成的假红**。
⇒ 改成"**形变中是例外、终态是默认值**"：**时机归宿主**（盯 `transitionend`，时长从计算样式读
`transitionTotalMs`）、**形态归 CSS**（相位下谁在场、锚在哪条边）⇒ 探针量到的就是终态。
规矩已提炼进 `docs/frontend/PROBE.md` §6.20。

## 四、顺带修掉的两个真问题

- **面板高是"换行后"的虚高**：面板挂载时视口还是折叠态小窗口，按 `innerWidth` 算出的宽是胶囊宽
  ⇒ 量到的高偏大 ⇒ 窗口开高一块。现在**先写 `--wg-card-w`、再量高**，两步在窗口侧同一任务里；
  面板的内联几何**整个删掉**（内联会盖住样式表，且组件赶不上那个顺序）——
  组件改用一个显式开关 `geometryFromHost`（`?density=widget` 在主窗口里仍走自己算的老路）。
- **收起时 `ResizeObserver` 逐帧 resize 窗口**：收起那 220ms 里 `expanded` 已是 false、
  胶囊宽正在过渡 ⇒ 加 `morphing` 闸门闭麦。另：形变任务**串行**（收起途中又点开）。

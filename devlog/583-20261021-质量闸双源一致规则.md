## 二、判据改进：双源一致才定罪

```
平台说少 + vtb 也说少        → low_coverage（真截断）
平台说少 + vtb 说够          → platform_suspect（平台的数偏大）
平台说够 + vtb 说少          → vtb_suspect（vtb 合并/错配）
只有平台可用（vtb 未收录）   → 仍以平台为准
L1 内部不自洽                → inconsistent（最高优先级，不被覆盖）
```

回填重跑后：**ok 283 · low_income 7 · no_external 16 · vtb_suspect 8 · low_coverage 3 · platform_suspect 6**
—— `low_coverage` 从 17 降到 **3**，剩下的都是双源一致判定的。

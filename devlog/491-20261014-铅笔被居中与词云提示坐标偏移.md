## 一、铅笔为什么跑到正中央：`space-between` 撞上「三个孩子」

**根因（CSS）**：`posts.css` 的 `.lc-dlg-head` 是 `justify-content: space-between`，
而头部有**三个**孩子 —— 标题组 / 铅笔 / ×。`space-between` 把**中间那个**（铅笔）推到正中央。

**为什么一直没被发现**：只有**两个**孩子时（不传 `onEditSession`，即自动场次且没有补录播入口）
`space-between` 的表现就是"标题靠左、× 靠右"，完全正常 ⇒ 它只在"有铅笔"时才现形。

**修法**：`justify-content: flex-start` + `.lc-dlg-close { margin-left: auto }` ——
即"只有关闭钮往右推"，铅笔于是紧接标题组。零 markup 改动。

## 二、词云提示为什么对不上：`position: fixed` 的包含块被抢走了

**根因（不是坐标算错）**：`.lc-dlg-cloud-tip` 是 `position: fixed`，而 **fixed 的包含块不一定是视口** ——
凡是带 `transform` / `translate` / `filter` 的祖先都会成为它的包含块。Radix 的 `DialogContent`
上挂着 `translate-x-[-50%] translate-y-[-50%]`（居中）与 `zoom-in-95` 动画 ⇒ 这个 fixed 元素
其实以**面板左上角**为原点，而代码给的是 `left/top = e.clientX/clientY`（**视口**坐标）
⇒ 整体偏一个面板原点。截图里胶囊偏到右下、偏移量恒定，正是这个形状。

**修法**：把提示 **portal 到 `document.body`**（`createPortal`，本仓已有三处先例：
`LiveCalendar` / `ImageViewer` / `StatusIsland`）。挂到 body 之后，容器怎么变换都不再影响它 ——
这比"改坐标换算"更稳：换算要跟着祖先链走，而祖先链是 Radix 管的。

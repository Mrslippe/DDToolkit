# 553-20261019-「文字超出按钮」的真因：三块浮片互相叠压

现象：右上角中间那块 `2026` 看起来**溢出到按钮外面**，压在右箭头上。

## 查法：加红框量盒子

临时给三块浮片加 `outline: 1px solid red`，再给中间那块加半透明底 —— 一眼看出：
**三块是互相重叠的**，中间那块的右半边被右箭头浮片盖住。不是文字溢出，
是**盒子被别的元素压住了**。

## 真因

`FloatPill` 是 `inline-flex` + `::before`（斜切白底，`z-index: -1`）。
三块放在 `.wb-hm-head` 这个 `display:flex; justify-content: space-between` 的窄行里，
（`h2` 标题 + 翻页组）——
浮片自身的 `flex-shrink: 0` 与我加的 `flex: none` 叠加之后，容器宽度不足以排下三块时，
它们不是换行也不是溢出，而是**相互叠压**，后画的压住前面的。

日历那边没问题，是因为它的导航行足够宽（`.lc-nav-row` 左导航右胶囊，中间没有挤）。

## 改法

中间那块**不再用 `FloatPill`**，换成普通 `<button>`，但用**同一套 token** 自绘斜切底：

```css
.wb-hm-year-btn-mid::before {
  content: ''; position: absolute; inset: 0; z-index: -1;
  background: var(--pill-bg);
  border-radius: var(--pill-radius);
  transform: skewX(var(--pill-skew));
  box-shadow: var(--pill-shadow);
}
```

盒子由 `min-width: 76px` + `padding: 0 12px` 决定，**大小可预测**；左右两个箭头仍是浮片，
视觉上是同一族。截图确认：`« 2026 »` 三块并排、互不遮挡、文字在框内。

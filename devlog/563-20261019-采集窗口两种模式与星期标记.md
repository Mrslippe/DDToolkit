# 563-20261019-采集时间窗口的两种模式 + 热力图星期标记

用户四件事（同一段话重复了三遍，按一段处理）。

## 一、左下角日期按钮 = **采集时间窗口**的边界

它原来是「滑轨区间」，语义含糊。现在明确成**采集时间窗口**，并有两种模式：

| 模式 | 触发 | 行为 |
|---|---|---|
| **默认** | 初始 / 热力图翻页 | 区间 = **热力图当前年份整年**，用**滑杆**挑窗口 |
| **手选** | 点日期按钮选一段 | 滑轨只拉这段，**窗口自动覆盖整段**（`coverTick` 触发） |

实现：

```ts
const [year, setYear] = useState(() => new Date().getFullYear())
const [pickedRange, setPickedRange] = useState<{from,to} | null>(null)
const range = pickedRange ?? { from: `${year}-01-01`, to: `${year}-12-31` }
```

- `Heatmap` 的年份**改为受控**（新增 `year` / `onYearChange`），翻页时 `onYearChange` 里
  `setPickedRange(null)` ⇒ **自动退回默认模式**；
- `RangeButton` 新增 `display`：默认模式显示「2026 整年」，手选模式显示具体区间；
- `WindowSlider` 新增 `coverTick`：值变化时 `size = total`、`start = 0`、滚回最左。
  依赖里带 `total`，所以**新数据到达后还会再覆盖一次**。

> 我按「窗口 = 该范围全部场次」实现（用户原话：时间窗口自动适应为选中的时间范围）。
> 副作用：选完日期后 25/50/75 档位会因窗口已等于全范围而高亮到最大值。

## 二、热力图右侧加 Mon / Sun

网格是 7 行（`gridTemplateRows: repeat(7, CELL)`，周一 = 第 0 行），原来没有任何行标记，
**分不清最上面还是最下面是周一**。右侧加一列 `.wb-hm-wd`，高度 = `7*CELL + 6*GAP`，
两端分别写 `Mon` / `Sun`。

# 550-20261019-修好截图探针，并按图改三处

用户："修探针然后自己截图自己改"。

## 一、探针为什么一直 401：环境变量名写错

`_shot_workbench.py` 给后端设的是 **`DDTOOLKIT_API_TOKEN`**，而后端认的是
**`DDTOOLKIT_DEV_API_TOKEN`**（`app/core/api_auth.py`；真源 `scripts/dev_token.py`）。
名字错了 ⇒ 后端**自己生成随机 token**，前端发固定值 ⇒ 401。

改对之后还要两件：
- **release 目录已空**（devlog 549）⇒ 源库退回 dev，两处都试、谁在用谁；
- **`static/` 也要复制** —— 只给库不给静态资源，档案卡的背景图与头像全部 404，
  截图里那片"空白"其实是资源缺失，**不是布局问题**。

## 二、按图改了三处（都是看图才发现的）

1. **元信息行被挤到换行**（"最近 10-11" 掉第二行）：它在 `.wb-profile-id` 里，
   而顶部一行还要放切换器 ⇒ 可用宽度只剩 ~290px。把它**移出名称块**，独占一行。
2. **档案卡下半部大片空白**：卡片被右卡拉高，内容全挤在顶部。`.wb-profile-body`
   加 `height: 100%`、`.wb-profile-cover` 加 `margin-top: auto` —— 覆盖块贴底。
3. **背景图回来后，"采集覆盖"那行压在亮部上看不清**（"2022-07-24 起"几乎消失）：
   遮罩原来只有横向渐变。加一层**纵向底部渐白**（42% 起，78% 到 .72，100% 到 .94）。

## 三、方法上的收获

前几轮我靠"读 CSS 猜视觉"，三次猜错（圆角发灰、浮窗偏移、图标被挤掉）。
这次把探针修通后，**一个模型就能自己闭环**：截图 → 看图 → 改 → 再截图验证。
三处问题全部是看图才发现的，静态读代码一个也看不出来。

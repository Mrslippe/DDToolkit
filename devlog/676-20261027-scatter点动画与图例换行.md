# 676-20261027-数据点改用 scatter；图例昵称改换行

## ① 折线上的「点」为什么不动

ECharts 的 line 系列里，`symbol` 是**线条的一部分**：线和点共享同一套动画时序
（`animationDuration` 只驱动线的描边），`animationDelay` 挂在 line 上**不会**让点依次弹出 —— 实测无效。

修法：**拆成两个系列**

```ts
series: [
  { type: 'line', showSymbol: false, animationDuration: 700, ... },      // 只画线与面积
  { type: 'scatter', symbolSize: 7, animationDuration: 500,
    animationDelay: (idx) => 700 + idx * 80, ... },                       // 专门画点，逐点弹出
]
```

scatter 的每个数据项是独立元素，`animationDelay` 对它生效。

## ② 图例第一个昵称被截、下面更长的却没有

截断是**按像素宽度**算的，不是按字符数：

- `AoineKo青` = 8 个拉丁字符 + 1 个汉字，拉丁字符宽度约为汉字的一半以上，实际像素更宽；
- `好想rua土豆啊` = 4 汉字 + 3 拉丁 + 2 汉字，像素宽度反而更小。

所以出现了"看起来更长的没被截、更短的被截"。

修法：**去掉省略号，允许换行**（`white-space: normal; overflow-wrap: anywhere`），
图例本身已有 `max-height + overflow-y`，行数多时滚动即可。

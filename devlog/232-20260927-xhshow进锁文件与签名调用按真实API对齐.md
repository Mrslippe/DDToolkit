## 二、签名调用按**真实 API** 对齐（原来是我按文档猜的）

装上后读签名（v0.2.0）：

```
sign_headers_get(uri, cookies, xsec_appid='xhs-pc-web', params=None, …) -> dict[str, str]
sign_headers_post(uri, cookies, …, payload=None, …) -> dict[str, str]
```

⇒ 两处纠正：
1. **`uri` 是 path**（不是完整 URL），参数走 **`params` 字典** ⇒ `Signer` 协议从
   "拼好的 query 串" 改成 "`uri` + `params/payload`"（拼 query 归调用方）；
2. 请求侧继续用 `urlencode(params, safe=",")` 手拼 query —— **签名的键值与发出去的 query
   必须是同一组**，且逗号不能编码（调研 §2.2 的坑）。

## 三、⚠️ 实测纠正一条文档口径：cookie 不是"只要 web_session"

这条直接影响下一步"cookie 录入入口"要收什么（否则用户粘一个 `web_session` 会永远签不出名）。

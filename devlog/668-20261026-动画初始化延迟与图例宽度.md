# 668-20261026-动画初始化延迟、图例宽度、名单滚动条、tooltip NaN

## ① 切页签动画没了

`echarts.init()` 是**同步**执行的：切页签时卡片刚插入 DOM，容器还没测量宽度（=0），
ECharts 在 0 宽容器里 init 会**跳过初始动画**（不是配置问题）。

修法：init 放到 `requestAnimationFrame` 里，等布局完成再建实例。

## ② 短昵称也被裁

`.wb-pie-legend` 只占 42%，名字列 `flex: 1 1 auto` 被数值列挤压。
修法：饼图收到 46%，图例给到 54%，名字列加 `min-width: 72px` ——
**挤的时候先压数值列，而不是截名字**。

## ③ tooltip 里「分位 NaN%」

数据点被 `map(v => [v[0], v[1]])` 砍掉了第三项（分位 p），formatter 读 `v[2]` 得到 undefined。
修法：保留三元组 `[x, y, p]`。

## ④ 名单卡片滚动条

`.wb-table-wrap { overflow-x: auto }` → `visible`（列宽已固定，不需要横向滚动）。

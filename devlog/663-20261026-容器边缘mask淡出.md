# 663-20261026-翻页时容器左右边缘降低透明度（mask，不是覆盖层）

用户给了参考图（图二）：翻页时**盛装卡片的容器**左右边缘应该变透明，
新卡片从外侧滑进来时在边缘渐显 —— 不是我上一版那种"整个视口径向压暗"。

## 改法

```css
.wb-charts.is-flipping .wb-charts-viewport {
  mask-image: linear-gradient(to right,
      transparent 0, #000 11%, #000 89%, transparent 100%);
}
```

- 用 **mask**（真透明），不是"盖一层背景色"。区别：mask 让内容真的透出后面的背景，
  新卡片在边缘是"渐显"；覆盖层只是把边缘涂成背景色，滑入过程中会显得生硬。
- 只在翻页的 340ms 内生效（`is-flipping`），静止时没有任何遮蔽，卡片边缘不受影响。
- 渐变带宽 11%（左右各）；想更强就调大到 15%，想更弱就调到 8%。

## 2. 投稿统计补全 + 标签改名

### 统计问题根因
- `video`（视频投稿，arc/search）：stats_json 键为 `play/comment`，前端认 `view` → 播放缺失；
- `video_dynamic`（投稿动态）：部分行只有动态互动（forward/like/comment），
  播放/投币/收藏/分享/弹幕缺失（数据在 raw 的 `major.archive.stat`）；键名 `reply` 未归一化。

### 修复
| 位置 | 改动 |
|------|------|
| fetcher `_normalize_stats` | play→view、reply→comment（新 helper，含测试） |
| fetcher `_archive_stats` | 投稿动态完整统计：archive.stat（view/like/coin/favorite/comment/share/danmaku）+ module_stat（forward/dyn_like/dyn_comment） |
| fetcher 动态映射 | ARCHIVE 类型动态用 `_archive_stats` 生成 stats_json（feed 与 detail 两处） |
| fetcher `fetch_bilibili_videos` | stats_json 键 `play` → `view` |
| fetcher `fetch_video_detail` | stat 键 `reply` → `comment` |
| scheduler 视频补充分支 | 详情统计与 feed 统计**合并**（forward/dyn_like 不丢） |
| 回填脚本 `scripts/repair_post_stats.py` | 已执行：3,554 条更新（video 归一化 1,895，video_dynamic 从 raw 补全 1,659） |
| 前端 | `video_dynamic` 标签改为「投稿」 |

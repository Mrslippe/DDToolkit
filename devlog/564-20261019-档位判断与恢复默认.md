# 564-20261019-档位只看总场次、禁用态补样式、恢复默认

用户四条，第 3 条是个提问。

## ① 档位能不能点：只看总时间范围内的场次数

上一轮我按「视野内能显示多少场」判断，用户纠正：**只看 `total < g`**。
于是窗口可以比视野宽（能拖、能缩放），`viewCount` 那套连同"窗口自动缩到视野大小"一起删掉。

> 这两轮的要求是反的：上一轮说"视野装不下就缩窗口"，这一轮说"档位只看总场次"。
> 以后同类需求我先问清"视野"和"总范围"哪个说了算，再动手。

## ② 禁用态**根本没有样式**

用户截图：48 场的区间里 50/75 点不了，但**外观和 25 一模一样**。

查了 CSS —— `.wb-grade` 从来没有 `:disabled` 规则。补：

```css
.wb-grade:disabled { opacity: .38; cursor: default; }
.wb-grade:disabled:hover { border-color: var(--c-border); color: var(--c-text-sub); }
```

## ③ 「恢复默认」按钮

放在日期区间选择器的**确认按钮上方**（用户指定位置）。做法：`DateRangePicker` 新增可选
`onReset` / `resetLabel`，只有调用方传了才渲染 —— **帖子页那个筛选器不受影响**。
`RangeButton` 只在手选模式下把它透传下去。

## ④ 「翻页/确认后界面重绘一次，正常吗？」

**正常**：换区间会重新拉 `/activity`（数据整个换了，不重绘才奇怪）。

但原来的实现会先 `setActivity(null)` ⇒ 整块闪成「读取直播记录…」再出内容。已去掉这一行：
**保留旧数据、拿到新的再替换**，观感从"重绘"变成"原地更新"。

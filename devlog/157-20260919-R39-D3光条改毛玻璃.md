# 157-20260919-R39-D3光条改毛玻璃：从"调数值"到"换手段"

> 用户第三轮反馈：「光条的边界还是很明显，有没有更优雅更美观的处理方式或者设计指南」。
> —— 前两轮我都在调渐变数值（线性 → 径向 → 收半径），这次先**量像素**再动手，
> 结论是"再调也治不了"，于是给方案让用户拍板：**A. 毛玻璃工具栏**（选中）。

---

## 一、量像素：边界早就不在亮度上了

用探针量到的光条矩形（`{x:802, y:40, w:354, h:59}`，设备像素比 2）去截图上取剖面：

| 边缘 | 跨边缘亮度落差 | 说明 |
|---|---|---|
| 左 | **0.0** | 无边界 |
| 右 | **0.0** | 无边界 |
| 下 | **0.8** | 可忽略 |
| 上 | 69.5 | 但那是**顶栏粉色**（亮度 183 = `#ffa2b4`）与内容区 252 的分界，不是光条的 |

也就是说：**"光条盒子"在像素上已经看不出来了**（R39-D2 收半径那一版就做到了）。
用户的截图我也逐行量了：x=700 处是 219→228 的**连续**过渡，x=1200 那些 252 的亮区是
插画里的**白百合**，最陡的横向跳变（+73 @ x=1091）是**指纹图标**的边。

## 二、那"明显"的是什么：**纹理边界**

半透明白叠加**不改变**背景的亮度轮廓（渐变已经在盒子内归零），但它**抹掉背景的局部对比**：
在光条覆盖的范围内，插画的细节被冲淡，边缘处细节"突然回来" ⇒ 眼睛读到的是
**"细节从哪开始消失"的那条线**。这是**"在照片/插画上叠白光"这个手段本身的天花板** ——
继续调 alpha/半径只能让它更淡，不会让它消失。

## 三、换手段：毛玻璃工具栏（用户拍板方案 A）

```css
.glow-bar {
  border-radius: 12px;                                  /* 与 --pcard-radius 同值 */
  background: rgba(255, 255, 255, 0.10);                 /* 极轻，只提亮一点点 */
  box-shadow: inset 0 0 0 1px rgba(255, 255, 255, 0.22); /* 玻璃的边 = 内描边 */
  backdrop-filter: blur(6px) saturate(1.08);             /* 让背景**变糊**而不是**变白** */
}
```

关键差别：`backdrop-filter` 是**柔化背景**（局部对比仍在，只是变糊），而不是**覆盖一层白**
（局部对比被抹平）⇒ 没有"细节消失的边界"可读。同时矩形有了**明确的形状**（12px 圆角 + 内描边）
—— 边界被理解为"一块工具栏"就不刺眼。**不加外阴影**：外阴影会在背景图上再投一条线。

## 四、设计指南（已落 `docs/UI-MAP.md`）

1. **光的边界只能由衰减决定，不能由盒子决定** —— 渐变/遮罩在元素边界必须已归零；
   `radial-gradient` 的百分比是相对**整个盒子**的（72% × 354 = 255px > 半宽 177px ⇒
   边缘还剩 16% 的白），要"在盒子内归零"必须 ≤50%。
2. **亮度连续 ≠ 看不见** —— 半透明白抹的是**局部对比**，眼睛读**纹理边界**。
3. **两种正解，别停在中间态**：让形状**明确**（毛玻璃/实底 + 圆角 + 内描边）或让形状**消失**
   （只在当前项后面留一团柔光）。
4. **图标压在不可预测的图上必须自带对比保护**。
5. **外阴影一律不要**（会在图上再投一条线），玻璃的边只用内描边。
6. 圆角取 12px（全仓"贴纸卡那一族"的口径）。

## 五、护栏（口径变了，断言跟着变）

R39-D2 那批的判据（"必须是径向渐变 + 半径 ≤100% + 末端归零"）**整套替换**成毛玻璃口径：

| 新判据 | 拦的是什么 |
|---|---|
| `backdrop-filter` 含 `blur` | 退回"纯半透明白叠加"（就是这次要修的那个手段） |
| 底色 alpha ≤ 0.2 | 毛玻璃靠 blur 起作用，底色太白就变回"白板" |
| 圆角 ≥ 8px | 工具栏要有明确形状（圆角是"这是一块面板"的主要信号） |
| `box-shadow` 非 none 时**必须含 inset** | 外阴影会在背景图上再投一条线 |

反向验证：把 CSS 改回 `radial-gradient` 那版 ⇒ 四条全红；换回毛玻璃 ⇒ 归零。

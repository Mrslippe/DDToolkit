# 443-20261007-让位深浅的旋钮没接线（另附单推调参地图）

用户问「启动单推模式的动画节奏和时长在哪调」。回答时顺手核对了一遍那几颗旋钮，
发现**其中一颗是死的**。

## `--solo-dim` 只在 `:root` 里躺着，没有任何规则引用

```css
/* layout.css :root */
--solo-dim: 0;         /* 注释写着"让位后页面元素的不透明度" */
```
```css
/* posts.css 让位那条（改前） */
opacity: 0 !important;   /* ← 写死的，跟旋钮无关 */
```

⇒ 有人（包括我）去调 `--solo-dim` 会**毫无变化**，而且症状是"改了没反应"这种最难查的形态。
改成 `opacity: var(--solo-dim) !important` —— 与同一条里的 `--solo-hide-shift` / `--solo-hide-ms`
一样接线（那两颗一直是有接线的，所以从没暴露这个问题）。

**判据**：★「淡出的**深浅**是旋钮」—— 断言让位那条写的是 `var(--solo-dim)`（不是字面 0），
**并配**"旋钮有定义"（`:root` 里 `--solo-dim: <数>`）；一条管**接线**、一条管**存在**，
缺哪条都还能悄悄退化（只断言定义 ⇒ 又变成死旋钮；只断言接线 ⇒ 定义被删就静默失效）。
**反向验证**（两组，都杀死了）：把 `opacity` 写回字面 `0` ⇒ 那条红；
删掉 `:root` 里的 `--solo-dim` ⇒ 那条红。

⚠️ 改这条判据时**必须同时改掉旧断言** —— 旧的两条断言正是 `/opacity:\s*0/` 与
`/opacity:\s*0\s*!important/`：**测试把旋钮锁死了**（它们盯着字面值，接线反而会让它们红）。
"测试保护了 bug"不是罕见情况：断言字面值时，问一句 **"这个字面值是不是某颗旋钮的替身？"**

## 顺带删掉一条过期注释

`posts.css` 单推块开头还写着"唤出时用 `~` 兄弟选择器把两个变量拨回原值 —— 那两条贴边窄带…"
—— 窄带在 `devlog/433` 就撤掉了，`~` 规则一条不剩。留着会让人去调一个**不存在的机制**。
改成"只有 `data-idle` 一个键"＋点名三颗旋钮住在 `layout.css: :root`。

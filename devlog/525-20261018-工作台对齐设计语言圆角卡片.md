# 525-20261018-工作台对齐设计语言：圆角卡片

用户：「对齐项目的总体设计语言，以圆角卡片作为主要展示形式」。

## 一、只复用、不新造

卡片直接走 `tokens.css` 的**档案卡族**（`--pcard-*`）：12px 圆角 + 双层柔和阴影 +
顶部高光内描边 + 发丝级边框，白卡浮在近白页面上。按钮一律 `FloatPill`（全站唯一交互层元件），
输入框用内圆角 `--pcard-radius-inner` 与 `--focus-ring-inset`。**没有新增任何视觉变量。**

结构：页头 → 卡 1「采集设置」（表单 + 预估读数 + 进度条）→ 卡 2「粉丝名单」（表格）→ 页脚口径。

## 二、★ 真浏览器截图逼出来的三个问题

只用测试是不够的 —— 我用仓库现成的 Edge 无头 + `_copy_db_online` + `DDTOOLKIT_FAN_DATA_DIR`
（指向 `datasets/fan-structure`，**不复制 679 MB**）截了 1280 / 980 两档真图，看出：

1. **副标题被推到最右**（`justify-content: space-between`）⇒ 读成"两件不相干的东西"。
   改成标题下方左对齐。
2. **窄窗下「结束日期」和按钮挤在同一行** ⇒ 看着像按钮属于那个日期字段。改成三列网格
   （第 4 列是按钮，宽窗同行），视口 < 1100px 退成单列。
3. **标签一多就撑成 2~3 行** ⇒ 行高参差、扫不动。改成**每行最多 3 枚 + `+N`**。

第 3 条是截图才看得出来的：测试里标签是个数组，渲染几行都不会红。

## 三、两处刻意的克制

- **表头不做 sticky**：卡片不是独立滚动容器，`top: 0` 会贴到页面顶部而不是卡片里。
- **不做负边距出血**：出血要 `overflow: hidden`，而它会把 sticky 掐死。改让单元格左右内边距
  与卡片内边距对齐（20px），视觉同样"齐"。

另加 `prefers-reduced-motion` 关掉进度条过渡；进度条带 `role="progressbar"` +
`aria-live="polite"`（状态变化能让读屏播报）；错误不只靠颜色（前缀「⚠」）。

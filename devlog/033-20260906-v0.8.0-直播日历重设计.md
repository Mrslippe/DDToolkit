# 033-20260906-v0.8.0-直播日历重设计（照参考图周行列表）

## 背景（用户 2026-09-06）

用户提供参考图（日历订阅类产品截图）：深色卡、顶部统计行
「共 938 场。杂谈 41、游戏 334、观影 284、投稿 120、歌回 16、健身 32、
电台 68、联动 14、特殊 29」、**周行列表**（每行一周 7 格，最新在上、
向下看历史）、格子 = 日期+星期 / 类型彩签+时间 / 标题、无场次日「休息」、
当前周/今天高亮。要求：直播日历设计完全参照该卡片，配色参考该图。
用户决策（询问后）：① 周行列表（照参考图）；② **卡片保持浅色，只换标签配色**；
③ 类型对齐 9 类；④ 格子最多 2 条 + 点击浮层看全部。

## 改动

### liveType.ts：9 类体系
- 原 6 类（game/chat/song/radio/anniv/live）→ 新 9 类：
  `chat 杂谈 / game 游戏 / watch 观影 / upload 投稿 / song 歌回 /
  fitness 健身 / radio 电台 / collab 联动 / special 特殊` + `live 直播` 兜底；
- 优先序：特殊（生日/周年/出道/庆典/新春/圣诞/跨年/新年）→ 歌回 → 观影 →
  联动 → 健身 → 电台 → 杂谈 → 游戏 → 投稿；`LIVE_TYPE_ORDER` 导出统计行顺序。

### LiveCalendar.tsx：月网格 → 周行列表
- 头部：◀「最近周」▶（anchor 偏移，0=当前周，可翻 12 周；回锚清浮层）；
- 统计行：`共 N 场。` + 9 类彩色计数（`inferLiveType` 全量统计，>0 才显示）；
- 周行：`currentMonday`（周一开）→ 向下最多 6 行/12 周，空周早于数据起点停止；
- 格子：`26/09/06 周六`（日期+星期）/ `[彩签] 8 PM` + 单行标题（最多 2 条 +N 场）/
  无数据「休息」（居中灰字）/ 礼物日保留金额角标；今天绿描边（`box-shadow 0 0 0 1px`）；
  点击格子 → 浮层（全量场次/起止/时长/礼物，弹窗层规格 12px 圆角）；
- 时间格式照参考图 = `8 PM`（12 小时制英文）。

### posts.css
- `.live-calendar-weeks`（周行容器）+ `.live-calendar-week`（7 列 grid，行距 4px）
  + `.live-calendar-rest`（休息）+ `.live-calendar-cell.today`（绿描边）；
- 9 色类型标签（对齐参考图感知色）：杂谈橙 `#e8842e` / 游戏绿 `#3aa76d` /
  观影蓝 `#4a90e2` / 投稿紫红 `#b85fce` / 歌回红 `#d8645e` / 健身黄 `#d8b13e` /
  电台紫 `#8b6fd8` / 联动青 `#2fa5ad` / 特殊=红描边浅红底；
- 删除旧 `.live-calendar-grid` / `.live-calendar-title` / `.live-type--anniv`；
- 卡片本体保持浅色（`--c-bg-card` / `--c-bg-page`），格内数据日 `--c-bg-card` 底。

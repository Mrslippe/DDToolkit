# 700-20261028-对比页 · 帖子评论模式（P4 前端）

## 交互（一段式）

```
粘贴链接 → 开始抓取 → 轮询（顺带显示解析出的 UP / 标题 / 评论总数）
        → 完成 → 自动取名单 + 与当前主播名单做重叠 → 结果区
```

为什么不做"先解析、再确认、再抓"两步：后端在 `resolve` 阶段就拿到标题，**轮询第一帧就能显示**，
分两步只多一次请求与一个状态机。抓错帖子按「取消」重来即可。

## 面板

| 区域 | 内容 |
|---|---|
| 输入卡 | 链接/BV 输入 + 「含楼中楼」开关 + 开始/取消 |
| 进度 | `正在抓评论 · 第 3/12 页 · 已抓 60 条 / 共 12438 条（0%）` + 进度条；完成后显示标题与「部分数据」标记 |
| KPI | 共享人数 / Jaccard / lift / 上尾 p |
| 判定 | 显著富集 / 显著贫化 / 不显著（读数是人话，不是原始数字） |
| Top-N 覆盖 | 前 10/25/50/100/200/500/1000 的命中率条形 |
| 分层命中 | 核心/次核心/外层 × 命中/未命中 |
| 交集名单 | 前 50 行 + 「导出 CSV」（带 BOM） |

失败**不静默**：错误条直接显示后端给的原因（未登录 / 视频不存在 / 风控）。

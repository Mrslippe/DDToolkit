# 226-20260927-R50b通知默认值与测试通知改用真主播动态

用户口径（2026-09-27，三条）：

1. 「不透明度默认 90%」；
2. 「弹窗**字号**范围扩大到 300%、默认 150%」；
3. 「测试通知修改为**固定发送明前奶绿的最新动态**」。

前两条是改参数，第三条是换取材 —— 但第三条牵出一个必须一起做的技术点（§三）。

## 一、默认值/范围：三处必须同步改

| 位置 | 原来 | 现在 |
|---|---|---|
| `config.py` 类属性（默认值兜底） | 字号 120% / 不透明 91% | **150%** / **90%** |
| `runtime_settings.SPECS`（界面范围与默认） | 字号 `80~200` | **`80~300`** |
| `desktop_popup.popup_scale()` 的夹取 | `min(2.0, …)` | **`min(3.0, …)`** |

⚠️ 第三条最容易漏，而且**漏了不会红**：界面允许拉到 300%、绘制层却按 200% 封顶 ⇒
"250% 以上没变化"。这正是本仓反复强调的那类**静默不算数**（判据见
`tests/test_desktop_popup.py::test_font_scale_enlarges_text_geometry_but_not_width`：
现在 `400` 才该被后端拒、`500` 落到绘制层要夹成 `3.0`）。

不透明度同样是"界面百分数 → 绘制层 0~255"的换算（`90% → 230`），换算只在
`popup_alpha()` 一处做。

## 二、测试通知改成「明前奶绿的最新动态」

原来的通用文案（"DDtoolkit 测试通知｜点击打开示例链接"）**验不出真实观感**：
没有头像、标题太短（验不出折行）、点进去是示例站（验不出"点一下能不能到那条帖子"）。

新取材（`routers/settings.py::latest_post_of`）：

- 精确匹配 `vtubers.name == "明前奶绿"`，没有再模糊匹配（用户把名字写全一点也能命中）；
- 账号优先主平台（bilibili），同平台按 id 稳定排序；
- 帖子取**她最新的一条内容**（`published_at` 倒序、空值排最后、`id` 兜底）——
  **刻意不按类型挑**：实测她库里是「图文 23 条 / 转发 1 条」、**一条 `type='dynamic'` 都没有**
  （B 站把带图的动态建成 `image`、纯文字才是 `dynamic`），按 `type='dynamic'` 挑反而会挑到
  更旧的一条。拿到的是哪一类写在 `source` 里（"明前奶绿 的最新动态（图文）"），用户一眼能看出；
- 排序 `published_at` 倒序、空值排最后（`is_(None)` 前缀 + `id` 兜底 = 不依赖 SQLite 的
  `NULLS LAST` 也能稳定）。

一次点击同时验完四件事：**头像**（真实主播头像）/ **折行**（真实标题长度）/ **可点**
（真实 permalink）/ **深处正确**（点开就是那条帖子）。接口顺带回 `url` 与 `source`
（"明前奶绿 的最新动态（图文）"），界面把 `source` 原样显示出来 ——
用户才知道看到的是不是对的。

**兜底**（用户第二次修订口径："无论库里有没有明前奶绿动态，都默认调取明前奶绿最新动态，
不再调用通用文案"）：库里没有她、或她一条帖子都没有 → 用**最小卡片**
（标题仍是「明前奶绿 更新了动态」、正文只剩"1 条新内容"，走**同一个 composer**）。
既不编造内容，也不会让用户看到"另一种完全不同的通知长相"。按钮仍然会弹。

界面侧同步删减（用户口径：「发一条测试通知下面的话全部删除，只保留发出的状态」）：
按钮下面只留一行状态 —— 成功是 `已发出：{标题}`，失败是 `没发出去：{原因}`；
原来那段解释（取材 / 开关关系 / 兜底说明）整段删掉。

## 三、顺带修：大字号下的头像分辨率

卡片左上角的图标按 `_px(30) = 30 × DPI × 字号` 绘制 —— 字号上限放到 300% 后需要 **135px**
的位图，而 `notifier._icon_base_size()` 只按 DPI 取（150% 屏上 48px）：
**把 48px 拉大到 135px，头像糊成一团**（用户此前专门反馈过"图标分辨率有点低"，同一类问题）。

改成 `32 × DPI × 字号缩放`：源图是下载下来的头像原图（通常几百像素），
按目标尺寸重新栅格化是**有信息量**的，不是放大插值。（判据：
`tests/test_notifier.py::test_icon_size_follows_font_scale`。）

## 四、判据

| 用例 | 钉什么 |
|---|---|
| `test_test_notification_sends_the_demo_vtuber_latest_dynamic` | 标题/正文/**点击目标**/来源都来自那条真帖子 |
| `test_test_notification_prefers_dynamic_over_newer_video` | "最新**动态**"优先于更晚的投稿 |
| `test_test_notification_falls_back_when_the_vtuber_is_absent` | 数据缺失时退回通用文案且**仍然弹** |
| `test_test_notification_can_be_clicked_repeatedly` | 连点两次真的投递两次（一次性去重键） |
| `test_icon_size_follows_font_scale` | 图标尺寸跟着字号走 |
| 设置台账（`test_runtime_settings.py`） | 默认值改成 150 / 90，范围上限 300 |

## 五、没做的

- 「测试通知发谁」**没有做成设置项**：用户口径是"固定明前奶绿"，多一个下拉框就多一处
  需要解释的东西；哪天想换成"当前选中的那个 V"，再从这里改一行取值即可。

# 657-20261026-轮播再修：单侧悬停、页码内嵌、阴影留白、动画改实例重建

## ① 箭头透明度不一致

原来 `is-visible` 是**整个容器**的开关：任一侧悬停或 flash 期间，两侧箭头一起亮。
改成三态 class：`is-left` / `is-right` / `is-flash` —— **只亮对应的那一侧**；
容器 `onMouseLeave` 统一复位，鼠标移开就全隐藏。

## ② 页码压到发丝线

`top: -20px` 正好落在页签下方的分隔线上。改到**行内右下角**（`bottom: 2px; right: 6px`），
并给一个浅色胶囊底，避免和内容粘连。

## ③ 翻页失效

两种原因并存：

1. **只有一页时箭头仍然显示**（点了没反应，像坏了）→ 现在 `pages.length > 1` 才渲染箭头；
2. 窄带 `left: -22px` 有一半被 viewport 盖住，鼠标进不去 → 窄带 `z-index: 9`，
   叠在卡片之上；viewport 的 `overflow: hidden` 只影响绘制，不影响命中测试。

## ④ 左右阴影被裁

viewport 的内边距从 `14px 6px` 加到 **`16px 22px`**，负 margin 同步 ——
左右各留 22px 给卡片阴影，内层内容宽度不变。

## ⑤ 数据动画仍然不播 → 改成"实例重建"

`clear()` + `setOption()` 实测**不会重播**初始动画（ECharts 的初始动画只在实例创建时走一次）。
改为：`run` 变化时 `dispose()` + `echarts.init()` 重建实例 —— 这是唯一保证"从 0 生长 / 旋转填充"的方式。

同时按要求**去掉 CSS 淡入**（`is-anim` 与 `key={anim}` 一并删除）。

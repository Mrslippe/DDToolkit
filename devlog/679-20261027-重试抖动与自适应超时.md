# 679-20261027-采集成功率：重试加抖动 + 超时自适应

P1 剩余两项。

## ① 重试：指数退避 + ±30% 抖动 + 状态分类

原来是 `sleep(0.8 * i)` —— **线性、无抖动**。问题在于并发 3 个任务遇到同一波 504 时，
三者会在同一时刻一起醒来、一起重试，把压力重新叠在同一个瞬间。

现在：

```python
def _retry_delay(attempt, base=0.8, cap=20, jitter=0.3):
    d = min(cap, base * 2 ** (attempt - 1))
    return d * (1 + random.uniform(-jitter, jitter))
```

实测（1..4 次）：`1.0 / 1.65 / 3.51 / 7.24` 秒，且每次不同。

另外**按状态码分类**：4xx 里只有 `408`（超时）与 `429`（限流）值得重试，
`404/403` 直接放弃 —— 以前会白等 3 轮。

## ② 超时：按记录数自适应

实测 15 万条的场次用固定 120s 会被腰斩。翻页请求改为：

```python
timeout = min(600, max(120, total / 1000 * 3))
```

| 记录数 | 超时 |
|---|---|
| ≤ 4 万 | 120 s（保底） |
| 5 万 | 150 s |
| 15 万 | 450 s |
| ≥ 20 万 | 600 s（上限） |

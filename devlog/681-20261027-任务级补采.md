# 681-20261027-任务级补采：整轮跑完再救一次长尾

P3 的第一项（B5）。

## 为什么不在"当场"多试几次

`_get_json` 已有 3 次重试（指数退避 + 抖动）。但上游 504 常常是**分钟级**抖动：
当场连试 3 次都落在同一个抖动窗口里，之后就永久放弃了。

整轮跑完再补采，等于**把重试窗口拉长到几分钟**，且不拖慢其他场次。

## 实现

```python
await asyncio.gather(*(one(s) for s in sessions))

# 补采：只针对 sessions_detail 里 state == "failed" 的场次，最多一轮
retry = [s for s in sessions if 该场失败]
for s in retry:
    p.failed -= 1                      # 回滚计数，避免重复计
    p.failures = [f for f in p.failures if f.live_id != s.live_id]
    _mark(p, s.live_id, "running", 0, "")
await asyncio.gather(*(one(s) for s in retry))
```

要点：

- **只补一轮**（再失败就真的失败），避免最坏情况无限延长；
- 补采前**回滚 `failed` 计数与 `failures`**，保证最终统计正确；
- 用户取消（`should_stop`）时不补采；
- 补采异常只记日志，不影响已完成的部分。

# 643-20261025-出席明细浮层 hover 不出来：被单元格裁掉了

用户：hover 没反应；另外 75 场只看到 40 格。

## 第二个不是 bug

40 格 = **2 行 × 20 列**，这是上一轮定的默认展示（场次多时靠 hover 看全）。

## 第一个是真 bug：浮层被裁

浮层用的是 `position: absolute`，挂在 `<td>` 里。而：

- `.wb-table-ranked.is-fixed td { overflow: hidden }`（固定列宽的必要设置）
- 外面还有 `.wb-table-wrap { overflow-x: auto }`

两层裁剪叠在一起，浮层**一点都露不出来** —— 看起来就是"hover 没反应"。

## 修法

浮层改用 **`createPortal` 挂到 `document.body`**，并用 `position: fixed`：
hover 时取方块区的 `getBoundingClientRect()`，把浮层定位到它下方 8px。

顺带：浮层自身也加了 `onMouseEnter`（取消收起）+ `onMouseLeave`（收起），
所以鼠标从方块移进浮层不会闪掉。

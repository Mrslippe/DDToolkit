# 032-20260906-v0.7.0-档案视图细化（重要日期卡 + 直播日历改造 + 布局改版 + 档案卡独立视图 + 粉丝趋势增强）

## 背景（P7，用户 2026-09-06 需求 + 参考图）

1. **重要日期卡**：vtuber 的纪念日和近期大型活动日期，显示「是什么、什么时候、还剩多少天」；
2. **直播日历改造**：一个时间格内显示直播类型、直播标题、场次时间等；
3. **布局改版**：参考用户图——上行「重要日期（窄）+ 直播日历（宽）」双列，趋势全宽在下；
4. **追加① 档案卡移出**：移走到另外新建的视图，专门展示 vtuber 详细设定相关信息；
5. **追加② 粉丝趋势增强**：时间轴缩略图+缩放、每日增减柱状图、灵活操作与动画。

## 数据面调研（实查 dev 库）

| 项 | 实况 | 结论 |
|---|---|---|
| `vtubers.birthday` / `debut_date` | 字段在（MM-DD / YYYY-MM-DD）但**全部为空** | 卡内提供行内编辑入口（`PUT /vtuber/{id}` 本来支持）；生日按 MM-DD 年循环、出道日按 N 周年展示 |
| 手动活动 | 无表无 API | 新表 `vtuber_events`（迁移 `e005`）+ CRUD 端点 |
| 自动预约帖 | 432 条 reservation 帖；`body_json.reservation` 只有 desc1（如 `08-21 20:00 直播`）、**无结构化日期**、大部分无 title；`raw_json` 有 `modules.module_dynamic.additional.reserve.title`（`直播预约\|xxx`） | `_extract_reservation` 增强输出 title/rid；读取端点回退 raw_json；desc1 需正则解析（全日期 / MM-DD / 今天 / 明天四种格式，年份按发布日期推断） |
| 场次标题 | 快照表 `live_title` 覆盖 100%（111/111） | 场次推导直接带出，零迁移 |
| 直播类型 | 无结构化分区数据 | 用户定案：`utils/liveType.ts` 按标题关键词推断（庆典/歌回/电台/杂谈/游戏/直播） |

## 后端

- **迁移 `e005_vtuber_events`**：`vtuber_events`（vtuber_id FK / title / event_date "YYYY-MM-DD" / created_at），`ix_vtuber_events_vtuber_date` 索引；`MIGRATION_HEAD = "e005"`；
- **`_extract_reservation` 增强**：输出加 `title`（活动名，raw 形如 `直播预约|xxx`）、`rid`；新抓帖即含，旧帖由读取端回退；
- **`VtuberEventRepo`**（repositories/vtuber_repo.py）：
  - 手动条目 `list_by_vtuber`（日期升序）/ `create` / `delete`；
  - `future_reservations`：按 V 账号组扫 reservation 帖 → `button_text=已结束` 剔除 → `_parse_reservation_start` 解析 desc1（`YYYY-MM-DD HH:mm` / `MM-DD HH:mm` 年份按发布日推断、早于发布日则次年 / `今天` / `明天`）→ `start_at` 在 `[now, now+90天]` 筛出 → title 降级链：reservation.title → raw_json reserve.title（去 `直播预约|` 前缀）→ desc1 原文 → `直播预约`；按 start_at 升序；
- **`live_sessions` 带标题**：查询追加 `live_title`，场次内最后一条非空标题为场次标题（中途改标题取新值）；`LiveSessionOut` 加 `live_title`；
- **路由**：`GET/POST /vtuber/{id}/events`、`DELETE /vtuber/event/{event_id}`、`GET /vtuber/{id}/future-reservations?days=90`；
- **`VERSION = "0.7.0"`**；pytest 新增 `tests/test_vtuber_events.py` 11 用例（CRUD / 四种 desc1 格式 / 已结束&已过&超窗过滤 / title 三级降级 / 场次标题携带），全量 **163 passed**。

## 前端

- **`utils/liveType.ts`**：标题关键词 → 类型徽章（庆典/歌回/电台/杂谈/游戏/直播），优先序即规则序，未命中默认「直播」；
- **`UpcomingEventsCard`**（重要日期卡，vtuber 级、不挂账号切换器）：
  - 纪念日：生日（MM-DD）/ 出道日（YYYY-MM-DD）按下一发生日年循环；出道展示「N 周年」；行内编辑面板（保存走 `updateVtuber`，支持 birthday/debut_date）；
  - 手动活动：行内添加（名称+日期）→ `POST events`，删除 → `DELETE event`；过期的活动自动隐藏；
  - 自动预约：`GET future-reservations` 渲染，只读，带「N 人已约」；
  - 行格式统一：图标+标题 / 日期描述 / **剩余天数胶囊**（≤3 天警示色）——「是什么、什么时候、还剩多少天」；
- **`LiveCalendar` 改造**：
  - 格内：日号 + 场次条目 `[类型徽章] HH:mm 单行标题`（最多 2 条，超出 `+N 场`），礼物日保留粉底 + 金额徽标；
  - 点击有数据的格子 → `live-day-pop` 浮层（弹窗层规格 12px 圆角+柔和阴影）：当日全量场次（类型/标题/起止/时长）+ 礼物聚合行；
  - 空月格样式不变；翻月关闭浮层；
- **ArchiveView 布局**：新 `.archive-grid-top` 双列（`minmax(240px,4fr) | minmax(0,7fr)`，<900px 单列）；排序：重要日期+直播日历 → 粉丝趋势全宽；
- **追加① 档案卡独立视图（`profile`）**：
  - 新 `ProfileView`（第五个视图钮 `Fingerprint`，状态机 `AppView = 'cards'|'list'|'archive'|'profile'`）：
    档案卡（同 ProfileCard，自治账号切换）+ 账号一览卡（全部账号：平台标/昵称/粉丝/房间号/直播中）；
  - ArchiveView 移除 ProfileSection（不再 import ProfileCard）。
- **追加② 粉丝趋势增强（`FanTrendChart` 重写）**：
  - 模式分段切换（趋势 / 每日增减）——切换重置缩放、不残留选区；
  - 趋势模式：原双序列不变；每日增减：按天聚合 diff 柱状图（正增主粉 / 负增警示色，逐柱 `<Cell>` 着色）；
  - 时间轴缩略图：recharts `<Brush>`（底部缩略条 + 拖拽选区缩放主图）+「重置缩放」按钮（bump key 重挂）；
  - 动画：折线/柱状入场 400ms（原 isAnimationActive=false → 开启动画）。
- `api.ts` / `types.ts` 同步新端点与类型；`UpdateVtuber` 参数扩展 birthday/debut_date。

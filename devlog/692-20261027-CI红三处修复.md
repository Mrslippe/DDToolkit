# 692-20261027-CI 变红的三处修复

## ① 后端（py3.12/3.14）：`NameError: name 'VodAltOut' is not defined`

`app/schemas/vtuber.py` 里 `alternates: list[VodAltOut] = []` 出现在 `class VodAltOut` **之前** ——
前向引用。本地 Python 3.14 有 PEP 649（注解惰性求值）所以不报错，**CI 的 3.12 会直接 NameError**，
而且是在 import 阶段炸，导致**全部测试收集失败**。

修法：文件首行加 `from __future__ import annotations`（3.12 也走惰性注解）。

## ② 前端 eslint（`--max-warnings 0`）：两处 hooks 依赖告警

| 文件 | 告警 | 处理 |
|---|---|---|
| `ResultCharts.tsx` | useEffect 缺 `option` | 该 effect **只应在挂载时跑**（后续靠 `dataStamp` 重建），加 `eslint-disable-next-line` 并写明理由 |
| `WindowSlider.tsx` | useEffect 缺 `scale/size/stateKey` | 滚动监听里读它们只是为了**顺带记住视野位置**，放进依赖会反复重挂监听；同样豁免并注释 |

> 关键教训：第一次把豁免注释加在了**另一个 effect** 上（归位 effect），lint 仍然红。
> 加豁免要对着 `eslint` 报的行号，不是凭印象。

## ③ 门禁

`scripts/docs_gate.py` → `[ok] 无 FAIL`；前端 1,584 passed；后端点测 39 passed；`import app.routers.vtuber` 正常。

## 教训

**CI 用的 Python 版本与本地不一致时，前向引用会在 import 阶段炸掉整个测试收集** ——
报错信息看起来与本次改动无关，其实是"从来没在 3.12 上跑过"。新文件默认加
`from __future__ import annotations` 是低成本防御。

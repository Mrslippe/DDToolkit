# 608-20261024-名单搜索 + 标签胶囊 + 成员详情

用户三条：标题行右侧搜索框（uid/昵称模糊 + 下拉）、标签改彩色胶囊不换行、点用户看详情。

## 一、后端新增两个接口

| 接口 | 说明 |
|---|---|
| `GET /fan/{v}/search?q=` | 在**当前窗口池内**按 uid / 昵称模糊搜，返回 ≤20 条（含 type、strength、头像） |
| `GET /fan/{v}/member/{uid}` | 单用户全部明细：出席/弹幕/去重/付费/礼物/舰长/SC、三轴分位、标签、独轮车，以及**逐场序列**（m/p/e/uniq） |

细节：
- 搜索**只搜池内**（被分流走的人不在名单里，搜到也没法看详情）；
- 详情拒绝非池内 uid（404），逐场序列从 raw 读取，按窗口顺序返回。

## 二、前端三件事

1. **搜索框**：`MemberSearch` —— 250ms 防抖、下拉 8 条、点外部关闭；命中项显示头像/昵称/类型/强度；
2. **标签胶囊**：`TagPills` —— 按标签字符串哈希取色（同标签永远同色）、单行不换行、
   超过 3 个收进「+N」，CSS `:hover` / `:focus-within` / 点开展开（不引 Popover 依赖）；
3. **详情抽屉**：`MemberDrawer` —— 右侧滑入、Esc 关闭，展示总量、三轴分位、标签、
   以及两张 SVG 迷你柱图（逐场弹幕数、逐场付费）。

## 三、踩到的两条护栏

- `avatarRender.test.ts` 要求裸 `<img>` 必须在白名单：新增的 `MemberSearch` / `MemberDrawer`
  头像同走本地代理（`resolveAsset`），已按规则补白名单并写理由；
- 测试里给受控 input 赋值必须走 `HTMLInputElement.prototype` 的 setter，否则 React 收不到 onChange。

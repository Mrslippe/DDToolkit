# 664-20261026-边缘淡出从"开关"改为连续曲线

用户：渐变的出现/消失太突兀。

## 原因

`mask-image` 的**渐变停靠点不可过渡**（CSS 不插值 `mask-image`），
所以上一版是 `is-flipping` 一切换，边缘立刻从"完全遮"跳到"遮 11%" —— 观感就是闪一下。

## 修法：把"宽度"变成可动画的自定义属性

```css
@property --wb-fade { syntax: '<percentage>'; initial-value: 0%; inherits: false; }

.wb-charts-viewport {
  --wb-fade: 0%;
  mask-image: linear-gradient(to right,
      transparent 0, #000 var(--wb-fade),
      #000 calc(100% - var(--wb-fade)), transparent 100%);
  transition: --wb-fade 300ms cubic-bezier(0.22, 0.61, 0.36, 1);
}
.wb-charts.is-flipping .wb-charts-viewport { --wb-fade: 11%; }
```

- `@property` 声明类型后，`--wb-fade` 才会被**插值**（否则自定义属性是字符串，过渡无效）；
- 静止时 `--wb-fade: 0%` ⇒ 渐变退化为"透明 0 → 不透明 0"，等于没有遮罩，
  卡片边缘不受影响；
- 翻页时宽度从 0% **连续**长到 11%，结束后再连续收回 —— 没有跳变。

## 兼容性

`@property` 需要 Chromium 85+ / WebView2，本项目桌面端满足；不支持时退化为"无过渡"（仍能显示遮罩）。

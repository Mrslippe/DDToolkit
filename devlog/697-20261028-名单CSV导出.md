# 697-20261028-名单 CSV 导出（P1）

用户定案：**走后端导出**（口径与页面一致）。这是「对比分析」三个需求里的第一件。

## 后端

`GET /fan/{vtuber}/ranked.csv?by=&window=&since=&until=&ids=&tags=`

- 内部**直接复用 `ranked()`**（同一个 `_compute`、同一套排序/标签过滤/`ids` 窗口），
  只是把 `limit` 拉到 `MAX_LIMIT`（5000）——前端只有分页加载的 20 行，后端能给全量；
- **UTF-8 BOM + CRLF**：Excel 双击不乱码；
- 文件名 `{主播短名}-{YYYYMMDD}-{页签}.csv`，用 RFC 5987 `filename*=UTF-8''…`（中文名不炸）；
- 列序**固定**并抽成 `CSV_COLUMNS`，纯函数 `ranked_csv_bytes()` 便于无数据集测试。

| 列 | 说明 |
|---|---|
| 排名 / uid / 昵称 / 强度 | uid 是跨表 join 的唯一键 |
| 出勤分位 / 互动分位 / 付费分位 | 三位小数 |
| 出勤场次 / 出席率 / 弹幕数 / 去重弹幕 | |
| 付费金额 / 舰长 / SC / 礼物 | 三路金额 |
| 类型 / 标签 | 标签用 `;` 分隔 |

## 前端

- `api.fanRankedCsv()`：因为要带 `X-DDToolkit-Token`，**不能用 `<a href>`**，走 `fetch → Blob → a.download`；
  文件名从 `Content-Disposition` 的 `filename*=UTF-8''` 里取（回退到 `{name}.csv`）；
- 按钮放在**标签筛选右侧**（`wb-btn-ghost` + 下载图标），导出中禁用并显示"导出中…"；
- 失败**不静默**：工具条下方出现「导出失败：…」的 `role=alert`。

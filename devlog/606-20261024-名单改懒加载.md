# 606-20261024-名单卡片改懒加载，容器向下自然展开

用户要求：名单卡片换成懒加载，卡片容器自动向下展开（不再"上一页/下一页"）。

## 一、做法

- 首屏仍取 20 条；
- 列表底部放一个哨兵，`IntersectionObserver`（`rootMargin: 160px`）进入视口就追加下一页；
- 同时保留「加载更多」按钮 —— 没有 `IntersectionObserver` 时兜底，也方便自动化测试点击；
- 行**累积**在页面状态里（`rows`），切页签时清空并从头拉；
- 面板 `key` 从 `${tab}-${offset}` 改成 `${tab}` —— 否则每次追加都会重播一次淡入动画。

## 二、副作用处理

- 追加时 `busy=true`，但结果区不再被进度块替换（604 那条已修：`busy && !ranked` 才显示进度块），
  所以滚动位置不会被顶回去；
- 头部读数从"第 x–y 人"改成「已加载 N / 全池 M 人」，因为不再有页的概念。

## 三、踩到仓库的护栏

`avatarRender.test.ts` 有一条守卫：**裸 `<img>` 只许出现在白名单里**（远程图必须用 `ProxyImage`）。
名单头像是本地代理（`/fan/avatar/<uid>`，后端缓存、非远程），且需要自定义"失败 → 首字"的兜底，
`ProxyImage` 的 onError 语义不适用。已把 `components/workbench/RankedTable.tsx` 加入白名单并写明理由。

## 四、验收

前端全量 **1,578 passed**；`tsc` 干净；`npm run build` 成功。
用例改为：点「加载更多」时 `offset=2`（首屏 mock 2 行）、表格行数从 2 变 4。

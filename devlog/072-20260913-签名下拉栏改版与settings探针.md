## 一、设计案（已确认）与落地后的实际结构

```
┌─ 签名 ─────────────────────────────────────────────┐
│ 签名                                                │
│ ┌─────────────────────────────────────────┬─────┐  │   ← 输入条（右内距 30px 给图标让位）
│ │ 你的签名文本…                            │  ⌄  │  │      chevron 绝对定位、22px 热区、展开时旋转 180°
│ └─────────────────────────────────────────┴─────┘  │
│ ┌─────────────────────────────────────────────────┐ │   ← 面板：**参与布局**（不是浮层）
│ │ 晚安，明天见～开播提醒在置顶… ▒▒  │ bilibili 主账号│ │      与输入条同宽、紧贴 6px、超高内滚
│ │ 今天也辛苦了，早点休息  │ 微博                   │ │
│ └─────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

三处设计决策及理由（写进注释，免得被"优化"回去）：

1. **面板参与布局，不做绝对定位浮层**：弹窗滚动体是 `OverlayScroll`（根 `overflow:hidden`），
   浮层越界会被**静默裁掉**（2026-09-10 筛选弹窗踩过同类坑）；in-flow 顺带天然与输入条同宽
   （就是参考图的结构关系），展开后 `scrollIntoView({block:'nearest'})` 滚进视野。
2. **渐隐用 `mask-image` 而不是覆盖式渐变**：行的底色有 hover/选中两态，
   覆盖式渐变很难与底色对齐（会露出一条色差）。平台名在滚动容器**之外**，不受遮罩影响 ——
   长文正是"从平台名之下渐隐穿过"。
3. **渐隐只在真的溢出时挂**（`.ovf`）：无条件挂 mask 会把短签名的结尾也虚掉，看着像坏了。

用户口径的三条落实：面板向下参与布局（推荐项）｜**去掉面板头那行说明**｜
**只留 hover 自动滚一次**（`scrollTo({left: scrollWidth, behavior:'smooth'})`，
移出立刻回起点、下次悬停重播；不做滚轮转横向、不做跑马灯；`prefers-reduced-motion`
下改为瞬移）。

顺带保留的键盘口径（设计案 §四已列）：输入框上 `↑/↓` 移动游标（左侧 2px 主色竖条）、
`Enter` 选中、`Esc` 只关下拉不关弹窗、收起时 `Enter` 仍是"主动失焦 → 提交"；
右侧图标 `onMouseDown` 阻止默认，避免点它的瞬间先触发一次"失焦即提交"（否则两次写库）。

## 三、第一次给档案设置弹窗装护栏：`ui_probe.py --settings`

这个弹窗一直在探针覆盖面之外（devlog/067 记过"只能靠肉眼"），而它恰恰出过两类问题：
覆盖式滚动条压住输入框右缘、浮层越界被静默裁掉。新增模式量的是**几何不变量**
（纯布局，不依赖网络与定时器）：

| 断言 | 含义 |
|---|---|
| `chevronInside` | 内嵌图标完整落在输入框矩形内 |
| `inputRightPad ≥ 26px` | 图标位置对 ≠ 文字没被压住：内距必须给图标留位 |
| `panelSameWidth` | 面板宽度 = 输入条宽度（参考图的结构关系） |
| `panelClipped == false` | 面板矩形不越出弹窗矩形（越界＝会被静默裁掉） |
| `panelWidthWhenClosed == -1` | 收起态不该存在面板 |
| `rows ≥ 1` / 溢出与渐隐一致 | 有候选行；有可滚距离就必须挂了 `.ovf` |

**这条护栏当场抓到过一个真缺陷**：我写的 `.vd-sign-field > input { padding-right: 30px }`
与既有的 `.vd-field input { padding: … }` **特异度相同**，而后者在文件里更靠后 → 赢，
于是 `padding-right` 仍是 8px，**图标会压在文字上**。改成
`.vd-field .vd-sign-field > input` 后 30px 生效（探针实测 8px → 30px）。
位置类断言（`chevronInside`）**看不出**这个 —— 所以 padding 那条是必需的。

跑法（两条都跑才算覆盖到位）：

```
python scripts/ui_probe.py --settings --vtuber 15   # 签名短：断言**没有**挂渐隐遮罩
python scripts/ui_probe.py --settings --vtuber 14   # 签名长：首行可滚 381px、.ovf 已挂
```

> ⚠️ 仍未覆盖：hover 自动滚动本身（几何断言看不到"滚了没有"）。
> 那是交互手感，仍需肉眼一次。另外 `_run_probe` 对探针 JSON 是**白名单** ——
> 新字段不登记会被静默丢掉（本次又差点栽在这里，已加提示行）。

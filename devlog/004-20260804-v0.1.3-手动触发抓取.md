# 004-20260804-v0.1.3-手动触发抓取

## 概述

新增手动触发数据抓取功能，不再只依赖 5 分钟定时任务。

## 触发方式

| 方式 | 说明 |
|------|------|
| `POST /vtuber/fetch` | API 端点，curl / 浏览器均可调用 |
| Flet 前端「立即抓取」按钮 | 桌面 UI 一键触发，抓取完自动刷新列表 |

## 变更

### [app/services/scheduler.py](app/services/scheduler.py)

- `async_fetch_and_update()` 现在返回 `FetchResult` 数据类（success / failed / skipped / details）
- 新增 `threading.Lock` 并发锁，防止手动触发与定时任务重叠执行
- 新增 `is_fetch_running()` 查询函数
- 日志级别改为从 `settings.LOG_LEVEL` 读取（修复了重复配置 `basicConfig` 的问题）

### [app/routers/vtuber.py](app/routers/vtuber.py)

新增端点：

```
POST /vtuber/fetch
```

- 如果已在运行 → 返回 `{"status": "skipped", "message": "抓取任务正在进行中"}`
- 否则 → 同步等待抓取完成，返回详细结果

```json
{
  "status": "done",
  "message": "成功 2, 失败 0, 跳过 0",
  "result": {
    "success": 2,
    "failed": 0,
    "skipped": 0,
    "details": ["明前奶绿 昵称未变更"]
  }
}
```

### [app/app_frontend.py](app/app_frontend.py)

- 新增「📡 立即抓取」按钮，点击后调 `POST /vtuber/fetch`
- 抓取完成后自动刷新主播列表
- 状态栏实时显示抓取进度/结果

## 使用

**curl**：
```bash
curl -X POST http://localhost:8000/vtuber/fetch
```

**Flet 前端**：点击「📡 立即抓取」按钮

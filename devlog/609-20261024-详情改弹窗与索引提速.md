# 609-20261024-详情：抽屉改弹窗、标签默认 5 个、回顶按钮、索引提速

用户四条反馈。

## 一、详情慢的真正原因

`/fan/{v}/member/{uid}` 每次都把窗口内 **75 个 raw 文件**重新读一遍再解析 ——
实测 **5.8–6.2 秒/次**，其中 99.9% 的数据与这次请求无关。

修法：`app/services/fan/member_index.py` —— **每个窗口只扫一遍**，把所有用户的逐场切片
收进紧凑索引（`uid → [(live_id, start_at, m, p, e, uniq)]`），之后任意用户 O(1)。
索引按 `(subdir, live_ids)` 缓存，最多留 4 个窗口；采集后由 `clear_cache()` 清掉。
`/ranked` 首页返回时**后台预热**索引。

实测：首次构建 7.9 s（后台跑，不阻塞页面），之后 **7 ms/次**。

## 二、抽屉 → 独立弹窗

`MemberDrawer` 改用项目现有的 `ui/dialog`（与 `ThirdpartyDataDialog` 同一套骨架），
Esc / 点遮罩关闭交给 Dialog 自己处理，删掉了手写的 keydown 监听。

## 三、标签默认 5 个

`TagPills` 的 `max` 默认值 3 → **5**，超出仍收进「+N」。

## 四、回顶按钮

照 `PostListView` 的 `.back-to-top` 外观（`ChevronUp` + `on` 状态），
但工作台的 `.wb-page` 自己就是滚动容器，`absolute` 会跟着内容滚走 ——
所以用 `position: fixed` 钉在右下角，滚动超过 600px 才出现。

## 五、验收

后端 fan 166 passed / 2 skipped；前端全量 1,580 passed；`tsc` 干净、`npm run build` 成功。

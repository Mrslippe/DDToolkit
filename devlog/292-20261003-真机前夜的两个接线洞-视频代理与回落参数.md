# 292-20261003 真机前夜的两个接线洞：`/video-proxy` 被 token 挡 + `?fallback` 被路由丢掉

> 起因：批 3 收尾时准备把"请用户真机验证 B站 1080P/音画同步"这条提上去，先自己按真机形态
> 过了一遍链路 —— 结果**两处都不会工作**，而且**当时的 1048 条单测全绿**。

## 一、洞 1：`/video-proxy` 没进公开白名单 ⇒ 真机每一段视频都 401

`<video src="/video-proxy?url=…">` 与 `<img>` 一样**带不了自定义头**（`X-DDToolkit-Token`）。
而 S1 之后**没配 token 就是 401**（devlog/202），公开白名单是唯一的出口：

```
PUBLIC_PREFIXES = ("/healthz", "/static/")
PUBLIC_EXACT    = {("GET", "/img-proxy")}          ← /video-proxy 不在这里
```

实测（配了 token、**不带任何头**打真应用）：

```
GET /video-proxy?url=https://sns-video-v4.xhscdn.com/a.mp4  → 401（缺令牌）
GET /img-proxy?url=https://i0.hdslb.com/x.jpg               → 502（门放行了，是上游 404）
```

⇒ **小红书视频靠"直连那条路"侥幸能播**（`sources = [...direct, ...proxied]`，xhscdn 不带 Referer
恰好给 200），所以此前用户真机看到的播放是正常的；而 **B站 DASH 档 100% 走代理**
（`direct = []`），**真机必然播不了** —— 正是这次要用户验的那一项。

**为什么单测没红**：`tests/conftest.py` 会给**每个** `TestClient` 默认塞上正确 token
（S1 收口时一次性修 86 条红的办法）⇒ 既有那条"公开端点保持公开"的用例证明的是
"**带对 token 能过**"，而不是"**不带头也能过**"。判据本身没错，是**覆盖不到真机形态**。

**修**：`PUBLIC_EXACT` 加 `("GET", "/video-proxy")`（只 GET —— 方法限死，将来给它加写语义
会自动落回要鉴权的一侧），并补一条**故意用错 token** 建客户端的用例
（`test_header_less_media_endpoints_are_public`）：只要不是 401 就说明白名单认领了它；
再加一条 `POST /video-proxy` 必须 401。

## 二、洞 2：前端发 `?fallback=true`，路由签名里没这个参数 ⇒ 静默丢掉

```ts
// 前端（BiliVideo）
api.biliPlay(postId, { fallback: true })   // → /bili/play/7?fallback=true
```
```py
# 后端（vtuber.bili_play）
async def bili_play(post_id: int, qn: int | None = Query(None), db=...):
    return await bili_play_svc.play_info(str(bvid), qn=qn)      # ← durl_fallback 从没被传
```

FastAPI **对未知查询参数默认静默忽略**（不报错、不进日志）。于是"DASH 播不动 → 回落重取"
取回来的**还是 DASH**；而 `BiliVideo` 拿到 `kernel=dash` 又会把回落闸门重开 ⇒ **无限重取**。

服务层用例当时是绿的：`tests/test_bili_play.py` 直接调 `play_info(durl_fallback=True)`，
**绕过了路由**。这一层的价值恰恰是"接线接上了没有"，所以判据补在**路由层**
（`test_bili_play_route_forwards_qn_and_fallback`，四条参数组合 + `kernel` 回声）。

**修**：路由加 `fallback: bool = Query(False)` → `play_info(..., durl_fallback=fallback)`。

## 五、教训（已进 `docs/DEV-LOOP.md` §6）

1. **"能过门" ≠ "不带头也能过"**：测试夹具为了省事统一加的东西（token 头），
   会让一整类真机形态**永远测不到** —— 凡"浏览器自己发的请求"（`<img>`/`<video>`/`<a>`）
   都要有一条**裸请求**判据。
2. **两层之间新加的参数必须有跨层判据**：服务层测参数、路由层测接线，缺一层就等于没接。
   未知查询参数被静默忽略这件事，让"漏接"看起来和"没传"一模一样。

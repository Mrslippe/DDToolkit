## 一、vtbs.moe 与 vdb：**都没有图片**（翻完整棵树 + 实测）

| 目标 | 实测 | 结论 |
|---|---|---|
| `dd-center/vtbs.moe` 全树 | 118 个条目（`truncated: false`）；图片只有站点自家的截图/`logo.png`/favicon，5 个子模块都是代码仓库 | **0 张企划 LOGO** |
| 它的 `LICENSE` | MIT © 2019 simon3000 | **只覆盖代码，不覆盖任何第三方商标图形** —— 最容易踩的一处误读 |
| `vdb.vtbs.moe/json/list.json` | HTTP 200 / **2,356,526 字节**；`vtbs` 10,133 条 = vtuber 9898 + **group 221** + fan 13 + misc 1 | 结构 `{meta, vtbs[]}` |
| vdb 的图片字段 | 全量递归扫 13 个词形（`avatar`/`logo`/`image`/`icon`/`face`…）：**字段 0 个、图片 URL 0 个** | vdb 不存任何图 |
| vdb 的其它端点 | `syntax/list`·`group`·`groups`·`vdb`·`index`·`raw`·`stats`·`all`… **全部 404** | 只有 `list.json` 一个端点 |

**但 `accounts[]` 是宝贝**：221 个企划里 **153 个有官方账号**（bilibili **147**）。

## 二、程序化来源实测可行（本批不做，底数留档）

企划 → vdb `accounts` 里的 official B 站 uid → `x/web-interface/card?mid=<uid>` 的 `data.card.face`
（**免登录、免 wbi**）。实测 133 次调用 **0 失败**；**目视抽检 6 张全部是 LOGO 本体**
（VirtuaReal 的 VR 字标、虚研社蓝底圆标、极光社「AURORA」、MZ「Marga zone」、四禧丸子「SIXIWANZI」、EOE「Elf of Era」）。

覆盖（与 `WORKLIST.md` 对照）：**187/212** 个企划名对得上 vdb，其中 **125 个**有 official 账号
⇒ 按池内条数加权 **1,419/1,597 = 88.9%** 对得上、**1,109 = 69.4%** 有官方账号。

⚠️ 两处不能照抄：① **映射本身有错** —— 125 个里 18 个昵称对不上（`C-Live_Project` →「账号已注销」、
`追光社` →「约稿联系另一个号」、`MZ次元` →「MZ小卖部」），真要用得人工过一遍；
② 官方头像多是**不透明方图**，`object-fit: contain` 塞进 20×20 会显示成**色块**。

## 三、现成收集库：只有 Wikimedia Commons 那一小撮

| 资源 | 实测 |
|---|---|
| **Commons** ⭐ | `Category:Anime companies logos by VulcanSphere`（66 成员）含 Cover / Hololive（EN·ID·2026）/ Holostars / **Nijisanji(+EN)** / **AnyColor** / VSPO! / VShojo；模板实测 `{{PD-textlogo}}{{trademark}}` ⇒ **无版权、只剩商标** |
| 萌娘百科/萌娘共享 | `Category:虚拟UP主Logo` **是空分类**；全站 **CC BY-NC-SA 4.0（禁用商业）** ⇒ 不能当素材库 |
| simple-icons（CC0） | 6 个 VTuber slug（hololive/nijisanji/anycolor/vspo/holostars/upd8）**全部 404**；只有 bilibili/niconico/youtube ⇒ 无用 |
| GitHub | 搜到的全是「Programming VTuber Logos」这类**恶搞**（把 VS Code 画成二次元），license 多为 `NOASSERTION` ⇒ 与企划无关 |
| 官方素材包 | 没有一家大社提供公开下载（`virtuareal.com` 是纯 JS 空壳） |

**Commons 对我们的实际覆盖只有 3 个名字**（`Hololive`/`NIJISANJI`/`NIJISANJI EN`）
= 池内 **120 / 1,597 行 = 7.5%**；中国企划实测**一个都没有**。

## 四、协议：**沉默 ≠ 授权**（逐字复核，并纠了子代理一处）

按 `ロゴ`/`商標`/`logo`/`trademark` 四个词形全文计数：**hololive 规约（JP 与 EN）、Holostars、
ANYCOLOR 二创规约全部 0 次** ⇒ 它们管的是"二次创作"，而**原样复制官方素材根本不算二次创作**，
压根不在保护伞内。真写了 LOGO 的**全是限制**：ANYCOLOR 応援広告規程（素材由事务局发送 + 只能用于应援广告）、
**VSPO!** 与 **RIOT MUSIC**（「公式画像（イラスト、**ロゴ等**）…**一切許可しておりません**」）、
**.LIVE/アップランド** 第3条3項（明示**不授予**商标等使用许可）。

⚠️ 本批纠出的错：子代理称 KAMITSUBAKI 规约点名了「ロゴ」—— **实测该页 `ロゴ` 0 次**、`商標` 1 次，
按实测写。**否定式结论只有逐字计数才算证据。**

本仓是 **MIT + 公开远端** ⇒ 把 LOGO 提交进仓库**就是再分发**；`cc-by-sa-4.0` 那张
（`Hololive China logo.webp`）会把 ShareAlike 带进整个仓库 ⇒ 默认不用。

## 二、修 (c)：一笔 commit

`scheduler.live_sweep_core` 原来是「写 `live_*` → `commit()` → 跳变落快照 → `commit()`」。
**第二笔失败 ⇒ 状态已落盘、快照缺失，而下一轮 `prev_status == acc.live_status`
⇒ 这条边沿被永久吞掉**（用户看到的是直播日历少一场）。回滚救不回来。
现在：快照与 live 字段**同一个事务**一次 `commit()`；`note_dynamics_activity`（开播恢复
动态流满速）挪到 commit **之后**（失败就不该恢复满速）。

⚠️ ⑤ 第一版判据写错了：照直觉断言"不 rollback 就用会报 `PendingRollbackError`" ——
**实测假红**（SQLAlchemy 2.0 里 `execute` 抛 DBAPI 错**不会**把会话打成待回滚态）。
改成先探针跑一遍、再按**真实**语义写判据（不半应用 / 抛后仍可读 / 回滚+解锁后能写 /
产品路径下一轮照常）。

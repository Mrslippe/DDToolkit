# 622-20261024-懒加载到底即停

用户反馈：没有更多内容时，「加载更多」按钮在尾部反复闪动。

## 根因

`hasMore` 的判据是 `off + items.length < total`。当服务端返回**空页**时，
`off + 0 < total` 依然成立 ⇒ `hasMore` 保持 true ⇒ 观察者再次触发 ⇒ 请求 → 空页 → 再触发……
表现为按钮在「加载中… / 加载更多」之间无限闪烁（也在空转网络）。

## 修法

1. `hasMore = items.length > 0 && off + items.length < total` —— **空页即到底**；
2. `onLoadMore` 再加一道 `!hasMore` 短路，避免观察者与点击重复触发；
3. 分母优先用后端的 `list_total`（筛选后的总数），否则 `off` 与 `total` 不同源也会误判。

## 回归用例

第二页返回空 → 按钮消失、出现「已到末尾」、请求次数只 +1（不再继续发）。

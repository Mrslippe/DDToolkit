# 518-20261018-区分效度改用效应量口径


评审建议补 Fisher z 检验。**那个方法不适用**：$r$ 与 $R$ 来自同一样本、彼此相关，
Fisher z 假设独立；且两者量纲不同（构念间关联 vs 同一构念两次测量的一致性）。

**正确做法两条**：比较对象用**衰减上限** $\sqrt{R_AR_B}$（不是把 $r$ 直接跟 $R$ 比）；
检验方法是 bootstrap 差值（不是 Fisher z）。

**先算效应量，再决定要不要花钱检验**（九组全算，$SE(r)=1/\sqrt{n-3}$）：
最小差距 **29.8 个标准误**（弥月 互动↔付费），最大 **106.7**（星瞳 出勤↔互动）。
即便把 SE 因"同源相关"与"信度方差主要来自场次抽样"放大 3 倍，最弱那对仍有 **10 个 SE**。

⇒ **选 A（只报效应量），不做 B/C**：差距是几十个标准误量级，检验结果不可能翻转，
买不到信息。文档里写明"若要进同行评审必须补**多层 bootstrap**（只重抽用户会低估 $R$ 的方差）
+ disattenuated correlation，这两条尚未做"。

**成本对照**（记下来供以后判断）：A ≈10 分钟（已完成）；B 用户级 bootstrap ≈1.5~2 小时；
C 多层 bootstrap ≈3~4 小时。

**顺手发现一条可解释的边界条件**：九组里只有 **弥月「互动↔付费」越过 0.5**（0.561，其余 ≤0.423），
而弥月恰是房间最静的（中位单场弹幕 8,455 vs 28,135 / 16,405）⇒
**房间越静，"愿意花钱"与"愿意说话"越是同一批人**；房间一吵，发弹幕不需要门槛，两轴就分开了。
与 §5.5 的机制同向。

另：全文最后一处未加检验的「显著」（§5.4 结论三的 2×2 分层付费率）也降级为「明显 + 给出差值」，
因为那一层的准确组规模没在手边 —— 同一标准，不特殊对待。

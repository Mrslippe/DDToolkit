# 009-20260804-v0.2.3-直播区发现 VTuber

## 概述

实现从 B站直播-虚拟主播分区 自动发现当前开播的主播，去重后入库。无需手动收集 UID。

## 变更

### [app/services/fetcher.py](app/services/fetcher.py)

新增 `fetch_live_area_vtubers(page, page_size)`：
- 调用 `https://api.live.bilibili.com/room/v3/area/getRoomList`
- `parent_area_id=9` 即虚拟主播区
- 返回 `[{uid, uname, roomid, title}, ...]`

### [app/services/importer.py](app/services/importer.py)

新增 `discover_from_live_area(pages, page_size)`：
- 逐页拉取当前开播的主播名单
- 按 UID 去重入库
- 自动写入 `name`、`bilibili_uid`、`room_id`、`live_title`
- 页间休息 1 秒防 Ban

### [app/routers/vtuber.py](app/routers/vtuber.py)

新增端点：

```
GET|POST /vtuber/discover?pages=3
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `pages` | 3 | 扫描页数，每页 50 人，最大 10 页 |

返回：
```json
{
  "status": "done",
  "created": 5,
  "skipped": 142,
  "scanned": 150,
  "errors": [],
  "_fetch_triggered": true
}
```

有新 VTuber 加入时自动触发抓取，立即拉取详细信息。

## 使用

浏览器直接访问：`http://localhost:8000/vtuber/discover?pages=5`

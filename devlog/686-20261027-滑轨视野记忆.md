# 686-20261027-采集完成后滑轨窗口"跑到中间"

## 现象

采集结束后，滑轨里的时间窗口自己跑到轨道中间，而不是用户原先设定的位置。

## 原因

数据刷新会触发"按 stateKey 归位"：

```ts
const center = PAD + wantStart * stp + (wantSize * stp) / 2
el.scrollLeft = Math.max(0, center - el.clientWidth / 2)   // ← 总是把窗口**居中**
```

- 没有存过状态时 `wantStart = span`（默认贴最右），但这段仍然把视野**居中**；
- 于是视觉上窗口就从最右"漂"到了中间。

## 修法

1. `SLIDER_STATE` 增加 `scroll` 字段，滚动时记住**视野**位置；
2. 归位时优先恢复 `scroll`；
3. 没有记录视野时：默认贴最右就滚到最右（`maxScroll`），只有"用户确实设过中间位置"才居中；
4. 一律夹在 `[0, maxScroll]` 内。

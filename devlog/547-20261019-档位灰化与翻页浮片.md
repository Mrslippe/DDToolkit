# 547-20261019-档位灰化、翻页浮片宽度、区间按钮归位

用户口径：**区间场次少于档位时，档位变灰且不可选**（不再"静默取满"）。另修两个视觉问题。

## 一、档位灰化

```tsx
disabled={total < g}
title={total < g ? `当前区间只有 ${total} 场` : undefined}
```

之前是 `setSize(Math.min(g, total))` —— 10 场的区间点 75 也能点，窗口大小显示成 75，
**看到的分母是骗人的**。现在直接禁掉，并给 `title` 说明原因。

## 二、翻页浮片：宽度塌陷 + 图标丢失

两个原因叠在一起：

1. 左右用了 `FloatPill shape="icon"` —— 那个形态是给"方钮"准备的，图标没渲染出来，
   只剩一个空白白片；
2. 中间那个没有 `nowrap`，被挤成 `2026 / 184 / 场` 三行。

改法：三个都走 `shape="text"`，加 `.wb-hm-year-btn`（`min-width: 26px`）与
`.wb-hm-year-mid`（`white-space: nowrap`）。图标用 `ChevronLeft/ChevronRight` 作为 children。

## 三、区间按钮归位

用户："应该处于直播与采集卡片的**左下角**，和采集、分析按钮同一行，但是顶在左侧"。

从统计条里挪到 `.wb-hm-actions`，外面包一层 `.wb-hm-actions-left { margin-right: auto }`
—— 同一行、靠左，右边仍然是删除/采集/分析。

## 四、踩坑

又两次：① 把 JSX 注释写进**标签属性之间**（`<button {/* … */} disabled=…>`），tsc 直接报
`'...' expected`；② 用例断言写着"滑轨区间"在统计条里，而按钮已经挪走。
两处都是 tsc / 用例先报的，不是脚本。

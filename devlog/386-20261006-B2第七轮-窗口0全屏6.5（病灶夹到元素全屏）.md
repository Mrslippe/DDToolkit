# 386-20261006 B2 第七轮：**窗口态 0.0%、全屏态 6.5%** —— 病灶被夹到"元素全屏"这条路上

> 用户把上一轮列的 5 项 A/B 全跑了（60fps 那条没找到素材，跳过）。这一轮第一次有了**同机同页同视频的对照**，
> 结果非常干净：**窗口态一帧不丢，全屏态稳定丢 2 帧/秒** —— 而且**两条内核都一样**。

**读出来的四件事：**

1. **不是我们的 MSE 喂数据**：同一台机器、同一个窗口，换成**渐进式**（`<video src>`，抖音流）后
   全屏照样 5.8~6.5%、窗口照样 0.0%。⇒ MSE 那条线（含 400ms 泵、配额淘汰）**排除**。
2. **不是像素量/放大倍数**：窗口**最大化**那 16.7 秒（445 帧）**一帧没丢**，而全屏（同样铺满）丢 6.5%。
   ⇒ 与"全屏像素多 ⇒ 合成更贵"无关，是**元素全屏这条代码路径**本身。
3. **不是"页面一直在动"**：`动画=` 现在只认 `running`（上一轮那条 `30秒` 是 `fill: forwards` 的假阳性），
   这批全是 **0~3 秒**，而窗口态（0.0% 丢帧）与全屏态（6.5%）的动画秒数**没有差别**。
   新加的 `动画名=` 还顺手报出了到底是哪几个：`vp-spin@svg`（缓冲转圈）、`rise-in-page@…`、
   `drawer-veil-out@…`、`opacity@div.vp-bar` —— 全是**短暂**的自家过渡，没有 `infinite` 的常驻动画。
4. **不是"合成器整页卡"**：全屏时 `页面=` 掉到 65~134fps，窗口态是 148~239fps；但**窗口态页面跑满 239fps
   也一帧不丢** ⇒ "合成器忙"本身不构成丢帧（这条推翻了上一轮的第 3 条硬事实）。

## 二、上一轮那条 flag 的结论要改写：**它生效了，但没用**

`--force-device-scale-factor=1.5` 让**界面真的变大** ⇒ 环境变量**是通的**
（wry 虽然无条件调 `set_additional_browser_arguments`，但 WebView2 侧环境变量优先 ——
与社区那个反例 [#5571](https://github.com/MicrosoftEdge/WebView2Feedback/issues/5571) 一致）。
于是 `--disable-direct-composition-video-overlays` 那次是**有效实验且零效果** ⇒
那条 DC overlay 提升路径**不是**病因（要么视频根本没走它，要么它本来就正常）。

⚠️ 顺带一个坑：设了这个环境变量会**整串替换** wry 的默认参数（含 `--autoplay-policy=no-user-gesture-required`）——
做 flag 实验时若发现"起播要点一下"，是这个原因，不是播放器坏了。

**这是本轮最大的方法论收获**：Chromium 的 flag 现在**不用改代码、不用重编**，重启应用即可 A/B。

## 三、病灶夹到哪一步了

```
数据（缓冲/饿住） → 干净        ✗

主线程（长任务 0~1 次）        → 干净   ✗
MSE 喂数据（渐进式照样丢）      → 排除   ✗
像素量/放大（最大化 0.0%）      → 排除   ✗
页面动画（0~3 秒，两态无差）    → 排除   ✗
────────────────────────────────────────
剩下：**元素全屏（requestFullscreen）这条呈现路径** —— 稳定丢 2 帧/秒、抖动 2~4 次/秒
```

## 五、本轮顺带修的尺子

- **`动画名=` 的 SVG 类名**：SVG 元素的 `className` 是对象，`String()` 出来是 `[object SVGAnimatedString]` ——
  真机日志里就出现了 `vp-spin@svg.[object`。现在字符串拿不到就退回 `class` 属性（`spin@svg.vp-spin`）。
- **新增 `页面峰=`**（整窗页面自绘最长间隔）+ 曲线里 >40ms 的那一秒标 `页NN`：
  用来分辨"合成器**整页**卡了一下"与"只有视频那一拍被推迟"（这一轮窗口/全屏两态的差别就靠它定性）。
- **新增 `尺寸=`**（`1920x1080→2560x1440`）：把"放大倍数"这件事写进日志，省得再猜。

护栏：`playbackProbe.test.ts` 25 → 26 条（页面自绘间隔的**正反两面**：55ms 要标、12ms 不许标；
SVG 目标要拿到类名）。两条新判据反向验证过，还原后逐字节一致。

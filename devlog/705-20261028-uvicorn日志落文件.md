# 705-20261028-控制台的 log 为什么不进日志文件

用户问得很好：**控制台看到的 `Exception in ASGI application` 在 `logs/app.log` 里查不到。**

## 原因

`logging_setup.setup_logging()` 配的是**根 logger**（轮转文件 + `StreamHandler`）。
而 uvicorn 用的是**自己的 logger**（`uvicorn.error` / `uvicorn.access`），
它们有独立 handler、`propagate` 不指向根 —— 根 handler 管不到它们。

结果：ASGI 未捕获异常由 `uvicorn.error` 打到 stderr（控制台看得见），
**文件里一条都没有**。这也解释了"我明明看到报错，日志里却干干净净"。

## 修法

`setup_logging()` 末尾调 `attach_uvicorn_to_file()`：

- 给 `uvicorn` / `uvicorn.error` / `uvicorn.access` / `starlette` / `fastapi` 挂**同一个**轮转文件 handler；
- `propagate = False`（否则同一条经根 handler 再写一遍）；
- **幂等**：handler 打 `_dsh_file_handler` 标记，重复调用不叠加。

验证（真跑一次）：

```
2026-10-28 02:07:30,838 [ERROR] uvicorn.error: ASGI 测试异常：这条必须出现在文件里
```

## 一、期望②：动效（"优雅流畅"，但不炫技）

顶栏是常驻视野，动效的原则是**只在状态真的变了的地方动**，不做装饰性循环动画。

| 位置 | 动画 | 取值依据 |
|---|---|---|
| 面板入场 | `si-panel-in` **220ms** `cubic-bezier(.22,.61,.36,1)`：`translateY(-6px) scale(.985)` → 原位 | 位移 6px = 面板与状态岛之间的间隙量，看起来像"从岛上长出来"；`transform-origin: top` 让缩放朝锚点收；`both` 保证首帧就在 from 态（否则先闪一帧原位） |
| chevron | `transition: transform .2s`（展开转 180°） | 原来是硬切，翻转是"展开/收起"的状态指示，值得 0.2s |
| 计数徽章 | `si-pop-in` **180ms**（`scale(.6)→1`） | 条目数变多时新徽章是"冒出来"的，不是硬贴上去；React 侧 `key={notices.length}` 让计数变化时重放 |
| 文案变更 | 沿用 `.pill-text-fade` 0.3s 淡入（R12a 已有） | 轮播与任务文案共用 |

**`prefers-reduced-motion: reduce` 的取舍（这一条是想清楚才写的）**：
去掉**位移与缩放**，但**保留淡入**（`si-panel-in-fade` 180ms）。理由是"完全不淡"反而更像闪帧 ——
减少动效要减的是前庭刺激（位移/缩放/视差），不是所有的时间维度变化。

**顺带纠正一处 R12a 遗留**：原来 reduce 分支里写着 `.si-island.open .si-chevron{transform:none}` ——
那是把**状态指示**当成动效一起减掉了（展开后箭头不指"可收起"，用户少一个反馈）。
现在 reduce 下箭头照旧**瞬时翻转**（无过渡、无插值 ⇒ 没有前庭刺激），只去掉 `transition`。
探针因此加了一条："展开后 chevron 的计算 `transform` 不许是 `none`" ——
它在两条分支上都必须成立，谁再把翻转删掉就会红。

探针按 `matchMedia('(prefers-reduced-motion: reduce)')` 自动分派断言**哪一支**都必须对，
所以两条支路都会被测到，而不是"写了 reduce 分支没人验证"。

## 二、期望③：空闲轮播（语录池）

```
utils/idleQuotes.ts
  IDLE_QUOTES[]            7 条内置语录（短、克制）
  idlePool(statusText)     池 = [状态文案, ...语录, ...各来源]（去重、trim）
  pickIdle(now, opts)      {text, index, size, pool} —— floor(now/tick) % size
  registerIdleProvider(fn) 扩展点（返回注销函数）：将来接弹幕热词/名场面不用改顶栏
```

### 三条设计约束（每条都有单测）

1. **状态文案仍在轮播里，且固定第 0 格**。全换成语录之后，"服务到底在不在跑"就没地方看了 ——
   那是顶栏的看家职责。用户 2026-09-10 的口径是"自动节拍不占顶栏"，不是"顶栏不说自己在跑"。
2. **确定性**：按 `floor(now / tickMs) % pool.length` 选，不用随机数 —— 同刻同值（重渲染不闪字），
   探针/单测才能断言"下一格是什么"。
3. **语录里不许出现会被既有口径误判的词**：`轮询` / `抓取中`（还有 `同步`，一并防）。
   `ui_probe._assert_topbar` 断言的是**顶栏文案**在自动节拍期间不能有进度词；
   语录是长期驻留文案，混进 `轮询` 就会让那条护栏永久红灯。单测
   `语录里不许出现会被顶栏口径误判的词` 拦在写入侧。

### 一个值得记的工程取舍：轮播的时钟**不挂在抓取轮询上**

最省事的做法是复用 `TopBar` 的 `fetch-status` 轮询（空闲 10s 一次）驱动重渲染，一行定时器都不用加。
**没这么做**：那样轮播的"在不在走"就隐式依赖 `POLL_IDLE_MS` —— 谁把它从 10s 调到 30s，
轮播就静默变慢；调到超过一轮周期，观感上就是"卡住了"，而且**没有任何测试会红**。
现在 `StatusIsland` 自带 `setInterval(IDLE_TICK_MS)`，并且**只在空闲（无条目）时开**：
有事发生时立刻停表（省一个无谓定时器，也让"轮播"与"有通知亮着"不可能同屏）。
`IDLE_TICK_MS = 6s` 的两侧代价写进了常量注释，并有区间单测（<4s 太抢注意力 / >15s 像卡住）。

## 三、护栏：把"会自己变的界面"变成可判定的

轮播最难测的点：静态 `--dump-dom` 只拍到**一帧**，"它到底在不在走"看不出来。
`ui_probe --status-island` 因此扩了三块：

| 断言 | 怎么量 | 为什么不能更省 |
|---|---|---|
| 三格连采在走 | 采 `.si-text` + `data-idle-index`，间隔 **7s 虚拟时间**（> 档位 6s），断言 `(idx[i+1]-idx[i]) % size >= 1` 且三次文案不重复 | 只采一帧的话，"轮播坏了"与"正好停在这一格"无法区分 |
| 取到的词**出自池子**且**就是 index 那一格** | 页面把 `pickIdle` 的结果原样挂成 `data-idle-pool`（`\|` 分隔），脚本断言 `text in pool` 且 `text == pool[index]` | 否则"索引在往前走"可以靠一个假索引骗过去 —— 断言空转 |
| 池子第 0 格 = 「数据服务运行中」+ 池内无进度词 | 直接读 `data-idle-pool` | 这是约束①②的机器判据，也是"语录不许长得像进度"的唯一入口 |
| 入场动画真的挂上了 | `getComputedStyle(panel).animationName` / `animationDuration` / `getAnimations().length`，按 `motionReduced` 判分支 | **CSS 文件里写了不算数**：选择器可能压根没匹配上 |
| 展开后 chevron 翻转了 | `getComputedStyle(chevron).transform` 必须是矩阵（不是 `none`），过渡时长按 reduce 分派（200ms / 0ms） | 这条挡的正是"把状态指示当动效一起减掉" |

实跑记录（1100 宽）：

```
# 默认（no-preference）
空闲：文案='数据服务运行中' 亮起=False 计数=False 右栏宽=670
空闲轮播：池=8 三格=['数据服务运行中','记录会一直留着，慢慢看','档案已就绪，随时可以翻'] 索引=[0, 1, 2]
入场动画：name='si-panel-in' 220ms 条数=1 ｜ reduce=False
chevron：transform='matrix(-1, 0, 0, -1, 0, 0)' 过渡=200ms
ttl 到期后：文案='今天也在安静地守着' 亮起=False      ← 回到空闲后继续轮播，不卡在消息上

# 加 --force-prefers-reduced-motion 再跑一次（一次性验证，脚本未入库）
空闲：文案='档案已就绪，随时可以翻' 亮起=False 计数=False 右栏宽=670
空闲轮播：池=8 三格=['档案已就绪，随时可以翻','今天也在安静地守着','想看谁，点左边的名字'] 索引=[2, 3, 4]
入场动画：name='si-panel-in-fade' 180ms 条数=1 ｜ reduce=True
chevron：transform='matrix(-1, 0, 0, -1, 0, 0)' 过渡=0ms
```

两次跑**都**拍到了「数据服务运行中」出现在空闲文案里（一次是首采第 0 格，一次是 reduce 跑前一轮的
`7 → 0 → 1` 回卷）——"状态文案没有被语录顶掉"这件事在真实 DOM 上被看见了，
而不只是单测里的取模运算。

### 反向验证（新护栏必须证明它会红）

一次改两处故意破坏：① `IDLE_TICK_MS` 改成 `600_000`（轮播停住）；
② 语录里塞一条 `'反向验证用：动态轮询中'`。探针实得：

```
空闲轮播：池=9 三格=['删掉的帖子也留了痕','删掉的帖子也留了痕','删掉的帖子也留了痕'] 索引=[6, 6, 6]
 - 语录 '反向验证用：动态轮询中' 里出现进度词「轮询」—— 空闲文案不许长得像任务进度
 - 空闲轮播没在走（索引 [6, 6, 6]，间隔 7s 虚拟时间/档位 6s）—— 用户期望③：空闲时轮播内容
 - 空闲文案三轮里出现重复（…）—— 索引动了但文案没换
exit=1
```

三条断言各自独立命中（池长也如实变成 9，说明那条"池内容条数 = 池长"的对账也在工作）。
还原后重跑：`池=8 三格=[…] 索引=[1,2,3]` + `[ok]`，exit=0。

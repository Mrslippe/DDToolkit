# 006-20260804-v0.2.0-扩展VTuber数据字段与抓取策略优化

## 概述

扩展 VTuber 数据模型，新增 6 个字段，区分"变动字段"与"稳定字段"的更新策略，优化数据抓取效率。

## 新增 DB 字段

| 字段 | 类型 | API 来源 | 说明 |
|------|------|----------|------|
| `sign` | String | `data.sign` | 个性签名 |
| `live_status` | Integer | `data.live_room.liveStatus` | 直播状态：0=离线 1=直播中 |
| `live_title` | String | `data.live_room.title` | 直播间标题 |
| `room_id` | Integer | `data.live_room.roomid` | 直播间 ID |
| `live_url` | String | `data.live_room.url` | 直播间地址 |

同时保留 `is_live`（Boolean）兼容旧逻辑，由 `live_status == 1` 自动推导。

## 抓取策略：变动 vs 稳定

| 分类 | 字段 | 更新策略 |
|------|------|----------|
| 变动 | `name`, `sign`, `live_status`, `live_title`, `live_url`, `fans_count` | 每次抓取覆盖 |
| 稳定 | `birthday`, `room_id`, `bilibili_uid` | 仅在 DB 中为空时写入 |

稳定字段（生日、直播间 ID）不会变化，避免无效写入。

## Fetcher 优化

- [app/services/fetcher.py](app/services/fetcher.py)
  - `fetch_bilibili_user_info()` 新增提取：`birthday`、`live_status`、`live_title`、`room_id`、`live_url`，`gender` 改用 `data.sex`
  - `fetch_bilibili_user_stat()` 移除无效的 `like` 字段，新增 `following`

## Router 简化

- [app/routers/vtuber.py](app/routers/vtuber.py)
  - `list_vtubers` 和 `get_vtuber` 用 `VTuberOut.model_validate(obj, from_attributes=True)` 替代手动逐字段构造
  - `/vtuber/fetch` 支持 GET + POST

## Schema 更新

- [app/schemas/vtuber.py](app/schemas/vtuber.py)
  - `VTuberOut` 新增 `from_attributes=True` 配置，移除 `is_live`（由 `live_status` 替代）
  - `VTuberCreate` / `VTuberUpdate` 同步新增所有字段

# 008-20260804-v0.2.2-头像持久化与本地缓存

## 概述

将 `data.face`（头像 CDN URL）持久化到数据库，并增加本地文件缓存，解决离线时头像无法展示的问题。

## 新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `avatar` | String | B站 CDN URL，线上直接使用 |
| `avatar_path` | String | 本地路径 `static/avatars/{uid}.jpg`，离线兜底 |

## 头像下载策略

在 [app/services/scheduler.py](app/services/scheduler.py) 的每次抓取中：

1. 比较新旧 URL → URL 不变则跳过下载
2. URL 变化 → 异步下载到 `static/avatars/` 目录
3. 下载成功后写入 `avatar_path`
4. 下载失败仅记录 warning，不影响抓取流程

## 静态文件服务

在 [app/main.py](app/main.py) 中挂载 `static/` 目录：

```
app.mount("/static", StaticFiles(directory="static"))
```

头像可通过 `http://localhost:8000/static/avatars/{uid}.jpg` 直接访问。

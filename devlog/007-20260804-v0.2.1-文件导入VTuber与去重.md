# 007-20260804-v0.2.1-文件导入 VTuber 与去重

## 概述

移除硬编码 Demo 数据，改为从文本文件导入 VTuber 列表，按 `bilibili_uid` 自动去重，新增 VTuber 时自动触发抓取。

## 变更

### 数据初始化（[app/main.py](app/main.py)）

- 移除 `init_db()` 的 Demo 数据
- lifespan 启动时自动读 `vtubers.txt` 导入
- 检测到新 VTuber 时延迟 5 秒触发一次抓取

### 新增 [app/services/importer.py](app/services/importer.py)

导入模块，提供两个入口：

| 函数 | 来源 | 使用场景 |
|------|------|----------|
| `import_from_file()` | `vtubers.txt` 文件 | 启动时自动导入 |
| `import_from_text(text)` | 文本字符串 | API 端点 |

去重逻辑：读取现有 DB 中全部 `bilibili_uid`，重复的行跳过，不重复的才 insert。

### 新增端点

**`GET|POST /vtuber/import`**

三种调用方式：
- `GET` → 重新从 `vtubers.txt` 导入
- `POST` JSON `{"text": "昵称 uid\\n..."}` → 从请求体导入
- `POST` 文件上传 → 从 `.txt` 文件导入

返回：
```json
{
  "status": "done",
  "created": 2,
  "skipped": 0,
  "errors": [],
  "_fetch_triggered": true
}
```

**`GET|POST /vtuber/reload`** — `/vtuber/import` 的便捷别名，直接从文件重新加载。

### 文件格式（[vtubers.txt](vtubers.txt)）

```
明前奶绿 2132180406
七海nana7mi 434334701
```

每行 `昵称 UID`，空格分隔。支持 `#` 开头的注释行和空行。

### 配置（[app/core/config.py](app/core/config.py)）

新增 `VTUBER_LIST_FILE = "vtubers.txt"`

## 运行流程

```
启动 → create_all 建表 → 读 vtubers.txt → 按 UID 去重 → insert 新项
  → 有新项 → 5 秒后自动抓取 → scheduler 定时运行
  → 无新项 → scheduler 定时运行
```

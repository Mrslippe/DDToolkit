# 713-20261028-L3 窗口缓存（879 s → 119 s）+ 测试风险分层表落档

## 1. 缓存：36 次加载 → 4 次

`test_fan_invariants.py` 是整套 fan 用例里唯一的重仓：9 条用例 × 4 个 V = **36 次
`load_window(75)`**，而它们其实只需要 **4 个窗口**。实测一次全量 **879 s**。

先量了时间花在哪（`tracemalloc` + 计时，四 V 逐个加载）：

| V | users | 池 | load | compute | 累计常驻 |
|---|---|---|---|---|---|
| 弥月 | 64,655 | 1,880 | 59.1 s* | 0.99 s | 108 MiB |
| 明前奶绿 | 195,045 | 5,305 | 160.6 s* | 2.77 s | 413 MiB |
| 星瞳 | 252,284 | 5,577 | 149.4 s* | 2.68 s | 738 MiB |
| 七海 | 305,961 | 3,664 | 213.9 s* | 3.69 s | 1,172 MiB |

\* 带 `tracemalloc` 的耗时被放大了 3–5 倍（真实约 24 s/V）。**结论很清楚：
99% 的时间是重复读盘 + 解析 gzip JSON，计算本身 1–4 s/窗口。**

## 2. 为什么敢缓存 4 个（而不是"只留一个"）

"只留一个"要按 V 分组跑，得动 `pytest` 收集顺序（conftest 钩子或动态生成用例）——
都是**隐式魔法**，还破坏"用例按写作顺序跑"的直觉。而缓存 4 个的代价量出来了：

- 累计 **≈1.17 GiB**（单个窗口 108–434 MiB）；
- 但这是**开发期**测试进程，跑完即退；发版门禁里 pytest 与 Rust 构建是**顺序**跑的，
  不会叠加；
- 换来门禁从 879 s → **119 s**（每次发版都要付的账）。

所以选显式缓存 + 写明代价，而不是 clever 的排序。给了逃生阀：
`DDTOOLKIT_FAN_TEST_NO_CACHE=1` 关掉缓存、回到逐条重载。

## 3. 缓存成立的前提：用例必须只读

共享同一个 `Window` 对象，任何一条用例改了它就会串味（而且表现为"换个顺序跑就红"）。
逐个核对过：`checks.check_identity`、`build_axis_table`、`type_label`、
`participation_strength`、`rank` **都不改 `Window`**（`checks.py` 里没有一处
`stats[...] =` 或 `sr.x =`）。这条前提写进了 `04-validation.md` §7.4：
**以后加用例若要改窗口，先复制一份再改。**

```python
_WINDOW_CACHE: dict[tuple[str, int], Window] = {}
_NO_CACHE = os.getenv("DDTOOLKIT_FAN_TEST_NO_CACHE") == "1"

def _window(short: str, n: int = 75) -> Window:
    hit = None if _NO_CACHE else _WINDOW_CACHE.get((short, n))
    if hit is not None:
        return hit
    ...
    _WINDOW_CACHE[(short, n)] = w
```

## 4. 顺带落档：模型风险 → 测试层 → 文件

`04-validation.md` §7 原来只有一张"三层"表，但**该把新用例加到哪一层**这件事只散落在
14 个 docstring 里。补了两块：

1. **六类风险的对照表**（口径漂移 / 数学性质 / 接线错误 / 静默丢数据 / **误读·结论越界** /
   打包形态），每行给出该找哪一层、现在谁在守；
2. **新加用例的决策树**（合成 → L1；真实但冻结 → L2 式；只钉关系 → L3；端点契约 →
   api；闭环 → collector；路径形态 → datapath）。

同时写明一件容易被误解的事：**CI 与本地门禁跑的不是同一批**。CI（`ci.yml` /
`ci-windows.yml`）没有那 673 MB 真实数据 ⇒ L2 与 L3 的真实数据用例一律 `skip`；
只有发版门禁（`scripts/release.py` 的 `gates`，`pytest -q` 非 0 直接停）才真跑。
所以**"CI 绿了"不等于"L2/L3 绿过"**。

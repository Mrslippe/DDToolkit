# 029-20260905-v0.6.1-二级界面（弹窗/浮层）参照风格重绘

## 概述

用户提供参考截图（圆角卡片弹窗风格：白底 12px 圆角 + 柔和阴影 + 发丝边 +
分区粗体标题 + 发丝分隔 + 描边圆角选项按钮 + 粉底激活 + 全宽描边 OK），
要求「弹窗等二级界面」统一按此风格。本次将其固化为 **C5 第四层「弹窗层」**契约。

## 定稿（与用户确认）

| 决策点 | 定案 |
|---|---|
| 卡片外框 | **12px 圆角（rounded-xl）+ 淡阴影** `--shadow-dialog: 0 4px 16px rgba(15,23,42,.10)` + 发丝边 |
| 底部/确认按钮 | **主操作=粉底白字圆角；次要=白底描边圆角**（AlertDialog 默认 Action/Cancel 即此形态） |
| P6-3 方向 | **推翻**：弹窗层从「表面层 0px 方形无阴影」剥离为独立层 |

## 改动清单

1. **tokens.css**：新增 `--radius-dialog: 12px`、`--shadow-dialog`（注释更新：
   方形契约仅剩表面层卡片/面板，弹窗层豁免）；
2. **ui/dialog.tsx** `DialogContent`：`rounded-lg`→`rounded-xl`、
   `shadow-none`→`shadow-[var(--shadow-dialog)]`（详情窗/添加 VTuber/登录/
   批量/添加账号 全部生效）；
3. **ui/alert-dialog.tsx** 同上（解除订阅/抓取方式/抓取完成报告/任务进行中）；
4. **ui/select.tsx** `SelectContent`：`rounded-md+shadow-md`→`rounded-xl+shadow-dialog`
   （账号切换下拉）；
5. **`.filter-pop`**（侧栏排序/筛选弹窗，layout.css）：恢复圆角+柔和阴影；
   分区标题 600 粗体 + 分组上方发丝分隔线；`filter-chip` 方形→**描边 8px 圆角**
   （hover 灰底），`.on` 粉底白字；底部分隔线 + 描边圆角按钮；
6. **`.time-pop`**（时间筛选浮层，posts.css）：同上（date 输入框 8px 圆角、
   actions 分隔线 + 按钮 8px 圆角；`.primary` 粉底保持 + hover 变 `--c-accent`）；
7. **AddVtuberDialog**：平台标 `rounded-none`→`rounded-md`、输入框/列表容器
   `rounded-lg`；
8. **LoginDialog**：平台切换钮/刷新二维码钮 `rounded-lg`；
9. **BatchFetchDialog**：任务条目 `rounded-lg`、图标底 `rounded-md`；
10. **PostDetailDrawer**：卡片随基础层（已有发丝 SectionTitle 即参考风格的分区感）。

## 契约更新

- UI-MAP C5：新增「弹窗层 dialogs」行（圆角卡片 12px + `--shadow-dialog` +
  发丝边 + 分区标题分隔 + 描边圆角控件/粉底激活 + 主粉底次描边）；
  表面层收缩为 post-card/posts-panel；「二期待办」P6-3 条目以本条为准（修订说明）；
- 用户审美特例（live-tag/type-chip/stat-pill/acc-switch/post-card/滚动条）
  全部未动。

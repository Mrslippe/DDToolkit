# 370-20261006-协议点了同意进不去（少一个 Content-Type）与正文改成正式版

> 用户两条：「点击我已知悉并同意后还是**没能进去**，显示无法知悉同意」；

## 一、事故：`fetch` 传字符串 body 的默认 `Content-Type` 是 `text/plain`

复现（把真后端起在真库上，逐个变体打同一发）：

| 请求 | 结果 |
|---|---|
| **不带 `Content-Type`**（前端当时就是这样发的） | **422** `{"detail":[{"type":"model_attributes_type","loc":["body"],"msg":"Input should be a valid dictionary…"}]}` |
| `text/plain;charset=UTF-8`（= `fetch` 传字符串的默认值） | 同上 422 |
| `application/json`（仓里其它 POST 的写法） | **200** `{…,"needed":false}` |

两个错叠在一起才让现场那么难判：

1. **少了 `Content-Type: application/json`** ⇒ FastAPI 不按 JSON 解析 body ⇒ 422。
   （仓里**所有**带 body 的 POST/PUT 都显式写了那个头，就我这条漏了 —— 它又是第一个
   "POST + JSON body" 的新写法，没有可抄的邻居时最容易漏。）
2. **422 的 `detail` 是个数组**，而 `request()` 里写的是 `String(body.detail)`
   ⇒ 界面显示「没能记录同意：**[object Object]**」——用户看到的"无法知悉同意"就是这个。

修法：① `acceptAgreement` 补上 `headers: {'Content-Type': 'application/json'}`（附注释说明
为什么必须有）；② `request()` 把非字符串的 `detail` **JSON 化**（宁可长一点，也要能读到 `msg`）
—— 这条是通用的：以后任何 422 都不该只显示 `[object Object]`。

**判据**（新增 `src/api/agreement.api.test.ts` 3 条）：请求形状（POST / 路径 / JSON 头 /
token 头 / body）+ 422 数组 `detail` 能读出原因 + 400 字符串 `detail` 原文照传。
⚠️ 这条为什么以前没有：`LegalNotice.test.tsx` 把 `api` 整个 **mock** 掉了（它测组件行为），
而**没有任何用例看"这个请求到底怎么发出去的"** ⇒ 形状错了全绿。
反向验证：把那行 `headers` 注释掉 ⇒ 第 1 条红。

## 二、正文改成正式版（用户口径：参考其他软件的用户协议）

结构照国内桌面软件 EULA 的通行写法（参考 [腾讯小鹅桌面软件许可及服务协议](https://rule.tencent.com/rule/202607210001)、
[万兴科技用户协议](https://www.wondershare.cn/company/terms-of-use.html)、
[福昕桌面应用软件许可协议](https://cn.fuxinsoft.cn/portal/products/phantompdfeula/)）：

- **首部「重要提示」**（单独框起来）：先点明"请审慎阅读，特别是**免除或限制责任**（第九条）、
  **第三方平台与账号风险**（第六条）、**使用限制**（第三条）"，并写明"点击即视为完全接受"；
- **十二节**：一、协议的接受与变更 · 二、定义 · 三、许可范围与使用限制（非独占/不可转让、
  禁止再分发/反向工程/商业用途）· 四、用户的权利义务与承诺（只用本人凭据、只用公开内容、
  遵守法律与平台协议）· 五、本软件的功能与边界（不是下载器/不代发内容）·
  六、第三方平台、内容与风险提示（非官方无关联、平台协议禁止自动化采集、账号可能被限制或封禁、
  内容权利归原权利人、第三方数据仅供参考）· 七、数据、隐私与本地存储（全在本机、不上传、
  备份与删除自负）· 八、知识产权 · 九、免责声明与责任限制（**按「现状」提供、不作任何担保**；
  列明不承担的具体后果；**"后果由您自行承担（责任自负）"**）· 十、协议的终止（含存续条款）·
  十一、法律适用与争议解决（大陆法律 + 作者住所地法院）· 十二、其他条款（可分割性 / 标题 /
  完整协议）；
- 头部一行 `版本 v{后端给} · 自 2026-10-06 起生效`。

判据更新：`LegalNotice.test.tsx` 第 1 条改成逐节核**十二个小标题** + 「重要提示」+
「公开可见」+「账号被限制或封禁」+「责任自负」（探针 `--first-run` 仍钉 `data-legal="1"`、
「我已知悉并同意」、「责任自负」三处，都还在）。

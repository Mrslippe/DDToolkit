# 725-20261028-结果区空态骨架化（修订第 1 条）

## 我上一版理解错了

`devlog/715` 我把"空态"做成了**该页签有几张卡就画几张**（总览 3 张、其余 2 张）。
用户看图后纠正：要的是**与有结果时完全一致的整页骨架**，只是把内容挖空，而且
**图表区只保留一张卡**。

## 改成什么

```
┌ 分析结果   尚未分析 ─────────────────────────┐   ← 标题行回归（空态也在）
│ 总览 | 出席 | 互动 | 付费          对比      │   ← 页签行回归（可切，标题跟着换）
│ ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁                        │   ← 进行中才有的 4px 细进度线
│ ┌────────────────────────────────────────┐ │
│ │ 核心度分层   分析完成后这里会出现 3 张图 │ │   ← **单张**空态卡，标题跟随页签
│ │        暂无数据 / 请先进行采集            │ │
│ └────────────────────────────────────────┘ │
│ ┌ 名单 尚未分析 ──────────────────────────┐ │
│ │        暂无数据 / 请先进行采集            │ │
│ └────────────────────────────────────────┘ │
└────────────────────────────────────────────┘
```

四条具体改动：

| 改动 | 原因 |
|---|---|
| 空态分支补上标题行「分析结果」+ 页签行 | 骨架完整，用户能看出这里将来是什么 |
| `ResultCharts.empty` 从"多卡"改成**单卡** | 用户口径：卡片只保留一张；标题跟随页签（总览→核心度分层 / 付费→付费贡献…），副标题点明"分析后会出现 N 张图" |
| **删掉整个 `.wb-busy` 大面板**（66 行） | 用户口径：即使正在采集也不改变布局 |
| 进行中只在空态卡顶部给一条 **4px 细进度线** | 信息不丢（有百分比就显示），也不破坏布局；细节仍在弹窗与顶栏 |

**只有 `ranked` 到达那一刻**才整页换成有结果的样子 —— 这是唯一的状态切换点。

## 一个必须说清的冲突（我按旧口径做了）

2026-10-23 的用户口径是：**结果区空态不显示三枚采集读数**（窗口场次 / 已有 / 待采），
理由很具体 —— 采集信息只在「直播与采集」卡里，不该重复一遍。而今天截图里那一行是
**有结果**的状态。

所以：**空态不渲染 `statsPills`**，旧用例（断言 `workbench-preview` 为 null）保持绿。
做成常量 `statsPills` 供有结果时使用，将来要改回"空态也显示"只需在空态分支加一行。

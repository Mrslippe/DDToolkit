# 295-20261003 播放器四则：删标题带 / 点播放就播 / 底栏永远一行 / 清晰度菜单不换行

> 用户真机复验（2026-10-03 22:0x）：**播放本身已经通了**（封面、播放器、清晰度菜单都出来了），
> 报的是四条界面问题。逐条落地，判据都补在 `VideoPlayer.dash.test.tsx` / `BiliVideo.test.tsx`。

## 一、封面下那条黑边标题带 → 删掉

`.bili-lazy-title`（懒加载态的标题）在封面下沿铺了一条黑带，用户口径：
「标题已经在详情页标题标出来了，直接删去吧」。

删的是整条链：`BiliVideo` 的渲染 + `title` 这个 prop + `PostDetailDrawer` 的传参
（留着 prop 就是留一个"没人用但有人会再填上"的口子）。⚠️ 它**本来就没有任何 CSS**
（`.bili-lazy-title` 在 `posts.css` 里查不到）—— 一条没样式的 div 能在真机上长成"黑边"，
靠的是 `.vp` 的黑底 + 默认块级盒。**"删干净"包括把这种没人管的裸元素一起带走。**

## 二、点中央播放键 → 拿到地址**直接开始播**

原来点完只把播放器画出来（B站那条路"点播放才取流"，取回来是新一次挂载 ⇒ 落地即暂停）。

- `VideoPlayer` 新增 `autoPlay`：地址就绪（`src` 变化）时调 `startPlayback()`；
- `BiliVideo` **恒传 `autoPlay`**：这条路上的每一次取流都源于用户动作（点播放 / 换清晰度 /
  播不动后的补救），没有"窗口自己开始播"的情形；
- `startPlayback()` 与 `toggle()` 共用一份（写两遍必然漂移成"点了能响、自动播不响"）；
- ⚠️ **DASH 档两条流必须成对起**：音轨被自动播策略拒绝（`NotAllowedError`）时
  **把视频轨也停住** —— 静音画面比"没反应"更糟，用户会当成坏了。判据把这个分支也钉了。

## 三、底栏右侧图标叠起来 → 进度条自适应

根因是 flex 的默认值，不是"图标太多"：

```
.vp-progress { flex: 1 }          /* 但 flex 项的 min-width 默认是 auto = min-content */
```

B站的档位名带空格（`高清 1080P`），**min-content 就是最长那个词**，于是那一项被撑住 ⇒
底栏溢出 ⇒ 后面的按钮换行/互相压（截图里 `1×` 被挤到 `1080P` 下面）。
修：`.vp-progress { min-width: 0 }`（关键那一条）+ `.vp-bar { flex-wrap: nowrap }`
+ `.vp-btn/.vp-time/.vp-rate { flex: none }` + `.vp-rate` 改 `inline-flex`。
"让进度条长度自适应"这句用户话，落到代码就是这一个 `min-width: 0`。

## 四、清晰度菜单：档位名一行 + 「需大会员」用小图标

- `.vp-menu-item { white-space: nowrap; display: flex; gap: 5px }` —— 档位名不再在空格处折行
  （折行会把它变成一条窄高条，`1×` 也被挤走）；
- 「（需大会员）」那串文字换成**一颗王冠小图标**（lucide `Crown`，`.vp-crown` 12px）：
  文字太占宽、又把行撑换行。⚠️ **信息不能丢**：`title` 保留，另加
  `aria-label="4K（需大会员，不可选）"`，图标本身 `aria-hidden`（否则读屏念两遍）；
- 顺手把禁用态做像样：整条压暗到 `.5`、hover 不再亮（原来只是 `disabled`，鼠标移上去还高亮，
  看起来像能点）。

## 五、测试基建：jsdom 没有 `play()`

自绘播放器开始**自动起播**之后，"渲染一个播放器"本身就会调 `play()`，而 jsdom 没实现它
（打印 `Not implemented` 并返回 `undefined`）⇒ 一批用例炸在
`Cannot read properties of undefined (reading 'catch')`，**与被测逻辑无关**。

处理方式是**补测试环境，不改生产代码**：新增 `vitest.config.ts`（`mergeConfig` 复用
`vite.config.ts`）+ `src/test/setup.ts`，给 `HTMLMediaElement.prototype` 补一份最小的
`play/pause`（返回 resolved Promise + 维护 `paused`，**不派发事件** —— 既有的
`playing` 状态仍由用例自己 `dispatchEvent` 驱动，保持可控）。
⚠️ 立场写在注释里：**不给生产代码加 `play()?.catch()` 这种防御**（生产里一定有返回值，
加防御只会把真问题藏起来）。

## 六、判据

| 用例 | 钉什么 |
|---|---|
| `BiliVideo.test.tsx` | 标题带**不再出现**（`.bili-lazy-title` 查不到）；点播放 ⇒ `VIDEO` 与 `AUDIO` **都**被 `play()` |
| `VideoPlayer.dash.test.tsx` | `autoPlay` 才自动播（不给就不播）；音轨被拒 ⇒ 视频轨 `pause()`；大会员档 `textContent === '4K'` + `.vp-crown` + `aria-label`；真 CSS 里 `nowrap` / `min-width: 0` / `flex: none` / `inline-flex` 四声明 |

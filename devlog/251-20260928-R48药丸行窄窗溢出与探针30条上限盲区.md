# 251-20260928-R48 药丸行窄窗溢出 + 探针「30 条上限」这个盲区

**这不是本批计划内的活** —— 它是 R46 的**副产品**：把左栏 8 个 radix 头像
（每个都带 `overflow:hidden`）换成 `ProxyImage` 之后，探针的门禁**当场红了**，
而红的那一条**不是 R46 弄坏的**，是尺子变准了。

## 一、现象与定位

R46 落地后跑 A 档门禁：`@1100 cards: 容器横向溢出 DIV.os-scroll client=534 scroll=564`。

- 复现与证明"既有"：`git stash` 掉本批改动 → 把 `probe.ts` 里
  `scrollers` 的 `.slice(0, 30)` 抬到 200 → **同一句话原样出现**
  （`client=534 scroll=564`）⇒ 缺陷早就在，只是**从来没被测到**；
- 算术也对得上：`.stat-pill` 宽 **191px** 写死、每行 3 枚 + 2×10 gap = **593px**；
  1100 窗口下英雄区内容盒只有 **504px**（`--sidebar-width: 492` + 面板内距），
  `.stat-sets { width: fit-content }` 于是**恒 593**、居中后左右各溢出 ~29.5px ⇒
  `scrollWidth 564 = 534 + 30` ✓ 与报错数字逐位吻合。截图证实：第三枚药丸被窗口右缘**切掉**。

⚠️ **窗口最小宽是 960**（`tauri.conf.json` 的 `minWidth`）⇒ 1100 及以下都是**真实可用尺寸**，
不是探针虚构的档位。

## 二、盲区为什么存在（本批最值钱的一条）

`scrollers` 清单用 `/(auto|scroll|hidden)/` 过滤 —— **`overflow:hidden` 也算一条**。
于是左栏每个 radix `Avatar`（shadcn 根节点是 `overflow-hidden`）都占一格：
8 个 V 行 = 8 条，正好把 cards 的 `.hero-scroll > .os-scroll` **挤出 `.slice(0, 30)` 窗口**
⇒ "任何容器不得横向溢出"这条判据对它**静默空转**（不是没写，是没跑到）。

⇒ 两条改动：
1. 上限 `30 → 200`（页面里不会有 200 个滚动容器，等于不再截断）；
2. **排除 DEV 专属的「启动诊断」覆盖层**（`bootDiag.ts` 的 `#boot-diag`）：
   它累计 ≥3 次资源加载失败就自己弹出来，弹出时装它的 `<pre>` 是
   `max-height:50vh; overflow:auto` —— **一条竖滚动条按设计就该有**。
   探针的 `--seed-accounts` 影子账号只带远端 `avatar_url`（探针环境里失败几次很正常，
   `ProxyImage` 三级兜底会处理掉）⇒ 不排掉它，这条判据就变成
   「跑这轮时恰好有 3 张图没加载出来」的**抛硬币**（实测：抬高上限后 10 视图 × 3 档
   一起报 30 条 `原生滚动条 PRE`，全是它）。

## 三、修法：让药丸行接受容器约束

```css
.stat-sets { width: fit-content; max-width: 100%; }   /* ← 新增 */
.stat-set  { width: 100%; justify-content: center; }  /* ← 新增（保持居中，像素不变） */
/* .stat-pill 不用动：它已 overflow:hidden ⇒ flex 的 min-width:auto 解析为 0，本来就能缩 */
```

窄窗下 3 枚药丸**横向压扁**（徽章美术是 `background-size:100% 100%` ⇒ 压扁而不是裁切）
从 191 → 约 161（1100）/ 约 125（960）。**没选换行**：换行会破 R45-C 的「行数 ≤2」不变量；
也没选"窄窗降成每行 2 枚"（那要改 `HeroView` 里写死的 `perRow = 3`，且探针的
`每行=[3,3]` 判据要跟着改）—— 两条都留作备选，见 `docs/TODO.md` §0 的 R48 备注。

## 四、判据与反向验证

| 层 | 判据 |
|---|---|
| 探针 | 三档 × 10 视图全过（`[ok] 全部宽度 × 视图通过`）；R45-C 药丸仍是 `行数=2（≤2）｜每行=[3,3]` |
| 反向验证 | ① 把 `.stat-sets` 的 `max-width:100%` 去掉 ⇒ `@1100 cards` 当场红（原句复现）；② 把上限打回 `.slice(0,30)` ⇒ **同一处又变绿**（证明这条判据此前确实空转）；③ 不排除 `#boot-diag` ⇒ 30 条原生滚动条报红 |

> ② 「这个**置顶徽章放置在右上角更好**，不要占掉标题位置」。

## 一、标题为什么变成了 `cv409088396`（两层根因）

先去库里看真数据（`posts` 里那条 弥月 的置顶帖）：

```
type='image'  title='cv409088396'  summary='[9P]'
body_json={"text": "小博兔们我来啦！我是家里蹲小博士弥月Mizuki~\n每天下午三点晚上九点直播哦！\n…"}
body_text='小博兔们我来啦！我是家里蹲小博士弥月Mizuki~\n…'
```

⇒ **内容一直都在**（`body_json.text` / `body_text` 好得很），是"标题从哪来"这两层都错了：

| 层 | 根因 | 修法 |
|---|---|---|
| 后端 | `fetcher._extract_dynamic_title` 的 `cv<id>` 兜底**没有按 major 类型设防**（docstring 写的是 ARTICLE，代码对**所有**类型都生效）⇒ DRAW/OPUS 的 `data.id`（opus/专栏 id）被当标题存了 | 只有 `ARTICLE` 才用 `cv<id>` 兜底；其余类型没有标题就**返回空串** |
| 后端 | `_extract_dynamic_text` 对 DRAW 返回 `[<n>P]`（图片张数）当正文 ⇒ 摘要成了 `[9P]` | DRAW **只把 title 当正文**；张数是结构信息（`body_json.images` 本来就有） |
| 前端 | `postDisplayTitle` 的兜底链是 `title → summary 前 20 字 → pid`，既没过滤占位串、也没看正文 | 改成 `title → **正文首行** → summary → pid`，并跳过占位串；另加 `postDisplaySummary`（卡片第二行同样过滤） |

**为什么展示侧也必须改**：后端修好只影响**以后抓到的**；库里已经存下的 `cv…` 不会自己消失 ——
R35 的置顶刷新写字段时是"**空值不覆盖**"，所以那条帖子的 `title` 会一直是 `cv409088396`
（这是刻意保留的口径：宁可留旧值也不要把已有内容抹成空）。所以「哪些值不是内容」这件事
必须有**统一的判定**（`isPlaceholderText`：`cv<数字>` / `[nP]` / `[OP]`），展示侧认得出才治得了存量。

**实测（探针跑同一份副本库）**：那条真置顶卡的标题从 `cv362939894` 变成
「你好⌯>ᴗo⌯ .ᐟ.ᐟ我是飞过阴霾和绝望，身披虹光，用声音治愈你给你带来力量的」✓（正文首行）。

## 二、徽章挪到卡片右上角（第一版错在哪）

第一版把它放在**正文顶部**（标题上面），于是标题被挤到第二行。用户要的是卡片右上角。

挪的时候踩了一次：把徽章塞进 `.post-card-cover`（卡片里唯一的定位祖先）⇒ 它落到了**封面**右上，
探针量出"距卡片右缘 **290px**"，一眼看穿。正解是让它做 `.post-card` 的直系子元素
（卡片补 `position: relative`），钉 `top: 8px; right: 8px`；标题用
`.post-card.is-pinned .post-card-title { padding-right: 58px }` 在**右端让位** ——
标题仍占自己那一行（两行截断不变），只是文字不会跑到徽章底下。

## 三、判据（`ui_probe.py --pinned`，对**每一条**置顶卡）

原判据是"第 1 张是种子帖 + 有角标" —— 这批发现它有两处松：

1. **"第 1 张"这个断言不成立了**：开发库里现在**已经有真置顶帖**（R35 上线后被抓到并标上），
   副本会继承它们；真置顶帖比探针种的 2020 年那条新，按 `is_pinned desc, published_at desc`
   就该排在前面。改钉真正的不变量：**置顶帖构成列表最前的连续块**（种子帖在块内、对照帖在块后）。
2. **几何判据只量种子帖 = 没牙**（反向验证当场抓到）：种子帖标题很短，"标题不让位"那种坏法照样全绿。
   改成**每条置顶卡都量**五条：

```
右内距 8px（4–14）· 上内距 8px（4–14）· 是胶囊宽（≤80px）· 在卡内 · 在卡片右半区
外加：徽章不与标题**文字**相交（Range 量字形）
```

> ⚠️ 那条"不压标题"必须用 **Range 量字形**，不能用元素盒：标题有 `padding-right` 让位，
> 盒子仍然横跨到徽章底下 —— 拿盒判**必然假红**（第一版就是这么错的）。

**反向验证 3/3 全红**（逐条改回坏行为）：

| 坏行为 | 判据反应 |
|---|---|
| 徽章挪回正文顶部（`position: static`） | 红：宽 258px（不是胶囊）+ 不在右半区 |
| 标题不给徽章让位（`padding-right: 0`） | 红：徽章压住标题文字（1000 vs 标题文字右缘 1040） |
| 徽章塞进封面（第一版的错法） | 红：右内距 290px + 不在右半区 |

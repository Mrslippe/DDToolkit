# 652-20261026-图表栏：整页滑动、浮动箭头、池子说明进卡片

用户三条（附截图）。

## ① 池子说明位置不对

原来 `pool-rule` 渲染在图表行**末尾**，悬在右侧空白处。
现在作为「核心度分层」卡的 `footer`，放在卡片**内部**（饼图下方），语义也对：
这句话解释的就是那个池子。

## ② 箭头不再挤压卡片

改为 `position: absolute` 浮在卡片之上（左右各一，`top: 50%`），
默认 `opacity: 0; pointer-events: none`：

- **鼠标进入图表区** → 淡入；
- **离开** → 淡出；
- **切页签** → 自动显示 1.6 秒再隐藏（提示"这里可以翻"）。

容器不再为箭头让出宽度，两列卡片始终占满整行。

## ③ 翻页 = 整页滑动

- 一页固定 **2 张**卡片；
- 所有页排成一行（`flex`，每页 `flex: 0 0 100%`），
  用 `transform: translateX(-页号 × 100%)` + 260ms 缓动做滑动动画；
- 页码显示 `1 / 2`（页数，不再是"第几张到第几张"）。

## 一、退不出去：托盘「退出」根本没接上前端

**根因（代码级）**：托盘菜单的 `quit` 分支做了两件事 —— `show_main_impl()` + `emit("shell:quit-requested")`，
然后**等前端确认**再 `invoke(quit_app)`。可是：

```bash
$ grep -rn "quit-requested" frontend/src
（空）
```

**前端没人监听这个事件** ⇒ 点了托盘「退出」只是把窗口唤回来，什么都不会发生。
选过「最小化到托盘」之后这个 bug 最刺眼：那时 ✕ 只是隐藏，**托盘成了唯一出口**，
而唯一出口不通 ⇒ 只能去任务管理器杀进程。

（深休眠还有第二层：隐藏 10 分钟后 WebView 被销毁，唤回时前端**刚重建、监听还没装上**，
事件同样会丢。所以"发事件让前端退出"这条路本身就不该是主路径。）

### 修法：托盘退出**不依赖前端**

| 场景 | 行为 |
|---|---|
| 没有手动任务在跑（含"问不到后端"） | **直接退**：置 `QUITTING` → `app.exit(0)` → 走既有清理（kill sidecar + Job Object） |
| 真有手动任务在跑 | 唤回窗口 + `emit("shell:quit-requested")` → 前端弹确认框（退出 = 中断本轮 / 最小化到托盘 = 让它跑完） |

判据来自后端：Rust 直接问 `GET /vtuber/fetch-status` 的 `manual_running`（sidecar 端口本来就在
`BackendPort` 里）。判断故意做得粗 —— 把响应去空白后找 `"manual_running":true`（uvicorn 可能回
chunked，正文会多分块长度前缀；为这一处引 HTTP 客户端或手写分块解码不值当，字段名是我们自己的）。
**问不到一律按"没在跑"**：用户点的是退出，不能因为问不到就退不出去；但也不会把"在跑"误判成"没在跑"
（那会在用户毫不知情时掐掉一轮抓取）——两条都写进了 Rust 单测（`cargo test`，2 条）。

前端同时补上监听（`shell:quit-requested` → 打开既有的忙碌确认框），覆盖"真有任务在跑"那条路。

## 二、设置窗口的两个渲染问题

1. **选项胶囊被挤成竖排单字**（`每次询问` / `最小化到托盘` / `直接退出`）：那三枚胶囊原本落在
   `.aps-row` 的**右侧控件列（132px）**里，三个排不下就被压成一字一行。
   新增 `.aps-row-stack` 变体：**说明占一行、控件落到下一行占整行左对齐**（只用于胶囊类控件，
   其它字段仍走默认两列栅格），并给 `.aps-radio` 加 `white-space: nowrap`。
2. **`**粗体**` 原样显示**：界面文案是**纯文本**渲染，而我在两处后端文案里写了 Markdown
   （`close_action` 的说明、`DYNAMICS_MIN_CYCLE_SECONDS` 的说明）。全部改成纯文本，
   并**加了一条用例扫这件事**（`test_user_facing_copy_has_no_markdown_markers`：遍历
   SPECS / 只读表 / prefs 规格表的 label·unit·effect·note·why·option，出现 `**` 或反引号就红）——
   源码注释里到处是 `**`，靠肉眼 review 是发现不了的，只能扫数据字段。

## 三、护栏：新探针 `--close-ask`

托盘菜单本身是 OS 级、无头浏览器点不到；但"首次点 ✕ 询问"这条链路的前端一半全能断言：

```
偏好：'ask' → 选托盘后 'tray' → 复位 'ask'
询问框：弹出=True 选项=['tray','quit'] 记住勾选=True 关闭=True
选项文案：['后台继续抓取 · 界面停止刷新与轮询 · 隐藏 10 分钟后释放界面内存', '结束进程，不再抓取']
隐藏：选托盘后=True ｜ 再点 ✕ 又弹框=False 隐藏=True
[ok] 首次询问：ask 弹框（两选项+记住）→ 选托盘写偏好并隐藏 → 再点不再问
```

两处探针侧的坑，都留了注释：
- **窗口控制钮在非 Tauri 环境是 `disabled`**（浏览器里没有窗口可关）⇒ 点不动。改为走 TopBar 暴露的
  dev 钩子 `__ddtoolkitCloseClick`（挂的是**同一个 handler**，不是复制逻辑）。
- **`Presence` 陷阱第二次踩到**：判"询问框关了没有"必须看 `data-state`，不能看节点在不在
  （退场动画在虚拟时间下不跑完，节点一直在）—— R14a 记过一次，这次写进探针注释。

# 010-20260804-v0.2.4-拆分发现脚本与精简服务器

## 概述

将批量发现/导入 VTuber 的功能从服务器拆分成独立脚本，服务器仅保留单个 VTuber CRUD。

## 新增：独立发现脚本

[scripts/discover_vtubers.py](scripts/discover_vtubers.py) — 可独立运行，不依赖项目模块：

```
python scripts/discover_vtubers.py                    # 全量获取
python scripts/discover_vtubers.py --min-fans 10000   # 粉丝 >= 1万
python scripts/discover_vtubers.py --limit 50         # 仅前 50 名
python scripts/discover_vtubers.py --concurrency 10   # 10 并发
```

**流程**：
1. 从 `vdb.vtbs.moe/json/list.json` 拉取 VTuber 名单（3000+ 人）
2. 筛选 B站官方账号
3. 并发获取粉丝数（默认 5 并发）
4. 按粉丝数降序排列
5. 写入 `vtubers.txt`（昵称 uid 格式）

## 服务器精简

**移除的端点**：

| 端点 | 原因 |
|------|------|
| `GET\|POST /vtuber/import` | 批量导入移至独立脚本 |
| `GET\|POST /vtuber/reload` | 同上 |
| `GET\|POST /vtuber/discover` | 直播区扫描移至独立脚本 |

**保留的端点**：

| 端点 | 说明 |
|------|------|
| `GET /vtuber/list` | 列表 |
| `GET /vtuber/{id}` | 单个查询 |
| `POST /vtuber` | 单个新建 |
| `PUT /vtuber/{id}` | 单个更新 |
| `DELETE /vtuber/{id}` | 单个删除 |
| `GET\|POST /vtuber/fetch` | 手动触发抓取 |

**移除的函数**：
- `importer.discover_from_live_area()`
- `importer.import_from_text()`
- `fetcher.fetch_live_area_vtubers()`

## 工作流

```
# 1. 首次部署：用脚本批量发现
python scripts/discover_vtubers.py --min-fans 10000

# 2. 启动服务器（自动从 vtubers.txt 导入）
uvicorn app.main:app

# 3. 日常添加单个 VTuber
curl -X POST localhost:8000/vtuber -H "Content-Type: application/json" \
  -d '{"name":"新主播","platform":"Bilibili","bilibili_uid":"123456"}'
```

# 672-20261027-为什么只有"入场时滞"那张图会动

用户观察：切页签后饼图与折线都不动，但「入场时滞分布」的坐标点会**慢慢出现**。

## 这个差异本身就是证据

那张图会动，说明 **ECharts 的原生初始动画是能播的**；
其余图不动，说明它们的**初始化时机**不满足 ECharts 播初始动画的条件。

我们这几个图之间唯一的差别就是"init 时数据是否已就位 / 容器是否刚布局完"：
ECharts 只把**第一次 `setOption` 携带的数据**当作入场动画的起点；
如果那一刻容器宽度还没稳定、或数据在同一个 tick 才到，它会认为"没有需要动画的变化"，直接画出来。

## 修法：先空、再真

```ts
api.current = echarts.init(host)
api.current.setOption(emptyData(option), true)   // 第 1 帧：series.data = []
requestAnimationFrame(() => api.current?.setOption(option, false))  // 第 2 帧：真数据
```

- **饼图**：空 → 有值 走 `expansion`（扇区从中心扫入）；
- **折线/柱状**：空 → 有值 走描边 / 生长。

之前试过"值全 0"，失败原因是 **0 值扇区不占角度**，对饼图等于没有变化。
换成空数组才是真正的"从无到有"。

## 为什么这不是"伪动画"

数据仍然由 ECharts 自己从空状态插值到目标值，走的是它原生的
`animationDuration / animationEasing`；我们只是把"给数据"这一步拆成两帧，
避开它对初始化时机的敏感。

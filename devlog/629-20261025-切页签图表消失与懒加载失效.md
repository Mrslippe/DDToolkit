# 629-20261025-切页签后折线图消失、加载更多失效

两条都是上一轮「去掉面板 key 防闪烁」引出的回归。

## 一、折线图不见了

ECharts 实例用 `api.current ??= echarts.init(host)` **只初始化一次**，并把画布绑在当时的 DOM 节点上。
切到别的页签时 React 换掉了那张图的宿主 `<div>`（总览专属），再切回来是新节点，
但 `??=` 让旧实例（绑定在**已脱离文档的节点**上）继续被使用 ⇒ 画到看不见的地方 ⇒ 图消失。

修法：新增 `ensureChart(api, host)` —— **宿主变了就 `dispose()` 重建**：

```ts
if (api.current && api.current.getDom() !== host) { api.current.dispose(); api.current = null }
api.current ??= echarts.init(host)
```

三张图（分层环形 / 核心度分布 / 单轴分布）统一走它。

## 二、加载更多点了没反应

闸门原来是 `loadingMore` 这个 `useRef`。**ref 一旦被某条异常路径留在 true，就永远拦住后续点击**
（不像 state 会随渲染复位）。

修法：改用 `busy` + `hasMore` 两个 state 判断，去掉 ref：

```ts
if (busy || !hasMore) return
void loadRanked(TAB_BY[tab], rows.length, true)
```

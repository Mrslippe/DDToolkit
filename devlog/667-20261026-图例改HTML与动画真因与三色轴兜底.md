# 667-20261026-图例改 HTML、动画双播真因、三色轴兜底

## ① 饼图图例消失

ECharts 自带 `legend` 在**窄卡片**里会被算成 0 宽度而不渲染（不是配置写错）。

修法：图例改由 **React 渲染**（`.wb-pie-legend`），ECharts 只负责画饼。
颜色点 / 名称（超长省略）/ 数值都在我们手里，`max-height + overflow-y` 可滚动。
同时把饼图 `label/labelLine` 全关 —— 顺带解决"昵称被裁最后一个字"。

## ② 场均弹幕横轴右侧全 100%

`(1-10^-x)*100` 在 x→3.3 时全是 `100.00`。改为**高分段显示三位小数**：

```
p >= 0.99 → p.toFixed(3)   // 0.990 / 0.995 / 0.999
否则      → p.toFixed(2)
```

## ③ 切页签动画播两次 —— 真因是**数据到达**

不是重挂载，也不是 `run`：

1. 切页签 → `loadRanked` 发请求；
2. 卡片先用**旧 charts** 挂载（播第 1 次动画）；
3. 新数据回来 → `charts` 换新对象 → `option` 变 → effect 里 `dispose+init` 又播一次。

修法：`EChart` 改为接收 `playKey`（= `页签:翻页计数`）：
- `playKey` 变了 → 销毁重建（播动画）；
- `playKey` 没变 → **只更新数据**（`setOption({...option, animation:false})`），不重建。

## ④ 付费三色轴"又不见了"

排查发现是**兜底写法**的锅：分类金额缺失时我先返回了纯文字 `¥26,660`，
于是整列看起来"没有轴"。而这次改动又引入次数估算分支，反而让"金额与次数都缺"的行落回纯文字。

修法：三层兜底

1. 有 `g/gd/sc` → 真实三色轴；
2. 只有次数 → **按次数比例分摊**总额（tooltip 标注"按次数估算"），仍是三色轴；
3. 什么都没有但有 `pay_total` → **单色总额条**（tooltip"缺分类明细"）。

后端名单行同时补了 `gift_cnt/guard_cnt/sc_cnt` 三个字段，让第 2 层能用上。

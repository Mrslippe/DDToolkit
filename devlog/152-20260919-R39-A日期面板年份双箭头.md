# 152-20260919-R39-A日期面板加年份双箭头

> 用户 2026-09-19 四条前端改动里的第 ① 条：
> 「list 视图中的筛选按钮呼出的下拉栏，选择年份那一行的按钮**只能单月跳跃**，
> 如果要选取很早的年份就很麻烦，所以可以在箭头旁**再加一个双箭头**，用来**直接调节年份**」。
> 拍板：**双箭头 ±1 年**（不做 ±5 年、不做弹年份列表）。

---

## 一、做法

- `DateRangePicker` 每块月历的箭头改成**成组**：左组 `[上一年][上个月]`、右组 `[下个月][下一年]`，
  标题仍在整块的几何中心（`space-between` 由两个组承担）；
- 跳年 = **`shiftMonths(month, ∓12)`** —— 复用已有的月位移口径，**不新写日期算术**
  （月末夹取、闰日这些边界早就被 `check_date_range.mjs` 钉住了）；
- 双箭头比单箭头弱一档（`opacity: .75`）：主操作仍是翻月，跳年是快捷方式；
- `data-nav="year"` + `data-dir="±1"` 下发给探针（探针按它点击对账）。

## 二、护栏

**纯逻辑**（`scripts/check_date_range.mjs`，+4 条）：年份跳复用的就是月位移，所以把"跳一年"的
边界也钉一遍 —— `02-28 进一年`、`闰日进一年`（2024-02-29 → 2025-02-28）、`12-31 进一年`、
`01-31 退一年`。

**探针**（新增一帧 `list-filter-year`）：**先红后绿**。只断言"按钮在不在"是不够的 ——
**粒度错了照样能绿**（比如双箭头还是跳一个月），所以它**真的去点**：

| 判据 | 说明 |
|---|---|
| 每块可见月历 `yearBtns == 2` | ±1 年各一枚 |
| 每块可见月历 `monthBtns == 2` | **原有行为不许被挤掉**（两个组都要在） |
| 点「上一年」⇒ 年份 **正好 −1** | `y0 − y1 == 1` |
| 跳年时**月份不变** | `m1 == m0`（只跳年，不顺手挪月） |
| 再点「下一年」⇒ 回到起点 | `y2 == y0`（两个方向都能用） |

反向验证：实现前跑 ⇒ **5 条红**（两帧 × 2 块面板 + "找不到年份双箭头"），实现后归零。

## 二、缩放模型：改「每场的像素」，不是改 `scrollLeft`

可视范围 = `clientWidth / 轨宽`，而 `clientWidth` 是容器固定的 ⇒ **只能改轨宽**。

```ts
const step = (BAR + GAP) * scale        // scale ∈ [0.6, 6]
innerWidth = total * step + 4
```

与 ECharts dataZoom 同构：缩放就是改这个比例。

- **滚轮** = 平移（`scrollLeft += deltaY`，竖直滚动量转横向）；
- **Ctrl + 滚轮** = 缩放，**以光标为锚**：先记光标下的场次（连续值），缩放后把同一场挪回光标下；
- **下方缩放条**：拖中间 = 平移，拖两端 = 缩放（`nextSpan = width ± dx` → 换算回 `scale`）。

原生横滚条**隐藏**（`scrollbar-width: none`），由缩放条取代。

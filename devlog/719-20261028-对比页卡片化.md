# 719-20261028-对比页卡片化重排（E 批）

## 用户口径

> 对比页也用卡片风格重新设计。

并明确选**允许重排信息层级**（不是我给的第一版"只把三块包成卡片、顺序不动"）。

## 重排后的四张卡

| 卡 | 内容 | 空态 |
|---|---|---|
| ① 选择主播 | 模式切换（多主播 / 帖子评论）+ 已选 chips + 「这些主播还没有分析结果」警示 | — |
| ② 重叠矩阵 | 矩阵（格子 = Jaccard）+ "点一格看配对详情" | 「再选一位主播就能看到重叠率」 |
| ③ 配对详情 | Venn + KPI（共享 / Jaccard / lift / p(BH) / 富集或贫化）+ 层级迁移 | 「点矩阵里的任意一格」 |
| ④ 评论交集 | 整块 `CommentComparePane`（抓取 → 覆盖 → 分层 → 交集名单） | 内部自带 |

为什么把**矩阵和详情拆成两张卡**（原来它们挤在一个 `.wb-compare-grid` 里）：
矩阵是"选哪一对"的入口，详情是"这一对说明什么"，两件事视线不同频 ——
挤在一起时用户在矩阵里点完，眼睛要往右跳一大段才找到读数。拆开后矩阵独占一行、可横向长，
详情自己一卡，宽屏仍用两列（Venn 左、读数右）。

## 一致性

- 空态文案直接用 `ResultCharts.EMPTY_TEXT`（与结果区同一句「暂无数据」），
  卡片壳用同一个 `.wb-empty-card`（同样有 176px 下界，不会塌成一条线）；
- 这套"先画卡框、再填内容"的口径与 A 批（`devlog/715`）一致 —— 两个页面不再各写一套空态。

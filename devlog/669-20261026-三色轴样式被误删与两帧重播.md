# 669-20261026-三色轴"不见"= 样式被误删；动画改两帧重播

## ① 三色轴的真正原因：**CSS 整块被删了**

`Select-String -Pattern '\.wb-mix' workbench.css` → **0 条命中**。

也就是说组件一直在正常渲染 `.wb-mix / .wb-mix-bar / .wb-mix-text`，
但这三个类**没有任何样式**：`inline-flex` 的容器没有宽高、内部的 `i` 高度 100% × 0 = 0，
于是只剩旁边的文字 `51% / 23% / 26%` —— 看起来就是"三色轴不见了"。

删掉它的是之前一次"从某个标记替换到文件末尾"的 CSS 大改（补轮播样式时），
把追加在末尾的三色轴样式一起覆盖掉了。

修法：补回样式，并在注释里写明"**以后再改 workbench.css 的大块，记得 grep `.wb-mix`**"。

> 教训：`.wb-mix` 这类"组件渲染了但样式没了"的 bug，从组件代码完全看不出来。
> 判断方法只有一个 —— **数一下 CSS 里这个类还有没有规则**。

## ② 动画：不再依赖"初始动画"

之前所有方案都建立在"ECharts 初始化时会播初始动画"这个假设上：
容器宽度为 0、resize 打断、数据晚到……任何一个都会让它静默跳过。

改成**两帧重播**，不依赖任何 ECharts 内部时机：

1. `init()` 后第 1 帧：`setOption(zeroed(option))` —— 所有 series 数据置 0（空图）；
2. 第 2 帧：`setOption(option)` —— 真数据，ECharts 从 0 长到目标值。

`zeroed()` 保留维度与名称（饼图仍然是那几个扇区，只是值 0），所以视觉上是
"扇区从无到有填充 / 柱状图从 0 长高"。

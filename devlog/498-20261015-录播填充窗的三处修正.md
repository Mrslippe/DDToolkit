# 498-20261015 录播填充窗的三处修正（层叠 / 录播号就地改 / 探针补上）

## 用户报的三条（2026-10-15，带截图）

1. 「假设我现在一个没记录的日期新建了一个录播记录，然后又在详情页中点开了编辑按钮……
   **新弹窗的出现让背景遮罩更深色了一点，直播场次详情窗却没有变化**，这让这两个弹窗的层级
   像是混在了一起」⇒ 要么新遮罩盖住二级窗，要么把小弹窗彻底改成下拉栏；
2. 「点开加号按钮后的**录播号设置应该要在这里就可以设置**，不然用户还得去其他入口查找」；
3. 「点击扫描录播并自动填充后，半透明黑色遮罩盖住了窗口，此时**点击任意处都会直接关闭窗口，
   无法选中按钮**」。

## 第 3 条：真机探针量出来的根因（不是猜的）

新加探测臂 `--vod-fill` 第一次跑就打出来了：

```
层叠：遮罩={'zIndex': '60'} 面板={'zIndex': '50'}
命中：面板中心=False（被遮罩拿走=True 命中元素='div.fixed'）勾选框可达=False
```

**面板在遮罩底下**。`.lvc-fill` / `.lc-ms` **没写 z-index** ⇒ 吃 Radix 基座的 `z-50`，
而它们自己的遮罩（`.lc-dlg-backdrop`）是 **60** —— 于是点哪都被遮罩当"点外部"吃掉，
既关窗又选不中按钮。`.lc-dlg`（场次详情）之所以没这个毛病，只因为它**显式写了 61**
（注释里甚至写着"面板 z=61"，但两个后来者只是"以为"继承得到）。

⇒ 修法不是补一个数字，是**把层叠变成命名的层**：

- `tokens.css` 加 `--z-dialog-6: 60` / `--z-dialog-7: 70`；
- `posts.css` 用 `data-slot='dialog-overlay'` / `'dialog-content'` 两条**兜底规则**
  给全族兜住（遮罩 = 第 6 层、面板 = 第 6+1 层），面板**不再自己猜数字**；
- 要在二级窗**之上**再开一层，加 `lc-dlg-layer` ⇒ 第 7 层（70/71）。
  这同时满足了第 1 条（新遮罩盖住底下的详情窗，两层不再"混在一起"）
  —— 用户给的选项里选的是"小弹窗出现时让新遮罩覆盖二级窗"。

修完复跑：`遮罩 70 → 面板 71 · 面板中心=True（命中 span.lvc-vod-title）· 勾选框可达=True
· 点「写入」之后仍开着=True`。

## 第 2 条：录播号就地可改

`+` 下拉的第三项本来是 `disabled` +「在档案设置里改」——等于把**前置动作**（加录播号）
指到别的入口去。新增 `components/live/VodAccountDialog.tsx`（复用 `.lc-ms` 外壳）：
输入 mid、逗号分隔、**左边优先**，写 `PUT /vtuber/{id}` 的 `vod_account_uid`；
留空发 `null`（清空）。真机探针对应判据：`录播号项=True(可点=True)`。

**面板中心点命中的是不是面板自己** + 勾选框可达 + 点按钮不关窗 + 层号严格递增。

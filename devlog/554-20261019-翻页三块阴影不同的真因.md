# 554-20261019-三块浮片阴影不同的真因：两种构造

用户把日历与工作台的按钮并排，指出阴影差异明显。

## 真因：**不是同一套构造**

| | 日历 | 工作台（改前） |
|---|---|---|
| 左右箭头 | `FloatPill` → 阴影来自 `::before` | 同左 |
| 中间那块 | `FloatPill` → 阴影来自 `::before` | **普通 `<button>` + 自己的 `::before`** |

两边都用 `--pill-shadow`，但**元素的行高/内距不同**，`box-shadow` 在两个不同盒子上
投出来的观感就不一样；更糟的是普通按钮那条配方是我手写的，少了 `--pill-h-sm` 的高度约束。

## 顺带查出的两个坑

1. **`:has()` 在这个 WebView 不支持**：我写的 `.float-pill:has(.wb-hm-year-text) { min-width }`
   从来没生效过 —— 这就是中间那块宽度时好时坏的原因。以后别在关键尺寸上依赖 `:has()`。
2. **窄行里的浮片会互相叠压**：`FloatPill` 是 `inline-flex` + `flex-shrink: 0`，容器放不下时
   既不换行也不溢出，而是**相互叠压**；放大 4 倍能看到中间那块上边缘有一条不跟随斜切的直线
   （底下压着另一个浮片）。已给 `.wb-hm-head` 加 `flex-wrap: wrap` + `row-gap`。

## 改法：三块**同一套配方**

```css
.wb-hm-years > button { …height: var(--pill-h-sm); background: transparent… }
.wb-hm-years > button::before { …var(--pill-bg)/var(--pill-radius)/var(--pill-skew)/var(--pill-shadow)… }
```

三块用同一个选择器、同一组 token ⇒ 阴影/斜切/圆角**由构造保证一致**，不再靠两次手写对齐。

# 666-20261026-饼图图例带数值、出席轴抽稀、分位对数轴

## ① 饼图空白处给图例（颜色 + 名称 + 数值）

新增 `pieOption(data, money)` 统一构造：**关掉外侧标签**（`label/labelLine` 全 false），
改为左侧竖排图例，`legend.formatter` 里拼上数值（`名称  ¥12,345` / `名称  12,345`），
`type: 'scroll'` 保证条目多时可翻。

顺带修掉 **④ 昵称被裁最后一个字** —— 那是外侧标签撞到画布边缘导致的，标签关掉就没有了。

## ② 出席页切页签动画播两次

切页签时卡片 `key` 变了 → 组件**重新挂载** → 初始动画本来就会播一次；
而我又在 `useEffect([tab])` 里 `setRun(v+1)`，等于要求"再播一次"。

修法：**切页签不再 bump `run`**（`run` 只服务于"翻页"这种不换卡片的场景）。

## ③ 出席分布横轴太密

`axisLabel.interval` 从 `0`（每个刻度都画）改回 `'auto'` + `hideOverlap: true`，
场次 70+ 时自动抽稀，不再糊成一片。

## ④/⑤ 场均弹幕分位曲线

两处改动：

1. **数据侧**：分位点从"等距 20 桶"改为**尾部加密**（…0.95, 0.97, 0.99, 0.998, 0.999, 1.0），
   且尾部窗口取前 **0.5%**（常规取 5%）—— 否则最右一档被普通用户稀释
   （实测最大值从 36.7 → **136.7** 条）。
2. **显示侧**：横轴从"分位字符串"改成 **value 轴 + `x = -log10(1-p)`**，
   刻度再映射回百分比显示；这样"最活跃 1%"那一截被真正展开。

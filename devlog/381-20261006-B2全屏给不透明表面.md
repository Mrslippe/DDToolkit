# 381-20261006 B2 第二刀：全屏给一个**不透明表面**（对照成熟播放器）

> 第一刀（`devlog/379`：复位圆角 + 去掉压在视频上的毛玻璃）之后用户实测**还是卡**，
> 并给了方向：「参考一下其他成熟播放器的全屏策略」。这一刀就是那个对照的结果。

---

## 一、对照：成熟播放器的全屏凭什么不卡

| 谁 | 全屏时它有什么 |
|---|---|
| YouTube / B 站网页播放器 | 跑在**不透明**页面里（视频层能被提升到 **硬件覆盖层**）；播放时**控件层整块撤掉**，页面里没有别的图层陪着画 |
| mpv / VLC / PotPlayer | 直接占一个**不透明全屏表面**，视频走**独立交换链**（D3D），UI 是另一层、播放时基本不画 |
| **我们（改前）** | ① 窗口 `transparent: true` ⇒ **WebView2 整页走 alpha 合成**，视频拿不到覆盖层，每帧都要 GPU 采样 + 混合再与桌面合成；② 面板自己的背景层（`.hero-backdrop` 图片 + 纱罩）在全屏时**仍留在合成树里** |

用户实测口径正好卡在这两条上：**B 站不卡 · 应用内非全屏不卡 · 小窗不卡 · 全屏卡**，
面板 240Hz —— 面积一上来，alpha 合成那笔账就付不起了。而"透明"是壳的既定视觉
（修四角白边 / 配 DWM 圆角，见 `layout.css` 顶部注释），**不能为了播放永久改掉**。

## 二、这一刀做了什么

1. **壳新增命令 `set_surface_opaque(on)`**（`lib.rs`）：一行落到 WebView2 的
   `DefaultBackgroundColor`（wry → `set_background_color`）——`Some(黑 255)` = 不透明表面，
   `None` = 回到透明。进了 `COMMAND_ACL`（注册表 ↔ 准入表对账用例自动覆盖）。
2. **播放器进全屏时开、退出/卸载时还原**（`VideoPlayer.tsx`）：`fs` 那条 effect 里调它，
   并在 `<html>` 挂/摘 `data-video-fs`。⚠️ 卸载也要还原 —— 否则"看过一次全屏"之后窗口一直不透明。
3. **CSS：全屏时把页面自己的背景层撤掉**（`html[data-video-fs] .hero-backdrop { display:none }`）：
   配套那一行属性的另一半 ——"一个干净的不透明表面"要两边都做（属性让 WebView2 不走 alpha，
   这条保证没有别的图层陪着画）。第一刀已经做过的圆角复位 / 玻璃片去 blur 仍然有效。
4. **浏览器/探针里静默退化**：`shellBridge.setSurfaceOpaque` 在非 Tauri 环境直接返回。

## 三、判据

- `VideoPlayer.keys.test.tsx`：进全屏 ⇒ `setSurfaceOpaque(true)` + `data-video-fs='1'`；
  退出 ⇒ `(false)` + 属性消失；**卸载** ⇒ 也必须 `(false)`（三条断言）。
- `BackdropCrossfade.css.test.ts`：`html[data-video-fs] .hero-backdrop` 必须 `display:none`。
- 壳侧：注册表/准入表对账（既有 `cargo test`）· `cargo test` **67 passed**。

## 四、这一刀没做什么 / 如果还卡

- **没动窗口的 `transparent: true` 本身**（只在全屏期间切表面色）——永久不透明会影响壳的视觉；
- **没加"主线程长任务"仪表**（`PerformanceObserver('longtask')`）：若这一刀还不解决，下一步就是它
  —— 那时要区分的是"我们自己每 0.5–1s 的周期性活儿（状态岛秒表 / 通知 / 进度轮询）把合成器拖住"
  与"驱动/窗口合成"；
- 真机复现口径不变：dev 壳（HMR）全屏放十几秒，看
  `Select-String -Path E:\test\DDToolkit-data\logs\app.log -Pattern "\[video\] seek" | Select-Object -Last 3`
  的 `全屏=1 · 丢帧=x/y · 最长停顿 · 后段 fps`（改前基准：`丢帧=9/268 · 最长停顿=0.06s · 后段=30.0`）。

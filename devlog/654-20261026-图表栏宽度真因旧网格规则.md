# 654-20261026-图表栏填不满的真因：一条遗留的 `.wb-charts` 网格规则

上一版我加了一堆 `width: 100%` 却没用 —— 因为**根因不在宽度**。

## 真因

`workbench.css` 里还留着改造前的一条规则：

```css
.wb-charts {
  display: grid;
  grid-template-columns: minmax(0, 0.9fr) minmax(0, 1.1fr);
  gap: 12px;
}
```

轮播改造后，`.wb-charts` 的子元素只剩 `.wb-charts-viewport`（箭头和页码是绝对定位，不参与布局）。
于是 viewport 被放进**第一列**（0.9fr ≈ 全宽的 45%），第二列空着 ——
卡片自然只有半屏宽。截图里右侧那片空白就是那个空列。

## 修法

把这条规则改成 `display: block`（宽度交给 `.wb-charts-page` 的两列网格），
之前加的 `width: 100%` 保留（无害且更明确）。

## 教训

**"加宽度"之前先看容器是不是网格/弹性布局**。`width: 100%` 对一个 `grid` 子项来说
只是"在它那一列里占满"，不会让它跨列 —— 所以两次都白改。

以后遇到"内容只占一半"，第一步应该是**把目标元素的 `display` / `grid-template-columns`
打出来看**，而不是先加宽度。

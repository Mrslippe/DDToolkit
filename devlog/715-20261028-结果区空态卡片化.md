# 715-20261028-结果区空态卡片化（四批改造的第 1 批）

## 需求

用户 2026-10-28 提的四条前端改进，第 1 条：

> 在还没分析的时候分析结果页就采用现在这样有结果的卡片样式，但是卡片内容用空态文本
> （暂无数据请先进行采集）填充。

## 为什么不是"加一句更长的提示"

原来结果区空态是一句孤零零的文本（`请先选择时间范围进行分析`）。问题不在文案，在**信息**：
用户看不出分析完成后这里会出现**哪些卡**，只能靠点一次采集再等一分钟才知道页面长什么样。
空态照画卡片框，等于提前把"这份数据能回答哪些问题"摆出来。

## 做法

| 文件 | 改动 |
|---|---|
| `components/workbench/ResultCharts.tsx` | 新增 `EMPTY_CARDS`（每个页签的卡片目录：标题 + 副标题，**逐字抄自真实卡片**）、`EMPTY_TEXT`、`empty` 分支 |
| `components/workbench/RankedTable.tsx` | 新增 `empty` 分支：保留卡壳与「名单」标题，去掉表格/搜索/标签/导出 |
| `pages/WorkbenchPage.tsx` | 结果区 `else` 分支从一句文本换成「空态卡片组」；对比页单独一张卡 |
| `styles/workbench.css` | `.wb-empty-card`：`min-height:176px` + 居中 |

三个刻意的取舍：

1. **空态把该页签的卡一次全列出来**（真实态是两卡一页 + 翻页箭头）。空态没有"第几页"的概念，
   而用户该一眼看到全部；有结果时仍按两卡一页翻。
2. **空态不渲染搜索/标签/导出/翻页箭头**：没数据时它们是四个"点了没反应"的按钮。
3. **对比页单独一张卡**，不去假装有矩阵：对比需要先有名单，硬画一个空矩阵会让人以为坏了。

## 一致性怎么守（这块最容易腐坏）

`EMPTY_CARDS` 是真实卡片标题的**副本** —— 副本就会漂。所以
`components/workbench/resultEmpty.test.tsx` 用**真实数据渲染一遍**，把渲染出来的
`.wb-card-title` 与目录逐字比对（四个页签各一条）。改标题只改一处，这条用例当场红。

另外三条：空态卡数量 == 目录长度、卡片里有空态文本、名单卡 `data-empty="1"` 且
**没有** `ranked-table` / `export-csv` / `ranked-search`。

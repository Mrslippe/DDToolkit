# 030-20260905-v0.6.1-阵营=企划=公会·档案卡精简为两列

## 概述

用户语义定稿：**阵营 ≡ 公会 ≡ 企划**（同一概念）。档案卡原本有三处相关条目
（阵营 Select 编辑行、「企划·公会」只读行、英雄区徽标），按用户要求
**精简为两列：企划 | 公会**；侧栏阵营标识槽位（`.vtuber-emblem`）未来
接线**企划**值；**公会先放着**（只读占位，不做任何接线）。

## 数据现状（调研结论）

第三方索引（danmakus→laplace vup-slim）`type` 只有
`vtuber / group / fan / unknown`，**没有企划/公会标签**；每 VTuber 一条
`group_name`（七海→VirtuaReal、Ranao→纸片人计划…），另有 143 条
`type='group'` 团体节点（极光社/边迹社…，含企划型与公会型，同样无标签）。
→ 本版**无需后端改动**：企划 = 现有 `faction` 字段（= 原阵营），
公名列 = 占位「未收录」，待数据源区分企划/公会后再接管。

## 改动清单

1. **ProfileCard.tsx（档案卡）**：
   - 原「阵营 Select 行 + 企划·公会只读行」合并为**一行两列**：
     - **企划列**：label「企划」+ Select 编辑（沿用 faction 字段与乐观更新，
       选项建议/「采纳」来自第三方 `group_name` 不变）+ 未来接侧栏企划槽；
     - **公名列**：label「公会」+ 只读占位「未收录」（先放着）；
   - 生日/出道/房间行不变；`rows` 数组移除「企划·公会」项；
   - 报错文案「阵营更新失败」→「企划更新失败」。
2. **文案改名 阵营→企划**（用户确认）：
   - 侧栏筛选弹窗：分区标题「企划」、触发器 title「组合筛选（状态 / 平台 / 企划）」；
   - 英雄区徽标 `.pill-logo` 字「阵」→「企」（`.faction-badge` 类名沿用）；
   - 注释/页签文案（ArchiveView「企划 / 公会 / 设定」等）同步；代码标识符
     （faction/Filters.faction）不变，避免无谓 churn。
3. **样式**：posts.css 新增 `.profile-card-group-row` / `.profile-card-group-col`
   （与 profile-card-row 同尺度的同行两列）。
4. **UI-MAP**：B2/B3 档案卡行、C3 筛选弹窗、企划槽/企划徽标行、
   信息层成员注记同步；阵营语义注记（阵营=企划=公会）。
5. **未做（按用户「之后/先放着」）**：侧栏 `.vtuber-emblem` 企划值接线、
   公列数据来源（等数据源区分企划/公会）、后端模型改动。

## 验证

- `tsc` 通过；`vite build` 通过。
- 手动验收：档案视图 ProfileCard 显示「企划（Select）｜公会（未收录）」两列；
  采纳按钮/Select 编辑仍写原 faction 字段；侧栏筛选弹窗出现「企划」分区；
  英雄区徽标首字「企」。

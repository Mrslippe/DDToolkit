# 642-20261025-各页前四列一致；明细列改成弹性列

用户两条：前几列列宽应跨页一致、最后一列吃剩余宽度；非总览页的滚动条会挤列宽。

## 根因

`table-layout: fixed` 下，**列宽总和超过容器就会在 `.wb-table-wrap` 里出现横向滚动条**。
各页签的列集合不同（出席页有 412px 的明细列、互动页比总览多两列），
一旦超出，滚动条占掉宽度 ⇒ 各列被重新分配 ⇒ 看起来"列宽变了、还被挤压"。

## 改法

1. **前四列（序号 44 / 头像 52 / 昵称 190 / 强度 78）在所有页签写死同一组**；
2. **每个页签的最后一列都是 `<col />`（无宽度 = 吃剩余）** —— 互动页额外补了一个空表头列兜底；
3. 出席明细列原本写死 412px，改为**弹性列**：
   - 方块改成 `repeat(20, minmax(0, 1fr))` + `aspect-ratio: 1`，随列宽等比收缩（上限 14px）；
   - 浮层里仍是固定 14px（`repeat(20, 14px)`），保证"20 格一行"的可读尺寸。
4. `.wb-table-wrap` 加 `scrollbar-gutter: stable`：真需要横向滚动时也不会让列宽抖动。

## 验收

前端 1,582 passed；`tsc` 干净；`npm run build` 成功。

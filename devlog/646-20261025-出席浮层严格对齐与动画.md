# 646-20261025-出席浮层：严格逐格对齐 + 进出场动画

上一版"看起来差一点"，根因是**两处内边距不一致**：

- 定位按 `-8px` 补偿；
- 但浮层实际 `padding: 10px 12px`（早期规则留下的），而且还有 `margin-top: 8px`。

于是格子整体偏右下，怎么都压不准。

## 修法

1. **单一来源**：删掉早期那条 `.wb-bits-pop` 规则（绝对定位 + 10/12 内边距），
   只保留一条 `position: fixed` 的规则，`padding: 8px`、`margin: 0`；
2. 定位补偿用常量 `PAD = 8`（与 CSS 同值，注释里互相指认，改一处必须改另一处）；
3. 默认区与浮层的方块几何完全相同（20 列 × 14px + 6px），所以第 N 格**必然**压在第 N 格上。

## 动画

- 进场：`wb-bits-in` 140ms，`opacity 0→1` + `scale .94→1`，`transform-origin: top left`（从原格子处张开）；
- 退场：`wb-bits-out` 120ms，先标记 `is-closing` 播动画，结束后才卸载（否则动画没机会播）。

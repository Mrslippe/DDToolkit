# 265-20260930 D1 视觉：小窗按样例页上材质与墨色（顺带修掉「判据自己坏了」与拆入口第 7 次）

用户看完 D1 的落地说：「小窗样式和动画应该以样例页 `docs/design/widget-preview/direction.html`
作直接指导，**当前的形式仍与样例页中的样式有很大差距**」。
—— 复核后确认他说得对：D1 那一批我只搬了**几何与参数**（宽/圆角/方向/内容槽位），
**没有搬视觉系统**（材质、阴影、墨色、排版、入场动画）。本文记这一批。

## 一、判据先行：先在小窗坐标系里把"现在长什么样"量出来

新增 `ui_probe --status-widget` 的「视觉」一段（测量在探针侧、判据在脚本侧）：
把胶囊与面板的**卡面 / 阴影 / 内距 / 计数底**，以及面板里 12 处**墨色**
（标题 / 正文 / 活数据 / 补充说明 / 来源行 / 图标 / 动作钮的三项 / 页脚 / 分隔线）
原样带出来，再按 α 复合到**纯白与纯黑两端壁纸**算对比度（与胶囊那条同一套算法）。

未改一行代码时的现场：

```
视觉·胶囊：底='rgba(20, 20, 26, 0.94)' 圆角=20 内距='12px'   阴影=<只有 inset 高光>
视觉·面板：底='rgba(20, 20, 26, 0.97)' 阴影='rgba(15, 23, 42, 0.1) 0px 4px 16px 0px'
视觉·墨色：title/itemText='rgb(75, 90, 107)'  meta/icon/foot='rgb(91, 108, 126)'
          divider='rgba(210, 216, 222, 0.55)'
```

**这些全是"浅色主题"的全站令牌**（`--c-text-main` #4b5a6b / `--c-text-sub` / `--c-border` /
`--shadow-dialog`）—— 铺在深色卡片上：正文 **≈2.2:1**（几乎读不出来）、
面板阴影是**浅色阴影**（深卡上等于没有）、动作钮是一颗**白药丸**（`--c-bg-card` 白底 + 深粉字）。

⚠️ **为什么以前全绿**：既有的判据全是**几何**（在不在视口内 / 点不点得着 / 三段不重叠 /
图标尺寸 / 字体族）—— 它们**一个颜色都不看**。"面板画得出来、点得着"与"面板读得出来"
是两件事，而前者有一整段判据、后者一条都没有。

## 二、搬了什么（数值全部照 `direction.html` 的深卡一套）

新增一组**小窗宿主自带的令牌**（`.si-island[data-density='widget']` 与
`.si-panel[data-density='widget']` 两处都挂 —— 面板是 portal 到 `body` 的，继承不到胶囊）：

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--wg-surf` | `rgba(24,25,32,.92)` | 胶囊与面板的底（同一块材料） |
| `--wg-hi` / `--wg-ring` | `rgba(255,255,255,.10)` | 顶边高光 + **1px 描边** |
| `--wg-fg` / `--wg-faint` | `#fff` / `rgba(255,255,255,.52)` | 正文 / 弱一档（活数据 · 补充说明 · 来源行 · 页脚 · 提示） |
| `--wg-line` | `rgba(255,255,255,.08)` | 分隔线（原来是浅色**虚线** `--c-border`） |
| `--wg-icon-bg` / `--wg-chip-bg` | `.10` / `.16` | 图标圆底 / 计数徽章底 |
| `--wg-action` | `#ffa2b4`（= `--c-primary`） | 动作钮描边与文字（深卡上 9.3:1） |
| `--wg-shadow` / `--wg-shadow-open` | inset 高光 + ring + **三档外阴影** | 折叠 / 展开 |

具体差异（**每一条都有判据**）：

1. **外阴影**：产品原来**只有 inset 高光** —— 卡片是"贴"在壁纸上的。样例页给的是
   `0 2px 5px / 0 9px 22px / 0 22px 54px`（展开态更重一档）＋ 一圈 1px 描边，
   靠它在**任意壁纸**上勾出边缘。**这是与样例页差距最大的一处。**
2. **墨色**：面板里 12 处颜色改成自带的一套（上表）；动作钮从"白药丸"改成
   样例页的**描边胶囊**（透明底 + 动作色描边，悬停反色成实心）。
3. **图标**：套上样例页的 **15×15 圆底 chip**（`.p-icon`），图标本身缩到 11px
   （chip 里放 13px 太挤）；颜色按**紧迫度**（告警红 / 进行中琥珀 / 其余前景色）——
   原来 `report` 用的 `--c-primary-deep`（#c9406f）在深卡上几乎看不见。
4. **排版**：头部内距 `11px 14px 9px` + 标题**居中** + 提示绝对定位到右上；
   条目内距 `8px`、间距 `9px`；列表内距 `0 6px 6px`；页脚居中 `8px 14px 10px`。
5. **胶囊槽位**：左内距 12 → **14px**；字形 `opacity .72`；活数据用弱一档；
   计数 15 → **16px**、底 `.28` → **`.16`**。
6. **入场动画**：`220ms` 的 `si-panel-in`（**永远从上方滑下**）改成样例页的节奏 ——
   **140ms（`--motion-fast`）+ 延迟 60ms（`--motion-lag`）**、"形变先行、内容后到"，
   并**按方向选 keyframes**：向下展开从上方滑下、向上展开从下方滑上
   （方向写在 `<html data-widget-dir>` 上 —— 面板是 portal 到 `body` 的，
   `.widget-shell` 不是它的祖先，挂在那儿它看不见）。
   ⚠️ 收起时**不清**这个属性：留着上一次的方向，下次展开的**首帧**动画就是对的
   （方向要等几何量完面板高才知道，而面板挂载时动画已经开播；清了会让贴下沿的小窗
   每次展开先朝下播一帧再换成朝上 —— `animation-name` 一变动画**重头再播**，看着是抖一下）。

## 三、两处**故意偏离样例页**的地方（都留了理由与数）

1. **`--wg-faint` 用 .52 而不是样例页的 .44**：按 α 复合到两端壁纸后，.44 实测
   **3.99:1**（探针给的是量出来的数，不是我手算的 4.01）—— 低于全站「小字 ≥4.5:1」的口径。
   **只抬 alpha、色相不动**（与 2026-09-24 胶囊那次同一个处置）。
   反向验证：把 .52 改回 .44 ⇒ 探针报 5 条墨色不符 + 2 条对比度不足（3.99:1）⇒ 当场红。
2. **图标 chip 里放的是 lucide 图标，不是样例页那个文本字形**：样例页的面板图标与胶囊字形
   是同一个字符；产品面板用的是 lucide（`KIND_ICON`）。改成文本字形要动 `StatusIsland` 的
   JSX 且**同时改掉顶栏宿主的面板观感**（那份没在本次范围内）⇒ 保留 lucide、只加 chip 与配色。

## 四、⚠️ 判据自己坏了一次（值得单独记）

第一版「阴影层数」判据写成 `len(sh.split("),")) < 3` —— **恒为 1 层**，于是修复之后
仍然报"只有 1 层"。原因：CSSOM 的序列化里**层之间是 `, `**（每层以 `rgba(...)` 开头），
`"),"` 这个子串**一次都不出现**。
⇒ **判据自己坏了，看起来和产品坏了完全一样**（两条红、文案还挺像回事）。
修法：层数改由**探针在浏览器侧**数（`split(/,(?![^(]*\))/)` 按括号深度切）。
与 devlog/189 那条同源 —— **反向验证要挑真的能破坏它的改法；改不动就说明这条断言是装饰**，
而这里是它的反面：**断言自己写错了，会伪装成"产品有毛病"**。

## 五、拆入口第 7 次：`@keyframes si-panel-in-fade` 只在 `layout.css` 里

顺手发现的：`prefers-reduced-motion` 那条分支（写在**共用**的 `status-island.css` 里）
引用 `si-panel-in-fade`，而这条 keyframes 只定义在 `layout.css` —— 小窗不加载那个文件
⇒ 小窗在 reduce 下引用一条**不存在的动画名**（等于没有入场）。
**搬家**（不是复制）到 `status-island.css`，`layout.css` 里留一条指针注释。
这是 DEV-LOOP §6.1 那条纪律的第 7 次（前六次：preflight 的 box-sizing · `.os-*` ·
`setApiBase` · dev token · 胶囊解剖 · 字体族）。

## 六、判据

- 探针 `--status-widget` 新增「视觉」一段：**19 条**（4 条材质/尺寸 + 12 条墨色 + 层数 2 条
  + chip 3 条 + 排版 2 条 + 动画 2 条 + 对比度 4 条；合计按报告里的条目数）；
  其中"对比度"那几条是墨色表的**理由** —— 只钉"值对不对"会让"为什么是这个值"失传。
- ⚠️ 探针的注入条目从**一条加到两条**（第二条带 `detail` 与 `action`）：
  一条时 `count` 徽章与 `.si-item + .si-item` 分隔线**在 DOM 里根本不存在** ⇒
  那几条判据会静默空转（"没量到"与"量到且正确"在报告里长得一样）。
- 反向验证：`--wg-faint` .52 → .44 ⇒ 5 条墨色 + 2 条对比度报红，逐字节还原（sha256）；
  另修准两处**判据自身**的错（层数、chip 圆角判 `50%` 而不是 `parseFloat` 出来的 50）。
- 门禁：`gate.py` B 档 6 步全过（tsc / eslint / doc_check / syntax / ui_probe 三档 / vitest 820）。

## 七、没做的（明确留白）

- **样例页的 F1**（展开后胶囊那一行整行隐藏、窗口 = 面板高）：仍未做 —— 产品里胶囊
  **同时是拖动把手**（面板 portal 到 `body`，指针事件不经过窗口壳），要一起做"面板也能拖"。
  这是本线与样例页**最后一处结构性差异**（样式差异本批已补齐）。
- **浅色主题 / W1 主题广播**：现在只有深卡一套（样例页的 `[data-theme=light]` 那套没接）——
  小窗浮在**浅色壁纸**上时的观感仍未定，那正是 W1 的活。
- **面板的滚动模型**：样例页是"高度跟内容、不滚动"（`.p-body { overflow: hidden }`），
  产品用 `OverlayScroll` + 按屏幕算的 `max-height` —— 条目多时前者会顶出屏幕，
  **这是产品有意的偏离**，不与样例页对齐。
- 真机项：入场动画的**方向**（上/下两态在探针里跑不到）、阴影在真实壁纸上的观感、
  四方向手感 —— 只能真机看。

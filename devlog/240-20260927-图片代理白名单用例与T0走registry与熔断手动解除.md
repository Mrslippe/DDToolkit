## 一、图片代理白名单**逐条**用例（`tests/test_img_proxy_hosts.py`，32 条）

破图的机制链是**三处一起改**：前端 CSP `img-src`、`IMG_PROXY_ALLOWED_HOSTS`、`_referer_for`
（微博图床不带合法 Referer 会 403）。漏改中间那处的症状是**静默的**（不报错，一片破图），
接小红书时就是手工补的两个域名（devlog/231）。

三层判据：

| 层 | 判据 | 错了会怎样 |
|---|---|---|
| **逐条** | 每个平台**真实出现过**的封面/头像 URL（含子域）都要被接受 | 破图 |
| **同批** | "平台 → 图床"表必须与 `registry.supported_platforms()` **同集合** | 新平台忘加域名，没人提醒 |
| **反向** | 近似域名（`i0.hdslb.com.evil.com`、`hdslb.com@evil.com`）、内网/元数据地址一律 403；白名单里不留**没有任何平台在用**的死条目 | 代理成了 SSRF 跳板 / 死配置 |

顺带锁定三个既有细节：主机名大小写不敏感、端口被剥掉、裸域名也接受；以及
`_referer_for` 的平台映射（小红书**不给** Referer）。

## 二、T0 直播状态**走 registry**（不再写死 B 站）

这是平台框架里**最后一处硬编码**（EXECUTION §1.4 的 ⑤）：`scheduler.py` 直接
`import fetch_bilibili_live_batch`，并写死 `platform == "bilibili"`。

- `BasePlatform` 新增能力位 `supports_live_batch`（默认 False）与
  `fetch_live_batch(uids) -> {uid: {...}} | None`；B 站在 `platforms/bilibili.py` 实现；
- T0 改成**按平台分组 + 按能力筛选**：不支持的平台**记一条日志**后跳过
  （§1.4 边界②：不支持不许静默丢弃，但也不该计成失败 —— 它不是工作项）；
- **两件平台知识搬进适配器**：① 批量接口要 **int uid**（非数字 uid 不发给上游，自己记日志）；
  ② `live_batch` 端点的**熔断检查与结果上报**（与小红书适配器同一分层）。
  核心只认"问了 N 个、回来 M 个"，**没回来的一律计 `failed`**（并写进 details）；
- `split_numeric_uids()` 从 `scheduler.py` **删掉**（它的语义是 B 站的，住在核心里就是错的），
  对应的保障改由两条用例盯着：适配器过滤 + 核心计 failed。

## 三、熔断**手动解除** + 可见性

- `identity_limit.Ledger.forget(platform)`（只清内存）+ 已有的 `clear_windows(db, platform)`
  （清落库）；`scheduler.clear_breaker(platform, db)` 两处一起清 —— **只清内存的话，
  重启会把刚解除的熔断"想起来"**；
- **入口 = 用户的显式动作**（不需要新 API 与新 UI）：按名抓帖子（`async_fetch_vtuber_posts`）
  与抓账号信息（`async_fetch_accounts`，含收录/加账号那条 fast 路）都会先清该平台的熔断。
  口径与 R27 一致：**显式意图优先**（自动档跳过冷却、手动档照跑）；
- **可见性**：`fetch-status.breaker` 上报各端点窗口（`tripped`/`samples`/`risk`/`risk_targets`）
  —— 熔断是"这个端点暂时不发请求"的沉默决定，不上报的话用户分不清"平台不动了"和"没内容"
  （同 R12a 修风控可见性的理由）。

## 四、顺手修掉一处测试污染（与上一条无关）

`test_services.py` 里 `monkeypatch.setattr(sch._dynamics_pacer, "gap_min", 0.12)` ——
`gap_min` 是**带 setter 的 property**，monkeypatch 的撤销走 `setattr`，于是它把值
**永久钉进实例**（`_gap_min = 当时的设置值`）⇒ 模块级 pacer 从此不再现读 settings，
`test_dynamics_backoff.py` 的"热更后立刻按新值排"会红（**只在按文件顺序跑时复现**，
单跑那条是绿的 —— 典型的顺序依赖）。改成**自己造一个固定值的 pacer**。

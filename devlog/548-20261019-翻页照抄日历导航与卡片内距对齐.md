# 548-20261019-翻页照抄日历导航、卡片内距对齐

## 一、右上角翻页：终于找对了参照物

用户："可以直接参考直播日历卡片上的按钮实现。"

读了 `LiveCalendar` 的导航行，和我写的差别在两处：

| | 日历 | 我之前的 |
|---|---|---|
| 尺寸 | **不传 `size`**（默认 25px） | `size="sm"` |
| 图标 | `ChevronsLeft/Right` + `.lc-nav-icon` | `ChevronLeft/Right` + 内联 `size={13}` |
| 结构 | `FloatPill shape="icon"` 包图标 | 同（但被 sm 挤掉了） |

**`size="sm"` 把图标挤没了** —— 26px 方钮减去内距后容不下 13px 的 svg。
现在整段**照抄**：`<FloatPill shape="icon"><ChevronsLeft className="lc-nav-icon" /></FloatPill>`，
中间用 `<span className="lc-nav-text">`，外层再加 `lc-nav` 类复用日历那套间距。

## 二、卡片内距对齐

`.wb-chart-card` 原为 `padding: 12px 14px`，比主卡片 `18px 20px` 紧一档 ——
两张图并排放在结果卡里时，边缘对不齐。改成与主卡片同档（gap 10 保留，因为它是嵌套卡）。

顺手复核了整屏的量度，现在是：

| 元素 | 字号 / 内距 |
|---|---|
| 页标题 `.wb-title` | 17px |
| 卡片标题 `.wb-card-title` | 13px |
| 读数标签 / 数值 | 11px / 15px |
| 提示 `.wb-hint` | 12px |
| 卡片内距 | 18 × 20（主卡与图表卡一致） |

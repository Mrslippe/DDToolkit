# 556-20261019-年份菜单文字溢出：一条遗留的后代选择器

现象：点开年份菜单，每一行都套着一个白块，文字挤到框外。

## 查法

菜单只有在展开时才可见，探针的截图默认是收起的。做法：**临时把 `pick` 初值改成 `true`**，
截图 + 裁图放大 —— 立刻看见每行都是一张**独立白卡**（圆角、边框、阴影），文字被挤到右边。

## 真因：一条遗留规则用**后代选择器**漏进菜单

`workbench.css` 里还留着统一配方之前的旧规则：

```css
.wb-hm-years button {          /* ← 后代选择器，不是 > */
  width: 24px;
  height: 24px;
  border: 1px solid var(--c-border);
  background: var(--c-bg-card);
  box-shadow: var(--pill-shadow);
}
```

年份菜单 `<div class="wb-hm-year-menu">` 就在 `.wb-hm-years` 里面，于是**菜单里每一行**
也被当成翻页按钮：24px 高 + 白底 + 边框 + 阴影 ⇒ 看起来像一叠卡片。
我后来加的 `.wb-hm-year-menu button { background: transparent; border: 0 }` 只能盖住
背景与边框（同优先级、位置更后），**盖不住只在这里出现的 `box-shadow` 和固定 `height`**。

## 改法

1. **删掉那条遗留规则**（翻页三块已由 `.wb-hm-years > button` 统一配方负责）；
2. 菜单行改成整行块级、居中、`::before { content: none }` 兜底。

## 教训

**同一组件的样式规则，最后一定要收敛成一条 `>` 精确选择器**。这条遗留规则存在了好几轮，
每次我都在下游（菜单、按钮）打补丁，而它在上游持续污染。

## 验收

前端 **1565 passed**、lint 0、`tsc` 干净、文档门禁 0 FAIL。
裁图确认：菜单是**单张白面板**里的五行年份，文字居中且完整在框内。

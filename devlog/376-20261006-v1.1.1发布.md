## 一、为什么是 1.1.1 而不是并进下一个功能版

`devlog/375` 的全部价值都在"用户拿得到"这件事上：v1.1.0 的产物里**没有** `extension\`，
只下载 Release 的新用户在当前版本上**装不了扩展**。这类"补上一件本该有的东西、但不引入新行为"
的改动就是补丁版的形状（patch 位），所以走 1.1.1。

## 二、这一版给用户的那一件事（写给 Release 页看）

装完/解压完，程序目录里就有 `extension\`（直装版 `<安装目录>\extension\`、便携版
`DDtoolkit\extension\`）；「设置 → 登录 → 浏览器扩展」显示**绝对路径** + 「打开目录」+ 装法三步。
扩展本体与 v1.1.0 那份一致（同源图标、`manifest.json` / `src` / `icons`，不含 `test/`）。
⚠️ 从**仓库目录**改成从**安装目录**加载的用户，扩展 id 会变 ⇒ 要重贴一次配对 token
（数据目录里的凭据不受影响）。

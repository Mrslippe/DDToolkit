## 一、三个被真机推翻的原方案

| 原方案（F2 存档那版） | 真机实测 | 改成 |
|---|---|---|
| **可变画布**：按相位边界 `SetWindowPos` 改窗口尺寸 | 固定画布多花 ≈ 2 MB 内存 + ≈ 0.05 ms/帧 blit，idle CPU 无差别 | **固定画布**：窗口尺寸恒定，开合只改窗口**内**的 `--card-x/y/w/h`（四个量同时长同缓动一起过渡）⇒「近边恒等 / 居中恒等」变成机械结论，`resize_widget_window` 这条命令不需要了 |
| **穿透**：动态 `WS_EX_TRANSPARENT` + ~25 ms 轮询 | 顶层窗口加该样式后，WebView2 的子窗口 `Chrome Legacy Window` **照样收得到命中**；`WM_NCHITTEST` 在 WebView2 下**压根不触发** | **`CreateRoundRectRgn` + `SetWindowRgn`**：区域**同时裁剪绘制与命中**（子窗口一并在内），区域外的指针直接落到桌面，**零轮询** |
| **拖动**：`startDragging()`（平台移动循环） | 拖动期间我们的代码一行都不跑 ⇒ 夹取/方向全无 | **自研 pointer**：`setPointerCapture` + `screenX/screenY × scaleFactor`，**夹卡片**，每帧重算抓取偏移 |

- 区域是 **1 bit 掩码**：不外扩就会把圆角的抗锯齿边切成锯齿 ⇒ `WIDGET_REGION_SLACK = 2` px
  （真机核对：区域 `172,229 → 433,273`，卡片 `(174,231) 257×40`）。
- 固定画布下 `CANVAS_W = PANEL_W + 2·PAD + (PANEL_W − CAP_MIN_W)`：展开态面板原地放下，
  胶囊贴边时也放得下 ⇒ 开合**永不碰窗口**，跨屏/贴边只剩纯数学。

## 二、"点一下就闪白框"其实是三个不同的东西

用户先后报了两次（① 点击时 ② 按住拖动起手）。三个来源叠在一起，逐个验掉：

| # | 来源 | 治法 |
|---|---|---|
| 1 | DWM 系统边框与圆角 + 窗口被激活 | `DWMWA_BORDER_COLOR` 取"无色" + `DWMWCP_DONOTROUND` + `set_shadow(false)` + `WS_EX_NOACTIVATE` |
| 2 | 点击时**清了区域**（区域一变系统要重画一次） | 点击**不碰区域**；`pointerdown` 也不再清 hover 定时器（那会掐掉展开动画） |
| 3 | **拖动起手清区域**（`set_widget_dragging(true)` 把区域放成整窗） | 该命令改成**只打日志**，跟手交给 `setPointerCapture`（实测指针滑出卡片 300 px 仍一路跟手） |

- ⚠️ 1 里的三样在窗口"隐藏 → 显示"时会被系统**重置** ⇒ 每次 `set_widget_hit_rect` 都要**幂等重刷**一遍。
- ⚠️ 顺带补的 `set_background_color(transparent)`：不设的话 WebView2 的底色是白的，
  窗口移动重绘的空档会露出白底 —— 这也是白框家族的第四个来源。

## 三、提炼（与"还有没有小窗"无关）

- **取证手法：临时垫一块纯黑背景 + 逐帧 `BitBlt` 数"接近纯白"的像素。**
  "闪白框"是**渲染层**现象，无头探针永远看不见，而肉眼只能判断"好像闪了一下"。
  做法：临时置一个全屏黑色 topmost 弹窗垫在窗口下面 ⇒ 采样矩形里只剩目标窗口本身；
  按窗口矩形逐帧取色、数近白像素；**自检**：垫一个白窗，计数必须立刻拉满（实测 632×530 = 334,960）。
  本次实测：hover 10 帧 / 按下 10 帧 / 26 步位移 78 帧 / 松手 12 帧，**白像素数恒定 26、一个像素都不变**。
  已落到 `docs/DEV-LOOP.md` §6。
- **"不闪"是结构性质，不是调参结果**：只要"改形状"这件事**只发生在看不见的那一帧**，
  白框就不可能出现在看得见的动画里。反过来，任何"在用户操作的那一刻顺手改一下窗口形状"的代码
  都会闪 —— 这次的三个来源全是这一类。
- ⚠️ **本机 pwsh 5.1 把 `.ps1` 当 GB2312 读**：临时脚本里写中文注释会被解成乱码，
  **行尾 LF 被双字节序列吃掉** ⇒ 若干行粘成一行、报"意外的标记"。临时探针脚本**只写 ASCII**。
- **最小实现的边界要写下来**：这一版**故意不接**数据层（无偏好键 / 无 API / 无事件）、
  不写 `shell.log`、不用 `OverlayScroll`、不做浅色材质与全屏隐藏、不含 `music` 第五类
  （数据层里根本没有这一类）。边界不写清楚，下一步接线时会分不清"没做"和"做漏了"。

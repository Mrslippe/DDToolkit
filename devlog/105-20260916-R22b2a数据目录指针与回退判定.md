## 一、为什么需要"指针文件"

数据目录现在是壳在 `setup()` 里算出来的：`app.path().app_data_dir()` ⇒ `%APPDATA%\com.ddtoolkit.app`
（dev 构建加 `-dev` 后缀），再由 `spawn_backend()` 以 `DDTOOLKIT_DATA_DIR` 注入给后端。
要支持迁移，就得有个**壳下次启动能读到**的持久记录 —— 而且它**不能放在数据目录里**
（用户把旧目录删掉就一起没了）。所以放在与数据目录**平级**的固定位置：

```
%APPDATA%\DDToolkit\data-dir.txt      ← 一行绝对路径
```

## 二、本批落地的东西（`frontend/src-tauri/src/datadir.rs`）

| 函数 | 干什么 |
|---|---|
| `pointer_path()` | 指针文件位置（没有 `APPDATA` 时返回 `None`，整套机制自动停用） |
| `read_pointer_at()` / `read_pointer()` | 读指针：**没设过 = `Ok(None)`**（新用户就是这种，不是错误）；设过但用不了 = `Err(原因)` |
| `write_pointer_to()` / `write_pointer()` | **原子写**（临时文件 + rename）：中途断电不会留下半个路径 |
| `clear_pointer()` | 迁回默认目录时清掉 |
| `resolve_with()` / `resolve_data_dir()` | 折算"这次用哪个目录" |

**核心纪律（这一批的重点）**：指针**坏了必须回退默认目录**（旧数据还在那儿），
并把原因通过 `Resolved.pointer_unusable` **带给界面** —— 按仓库规矩，
"静默失败看起来像没数据"是不可接受的；**绝不在坏路径上新建一个空库**（那会让用户以为数据没了）。

结构上刻意两层：**纯函数**（路径由调用方给：`read_pointer_at` / `write_pointer_to` / `resolve_with`）
+ **薄包装**（用 `pointer_path()` 找真实位置）。用例测前者 —— 不是"抄一份逻辑再测一遍"
（第一版我正是那么写的，`cargo test` 之前自己改掉了）。

**用例（+6，`cargo test` 8 passed）**：指针路径是绝对路径且在 `APPDATA` 下 · 没设过不是错误 ·
空内容/相对路径/目录不存在三种坏指针都报错 · 写→读往返（含用户手改带引号与缩进）·
四种解析结果（有效/未设/坏指针回退+带原因/不允许时忽略）· 便携版场景传 `false` 时完全不走指针。

**接线方式**：`setup()` 里 `resolve_data_dir(default_dir, false)` —— **这一版指针停用**，
行为与之前逐字节一致（零风险），B2b 才会真正启用。

## 三、⚠️ 抓到的漂移：**"便携版"在代码里识别不出来**

`README.md` §数据目录 与 `GLOSSARY` 都写着"**便携版运行后可改 `DDTOOLKIT_DATA_DIR` 环境变量自定义**"。
实测（`lib.rs::spawn_backend`）：壳**无条件**用自己算出的 `data_dir` 覆盖这个变量：

```rust
.env("DDTOOLKIT_DATA_DIR", data_dir.to_string_lossy().to_string())
```

也就是说：

- **便携版现在也用 `%APPDATA%\com.ddtoolkit.app`**，与安装版**同一个数据目录**；
- 用户手动设的 `DDTOOLKIT_DATA_DIR` **不会生效**（被壳覆盖）；
- 于是**没有任何可靠办法判断"当前是不是便携版"** —— 而 B2 的决定之一是"只支持安装版"。

**这条必须先定**（它决定 `resolve_data_dir` 的 `allow_pointer` 怎么传、以及界面要不要显示迁移入口）：

| 选项 | 含义 | 代价 |
|---|---|---|
| **A. 让壳尊重用户设的 `DDTOOLKIT_DATA_DIR`** | 便携版真便携（数据跟程序走），"便携版"= 该环境变量已设置或数据目录在 exe 旁边 | 要改壳的启动语义 + 改文档；旧便携版用户的数据在 `%APPDATA%`，需要一次迁移/提示 |
| **B. 承认现实：不分便携版** | 文档改成"两种分发方式都用 `%APPDATA%`"，迁移**对所有用户开放** | 与"便携"这个词的直觉不符，但实现最简单、风险最低 |
| **C. 加显式标记** | 便携包带一个标记文件（例如 exe 旁放 `portable.flag`），壳据此决定 | 多一个约定与一处遗漏风险 |

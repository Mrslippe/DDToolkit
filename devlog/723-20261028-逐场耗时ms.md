# 723-20261028-逐场耗时 ms（四批改造收尾）

## 最后一个字段

四批改造清单里唯一还没落地的就是它：`sessions_detail[].ms`（单场耗时，毫秒）。

| 位置 | 改动 |
|---|---|
| `collector._mark()` | 新增 `ms: int \| None = None` 形参；**给了才写** |
| 采集循环 | `_t0 = time.monotonic()` 在 `fetch_records` 之前；三处调用（ok / 上游无数据 / 记录太少）都带上 `_elapsed_ms` |

## 两个刻意的取舍

1. **`ms` 给了才写，不写 0**。跳过（已采过）与前置失败没有"耗时"这个概念 ——
   写 `ms: 0` 比不写更误导（用户会以为这一场真的 0 毫秒就采完了）。
2. **`_mark` 是 `update` 而不是替换**。逐场条目在"开始抓这一场"时就带着 `title`/`start_at`
   建好了，结束时只更新状态字段 —— 如果整条替换，标题会被冲掉（浮窗就退回显示时间了）。

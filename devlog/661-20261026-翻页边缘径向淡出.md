# 661-20261026-翻页时的「边缘 → 中心」径向淡出

用户：下一页从外侧进来的位置太靠外，希望翻页瞬间左右两侧有从边缘到中心的径向透明度渐变。

## 做法

给裁剪框加一层 `::after` 遮罩：

```css
.wb-charts-viewport::after {
  inset: 0;
  pointer-events: none;
  background: radial-gradient(ellipse 88% 130% at 50% 50%,
              rgba(0,0,0,0) 52%, var(--c-bg-page) 100%);
  opacity: 0;
  transition: opacity 260ms ease;
}
.wb-charts.is-flipping .wb-charts-viewport::after { opacity: 1; }
```

- **只在翻页的 340ms 内**出现（`is-flipping`），静止时 `opacity: 0`，不会淡化卡片边缘；
- 渐变中心透明、边缘为**页面背景色** ⇒ 视觉上四边向中心"化开"，
  从外侧滑进来的下一页就是渐显而不是硬切；
- `pointer-events: none`，不影响箭头命中。

## 为什么用背景色而不是纯透明

纯透明等于没效果。要让"边缘淡出"，遮住边缘的必须是**背景色**；
本项目页面背景是 `--c-bg-page`，与卡片区一致，所以看起来就是自然的渐隐。

# 605-20261024-头像：删掉"先试 CDN"那一跳

用户贴的错误报告里，20 条 `[resource] https://workers.vrp.moe/api/bilibili/avatar/...` 全部失败 ——
说明前端仍在**先试 danmakus 的 CDN**，失败后才退回本地代理。

## 问题

- 那个 CDN 在服务端是 403（Cloudflare），在 Tauri webview 里同样拿不到；
- 于是**每个头像都先失败一次**：慢、且把错误上报器刷满（报告里 20 条同类错误）。

## 修法

- 后端 `/ranked` 只返回**本地代理路径** `/fan/avatar/<uid>`，不再暴露 CDN 地址；
- 前端只走 `resolveAsset(row.avatar)`，失败直接首字兜底，不再有第二跳；
- 注释里写明原因，避免以后"优化"成先试 CDN。

## 验证

真实接口取 8 行名单，逐个头像请求：

```
头像 7/8 成功 · 合计 16.2 KB（平均 2.3 KB）
```

第 8 个返回 200 但内容不是 JPEG（B 站图床有时给 WebP），浏览器正常显示 —— 是我的校验条件太严。

## 提醒

后端改了路由返回字段，**需要重启应用**才会生效；前端已 `npm run build`。

# 555-20261019-箭头"退化成点"：图标尺寸写进 CSS

现象：阴影统一之后，左右翻页的 `«` `»` 变成两个小点。

## 事实

- 组件里写的是 `<ChevronsLeft size={15} />`，`size` 会落成 `width="15" height="15"` 属性；
- 但截图放大后量，图标只有 ~4px；
- 补一条 CSS 后恢复：

```css
.wb-hm-years svg { width: 15px; height: 15px; display: block; flex: none; }
```

## 根因：**没有找到**（如实记）

我查了 `tokens.css` / `layout.css` / `posts.css`，**没有**任何全局 `svg { width: 1em }` 之类的规则
可以把 15px 压到 4px。所以"谁覆盖了它"这一环**没查实**。

可复现的结论只有一条：**在这个仓库里，图标尺寸要写进 CSS，别只靠 `size` 属性**。
至于为什么属性没生效（lucide 版本？WebView？`inline-flex` 下的 svg 固有尺寸计算？），
留给以后遇到再查 —— 但至少现在有判据：**看图量，不要看代码猜**。

## 教训

这是这一屏第五个"看起来像 A、其实是 B"的问题：

| 现象 | 真因 |
|---|---|
| 文字超出按钮 | 浮片互相叠压 |
| 中间块阴影不同 | 两种构造 |
| 宽度时好时坏 | `:has()` 不支持 |
| 箭头变成点 | 图标尺寸没落到渲染（细节未知） |

**共同点：全部是"看代码看不出来、必须量"的问题**。放大截图 / `outline` 量盒子 / 裁图对比，
比读 CSS 快得多，也准得多。

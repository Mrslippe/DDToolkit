# 020-20260822-v0.4.6-更新动态统计合并崩溃修复

## 问题

`POST /vtuber/update-posts`（更新未归档动态）扫到「动态里带投稿视频」的帖子
（type=video_dynamic）时，整个更新任务被 TypeError 中断：

```
TypeError: _safe_json_parse() takes 1 positional argument but 2 were given
  File "app/services/scheduler.py", line 562, in _fetch_posts_core
    feed_stats = _safe_json_parse(d.get("stats_json"), {})
```

## 根因

devlog/018（投稿统计补全）引入的两处调用按「合并进现有 dict」语义传了
第二个参数 `{}`，但 `_safe_json_parse` 的签名只有单参：
- 视频详情统计合并：`_safe_json_parse(d.get("stats_json"), {})`
- 专栏 delta 补全：`**_safe_json_parse(d["body_json"], {})`

此前未暴露是因为触发条件苛刻——需要动态流里恰好出现带投稿的视频类动态
且走到 detail 合并分支。

## 修复

`_safe_json_parse(s, fallback=None)` 签名扩展：
- 可选 `fallback` 参数（默认 `{}`），两处双参调用合法化；
- 历史单参调用完全兼容；
- 加固：解析结果为**非 dict 的合法 JSON**（如 `"[]"`、`"3"`）也回退
  fallback，杜绝后续 `**` 展开崩溃。

新增回归测试 `test_safe_json_parse_fallback`（9 断言），锁定双参/单参/
非法 JSON/非 dict JSON 四种形态契约。

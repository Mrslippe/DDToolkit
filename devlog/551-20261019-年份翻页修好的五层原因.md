# 551-20261019-年份翻页：五个原因叠在一起

用户连报三次"右上角翻页还是错的"。**不是同一个 bug 没修好，是五个问题一层套一层**，
每修一层才露出下一层。

## 五层

1. **图标没有尺寸**：`.lc-nav-icon`（13×13）定义在 `posts.css`，而它只随帖子页加载 ——
   工作台拿不到，`<ChevronsLeft />` 成了 24px 的裸 svg。
   → 改用内联 `size`，不依赖那个类。
2. **浮片按钮在窄行里塌成 0 宽**：`FloatPill shape="icon"` 在这个 flex 行里被压没了，
   换成文字箭头也不显示（说明是容器问题不是图标问题）。
   → 干脆不用浮片族，改成自带 `width/height` 的普通 `<button>`。
3. **热力图网格比卡片宽 6px**：53 周 × 13px = **689px**，而卡片内容区只有 ~683px。
   网格溢出把头部行整体撑宽，右侧翻页被卡片 `overflow: hidden` 裁掉。
   → `CELL: 11 → 10`（53×12 = 636px）。
4. **右箭头被 `disabled`**：2026 是最大年份，`opacity: .35` 让它像不存在。
   → 两端不 disable，改成 `Math.min/max` 夹住。
5. **中间那块被 flex 压扁**："2026" 只露出 "202"。`flex: none` 不够，还得显式
   `min-width: 74px`。

## 方法

前两次我是"改一处、猜一处"，因为**看不到渲染结果**。探针修通后每一步都能截图验证，
五层是一次一层扒出来的 —— 而且第 3 层（网格溢出 6px）完全不可能靠读代码发现。

## 顺带

- 滑杆底部那行不再重复日期（区间按钮已经写着范围）；
- `.wb-result` 的 `min-height: 200px` 收掉（空态拖出一大片白）；
- 中间那块只留年份 —— "共 184 场" 在滑杆那行已经有了。

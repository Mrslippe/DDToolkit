# 015-20260817-v0.4.1-帖子展示问题修复与图片混合兜底

## 概述

按前端使用反馈修复 6 类帖子展示问题（详情见 docs/项目架构分析报告 前端迭代），
并落地"直连 CDN + 代理兜底"的混合图片方案。含存量数据回填（均先 dry-run 后执行）。

## 问题与修复

### 1. 大量帖子无发布时间（3,450 条，已全部回填）

**根因**：动态抓取只解析 `module_author.pub_time` 字符串（'2025年04月21日'/'08月09日'），
`_parse_pub_time` 格式表不匹配 → 返回 None。

**修复**：
- `fetcher._parse_dynamic_pub_time(author)`：**优先 `pub_ts`**（unix 秒级时间戳，100% 可用），
  `pub_time` 兜底；`_parse_pub_time` 补 `%Y年%m月%d日` 格式；
- 回填脚本 `scripts/backfill_post_published_at.py`：3,450 条全部回填成功，剩余 0。

### 2. 转发帖文本为空（1,718 条，已重建 1,619）

**根因**：FORWARD 动态顶层 `module_dynamic.major` 为 **None**，原文在 `raw.orig`，
fetcher 未解析 → body_json={"text":""}、摘要/封面全空。

**修复**：
- `fetcher._extract_origin(item)`：从 `orig` 提取原文（类型/标题/正文/图片/封面/链接），
  body_json 产出 `{text: 转发附言, origin: {...}}`，summary=附言+原文，title="转发：xxx"；
- 回填脚本 `scripts/repair_repost_origin.py` A 段：1,619 条重建，剩余 87 条为 raw 无 origin 的边角；
- 前端抽屉新增 **OriginCard**（原文类型标签/标题/正文/图片/原文链接）。

### 3. 无标题帖 → 摘要前 20 字

前端 `postDisplayTitle()`：title → summary 前 20 字 → platform_post_id；列表列与抽屉标题统一使用。

### 4. 正文符号不渲染（换行/缩进） + Delta 富文本

- 纯文本正文统一 `whiteSpace: 'pre-wrap'`（换行/制表符保留）；
- **Quill Delta 富文本**（专栏 body_json.content 为 `{"ops":[...]}`，实测 12 条）：
  后端 `_is_delta_content`/`_delta_to_plain_text` 识别并补 `delta`/`text` 字段（回填 10 条）；
  前端新增零依赖 **DeltaRenderer**：header 1-3 / align / bold·italic·underline·strike / color /
  link / list（有序·无序）/ blockquote / indent / \t 缩进 完整渲染。

### 5. 直播预约卡片（raw 有但未提取，1,196 条已补全）

**根因**：预约数据在 `modules.module_dynamic.additional.reserve`，fetcher 未提取。

**修复**：`fetcher._extract_reservation(md)` → `body_json.reservation`
{status(0=可预约/1=已结束/2=已预约), button_text, desc1, desc2, reserve_total}；
回填 1,196 条；前端 **ReservationCard**（时间/预约人数/按钮态颜色）。

### 6. 多图只显示一张 / 部分图加载失败 → 混合图片方案

**实测**：body_json.images 与 raw 完全一致（最多 10 张，无丢图）；URL 为 `http://`（https 页面会被混合内容拦截）。

**修复（混合方案）**：
- 前端 `SmartImage`：直连 CDN（https 化 + no-referrer）→ onError 自动重试后端代理 → 代理失败显示占位块；
  点击预览默认走代理（防盗链最稳）；
- 后端新增 `/img-proxy`（`app/routers/img_proxy.py`）：主机白名单（默认 hdslb.com 后缀）、
  磁盘缓存（static/img-cache/{md5}，命中不回源）、Cache-Control 7 天、拉取失败 502；
- 后端防丢图兜底：detail 图片数 < feed 图片数时保留 feed images（opusBigCover 特性防护）。

## 补充：忽略直播开播动态（同日）

- **背景**：库中出现 2 条 type='live' 帖子，为 B 站自动生成的直播开播动态
  （DYNAMIC_TYPE_LIVE_RCMD，major.live_rcmd）——主播开播瞬间出现在空间 feed 里被抓取，瞬态噪音；
- **修复**：`fetcher._is_live_rcmd(item)` 判定（raw type 或 major type 含 LIVE），
  动态映射循环直接跳过；存量 2 条已删除（posts 总数 11,055 → 11,053）；
- **测试**：+1 用例（`test_is_live_rcmd`），共 39 passed。

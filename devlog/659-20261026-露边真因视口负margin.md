# 659-20261026-下一页露边的真因：视口「padding + 负 margin」

## 之前的做法

```css
.wb-charts-viewport { padding: 16px 22px; margin: -16px -22px; }
```

本意是"给卡片阴影留空间、但内容仍与页面其他部分对齐"。

## 为什么必然露边

负 margin 让视口的**边框盒**向外扩了 22px，但它的**内容盒**仍然是 `父宽 - 44px`。
`.wb-charts-pages` 宽 100%（= 内容盒），每页 `flex: 0 0 100%` ⇒ 下一页正好从内容盒右缘开始 ——
而内容盒右缘**比父容器右缘内缩了 22px**（负 margin 补偿的是边框盒，不是内容盒）。
于是下一页的左边缘落在父容器内部 22px 处，被 `overflow: hidden` 漏出来一条。

上一版我在页里加 `padding-right: 12px` 只是把那条边**推近了一点**，没有消除。

## 修法

把左右留白**从视口挪到页内**：

```css
.wb-charts-viewport { padding: 16px 0 14px; }   /* 左右 0 */
.wb-charts-page     { padding: 0 24px; box-sizing: border-box; }
```

视口内容盒 = 父容器宽度 ⇒ 每页正好占满 ⇒ 下一页从边界**正开始**，被一刀切掉，不可能露边；
卡片的阴影空间仍由页内的 24px 提供。

## 教训

**负 margin 补偿的是边框盒，不是内容盒** —— 想在 `overflow: hidden` 容器里保留阴影空间，
留白必须放在**内容**一侧（子元素的 padding），不能放在父元素的 padding 上再用负 margin 抵消。

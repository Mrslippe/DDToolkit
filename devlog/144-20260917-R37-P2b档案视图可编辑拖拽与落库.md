## 一、几何先行：拖拽/缩放也是纯函数

手势（指针事件）本身在 node 环境测不了，但它最终都要经过几何函数 —— 所以 P2b 的第一件事
是把"移动/缩放之后大家在哪"写成纯函数（`layoutModel.ts`，**13 条新用例**）：

| 函数 | 口径 |
|---|---|
| `pushDown(cards, fixedId)` | `fixedId` 那张**不动**，其余按 (y,x) 顺序**向下推开**到不相交 —— 这就是选型里的「碰撞**推开**」 |
| `moveCard(cards, id, x, y)` | 夹范围（`x` 最大 = `12 - w`）后推开 |
| `resizeCard(cards, id, w, h)` | 下限 `MIN_W=3 / MIN_H=2`；**宽的上限是右侧剩余空间 `12 - x`** |
| `cellsFromPx` / `columnWidthPx` | 手势层把像素位移换算成格（列宽从网格实宽反推，与 CSS 同式） |

**用例抓到一个真 bug**：`resizeCard` 第一版靠 `clampCard` 夹宽 —— 宽先被放到 12、`x` 再被拉回 0，
于是"拖右下角放大"会让卡片**整张左移**（用户视角：卡片跳走了）。改成按 `12 - x` 封顶，
`x` 就不需要动。用例名写的是现象（`上限：宽不超 12、x+w 仍被夹在网格内`），改坏必红。

## 二、编辑态与阅读态**分离**（四个选型里的第三条）

- 头部一枚「编辑布局」按钮；进编辑态后变成「重置默认」+「完成」；
- 编辑态才有：卡片描边变粉、头部 `cursor: grab`、右下角缩放手柄、**网格辅助线**（`repeating-linear-gradient`
  画的 12 列 + 行线 —— 没有它就只能靠猜）；阅读态零干扰（没有手柄、没有辅助线）；
- **窄窗不允许编辑**：单列是 `toSingleColumn` 算出来的，编辑会跟它打架 ⇒ 按钮**禁用并写明原因**
  （`title="窄窗下先拉宽窗口再排布（单列是自动降级）"`）。
- 卡片内容在编辑态仍可点（没有加 `pointer-events: none`）—— 拖动是从**卡头**发起、缩放在**右下角**，
  正文区不参与手势，所以不需要牺牲可读性。

## 三、保存：松手一次整版 PUT，失败**回滚**

- 拖动过程中每跨一格重算一次布局（`d.base` = 按下时的快照 + **累计位移**，避免逐帧累积漂移）；
- `pointerup` 时把**最新布局**（`cardsRef`，不用闭包里的旧值）整版 PUT；
- 成功：用服务端返回的行重建状态（id 会重发）→ 顶栏胶囊「布局已保存」；
- 失败：**回到上一版已落库的布局** + 「布局保存失败，已恢复上一次的排布」——
  界面上不能留着"看着排好了、其实没存上"（本仓最忌讳的静默失败）。
- 空布局 = 还没排过 ⇒ 用注册表的默认排布渲染，**不落库**（用户没动过就不写）。

## 四、护栏：新探针 `--board`（端到端一条链）

`ui_probe.py --board` = 前端 `?probe=board` + 脚本对账：

1. 宽窗（**1440**，容器 838px ≥ 阈值 560 ⇒ 12 列）切到档案视图、点「编辑布局」；
2. 用**合成 PointerEvent** 把第一张卡往右 2 列 / 往下 1 行拖（分两步移动，贴近真人）；
3. 断言：格位变化恰好 `(+2,+1)`、卡片数不变、**拖动后零重叠**（推开口径生效）；
4. **去后端对账**：`GET /vtuber/{id}/profile-cards` 必须已经是新位置
   —— 只看 DOM 的话「排好了但没存上」照样绿；
5. 窄窗（**1100**，容器 498 < 560 ⇒ 单列）另跑一格：`cols=1` 且**编辑按钮禁用**。

**实跑输出**：

```
[probe] board @1440
  视图钮=True 编辑钮=True 窄窗禁用=False 编辑态=1 网格列=12
    anniversary: (1,1) → (3,2) 高 276→276
    top-posts:   (6,1) → (6,5) 高 276→276      ← 被推下去（推开而不是弹回）
  后端已存：[('anniversary', 2, 1, 5, 3), ('top-posts', 5, 4, 7, 3)]
[probe] board（窄窗）@1100
  窄窗：列=1 编辑钮禁用=True title='窄窗下先拉宽窗口再排布（单列是自动降级）'
  [ok] 拖拽换位 + 推开口径 + 落库对账 + 窄窗禁用编辑
```

**反向验证**（逐条改回坏行为，三项全红）：拖拽不重算布局 ⇒ 格位变化 `(+0,+0)`；
松手不保存 ⇒ 库里还是旧位置；`moveCard` 不推开 ⇒ 两张卡重叠。

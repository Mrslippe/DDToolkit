# 598-20261023-结果区改为四页签 + 名单分页（含空态瘦身）

用户给了两张设计参考图，定了四条：
① 页签只做 总览 / 出席 / 互动 / 付费（不做"综合"）；
② 名单展示**全池**（不是前 300）；
③ 名单排序**跟着页签走**；
④ 空态保留一句引导，但**不要显示采集信息**、不要堆流程说明。

## 一、空态

- 只剩一行「请先选择时间范围进行分析」；
- 删掉「窗口场次 / 已有 / 待采」三个胶囊 —— 那是**采集**进度，属于「直播与采集」卡；
- 删掉原来的三步流程说明（采集/分析/结果），信息密度降下来。

胶囊只在**出结果后**出现在结果卡标题行右侧（与标题同一行）。

## 二、后端

`GET /fan/{v}/ranked`：

| 改动 | 说明 |
|---|---|
| `by` 新增三条轴 | `attendance / interaction / payment`（原来只有 strength + 效标） |
| 新增 `offset` | 名单分页；`limit` 仍是每页条数 |
| `pool` 扩展 | `axes`（三轴各 20 桶分位分布）、`pay_split`（礼物/舰长/SC）、`type_counts` |

实测（星瞳 75 场）：三种排序首位分别命中不同用户；`offset=2` 返回第 3–4 名；
三轴桶之和各 33,434（= 全池），`pay_split` = 礼物 17,670.6 / 舰长 809,812.6 / SC 272,381.0。

## 三、前端

- 新增 `ResultTabs`（总览/出席/互动/付费）与 `RankedTable`（分页 + 独轮车标记）；
- `ResultCharts` 增加 `tab`：总览画分层环形 + 强度曲线，其余三页画该轴分布（柱状）；
  付费页多一张「付费构成」卡（礼物/舰长/SC 金额与占比）；
- 切页签 ⇒ 用对应 `by` 重新取名单并回到第 1 页；翻页 ⇒ 只换名单，不动图；
- 名单页脚写明「第 x–y 人 / 全池 N 人」，与图上「全池 N 人」对齐，避免又读混。

**配色**：不采用参考图里的彩色大标签（粉/绿/黄），改为「深粉文字 + 2px 下划线」；
三轴色取 tokens 里已有的深粉/藏青/珊瑚。

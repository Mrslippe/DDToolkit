# 640-20261025-出席明细图定稿：20 列 × 2 行 + 方块矩阵浮层

用户给了目标样式，并定了三个参数：**默认 20 列、默认两行、浮层同 20 列**；
场次不足时**保持方块尺寸、右侧留白**（不拉伸）。

## 定稿样式

| 项 | 值 |
|---|---|
| 方块 | 14×14，圆角 3 |
| 间距 | 6（行列同距） |
| 出席 / 缺席 | `#4CC85A` / `#ECECEC` |
| 默认区 | `grid-template-columns: repeat(20, 14px)`，只渲染前 **40** 格（2 行） |
| 浮层 | 同 20 列，**渲染全部场次**（行数按需），不放文字列表 |
| 收起 | 鼠标离开后 **120ms**（斜向移入浮层时不闪） |

## 与上一版的差别

- 方块 8→14、间距 2→6；
- 排列从「按宽度自动换行」改为**固定 20 列网格**（跨用户可比）；
- 浮层从「竖排时间·标题列表」改为**方块矩阵**；时间/标题降级为单格的 `title`；
- 默认只露 2 行，场次多时靠 hover 看全。

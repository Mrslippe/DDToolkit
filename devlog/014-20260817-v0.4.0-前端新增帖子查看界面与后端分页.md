# 014-20260817-v0.4.0-前端新增帖子查看界面与后端分页

## 概述

基于 React（Vite + TS + Ant Design 5）新增 VTuber 帖子查看前端（`frontend/`），
并为支撑前端列表追加两个后端端点（旧端点行为不变）。

## 前端（frontend/）

```
frontend/
├── vite.config.ts      # /api 开发代理 → http://127.0.0.1:8000
├── src/
│   ├── api/            # types.ts（与 Pydantic schema 对齐）+ api.ts（fetch 封装）
│   ├── pages/          # VtuberListPage（卡片列表）/ PostsPage（帖子列表）
│   ├── components/     # PostDetailDrawer / TypeTag
│   └── utils/          # 时间/数字格式化、JSON 安全解析
```

功能：
- `/` VTuber 卡片：头像（本地缓存路径拼接）、粉丝数、直播状态徽标、签名；
- `/vtubers/:id` 账号信息条 + 统计概览卡片（总数/类型分布/归档/时间跨度）
  + 类型 Tabs 过滤 + 服务端分页表格 + 详情抽屉（封面/正文/图片组/播放·点赞·评论·转发统计/原文链接/raw_json 折叠）；
- 抓取按钮：`抓取账号信息`（POST /vtuber/fetch）、`抓取帖子`（POST /vtuber/fetch-posts?name=…）。

## 后端新增端点

| 端点 | 说明 |
|------|------|
| `GET /posts/{platform}/{platform_uid}/paginated?page=&page_size=&type=&is_archived=` | 服务端分页 + 过滤（page_size ≤ 200；type 用别名参数，避开关键字） |
| `GET /posts/{platform}/{platform_uid}/stats` | 帖子统计概览（总数/归档/类型分布/最早·最晚时间） |

动机：旧 `GET /posts/{platform}/{platform_uid}` 一次返回全量（单账号最多 3,589 条、
raw_json 单条最大 33KB，响应可达数十 MB），前端列表必须服务端分页。

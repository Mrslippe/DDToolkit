# 674-20261027-切页签"没有动画"的真因：动画刚起步就被新数据打断

## 时序（之前）

1. 切页签 → React 先渲染 → 卡片用**旧的 `ranked`** 挂载 → `init` + `emptyData` → 下一帧喂真数据，
   **动画开始**；
2. 同时 `loadRanked` 在后台请求，几十毫秒后返回 → `ranked` 换新 → `charts/att_bins` 变；
3. 我们的"数据更新"分支 `setOption({...option, animation: false}, true)`（`notMerge: true`）
   **立刻重画**，把刚起步的动画打断 —— 最终定格在终态。

所以观感是"切页签没有动画"，而**首次分析**（没有后续数据更新）能完整播完 —— 与用户观察一致。

## 修法：用数据指纹做 key

把 `场次-池人数-口径` 作为 `dataStamp` 传进图表区，卡片的 key 带上它：

```
key = `${tab}-${page}-${dataStamp}`
```

- 切页签：先渲染旧数据（几乎瞬间被替换）→ 数据到达 → **key 变 → 重新挂载 → 用最终数据播一次动画**；
- 首次分析、翻页：同理，都是"数据到位后一次性入场"；
- 删掉了"数据更新只 setOption"的分支 —— 它正是打断动画的元凶。

## 取舍

数据变化时**一定会重播动画**（包括重新分析）。这是为了让"切页签有动画"成立而接受的代价；
如果以后希望"重新分析不重播"，可以只在 `by/场次` 变化时不带 stamp。

## 一、14a：立令牌，把散落的 5 种环色收敛成 3 个形态

`frontend/src/styles/tokens.css` 新增：

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--focus-ring` | `2px solid var(--c-primary)` | 常规控件（`outline` 简写） |
| `--focus-ring-inset` | `inset 0 0 0 2px var(--c-primary)` | 画不到框外的地方（卡片/药丸/浮片） |
| `--focus-ring-on-dark` | `2px solid #ffffff` | 深色/彩色底（状态岛）—— 粉环在粉底上看不见 |

⚠️ 焦点环**不是** `--ring`（那是 shadcn/Tailwind 的"输入态描边"），也**不是** `--pill-ring`
（药丸自己的描边，只是恰好被当成焦点视觉用过）—— 这两个混用正是"5 种环色"的来源。

**替换了 11 处**焦点规则：`posts.css` 6 处（`.live-tag.clickable` / `.pill-more` / `.post-card` /
`.data-deck` / `.stat-pill.is-link` / `.vd-sign-toggle`）、`profile-board.css` 3 处
（`.board-add-item` / `.pcard-remove` / `.tp-hit`）、`layout.css` 的 `.float-pill::before`、
`status-island.css` 的 `.si-island`（→ `-on-dark`）。

## 二、14b：摘掉那条"连 `:focus-visible` 一起关"的全局规则

原来 `frontend/src/index.css`：

```css
/* 桌面应用交互：点击不残留焦点框（图表 SVG/按钮获焦时被 outline 描粉）；
   键盘可达性由按钮自有样式承担 */
:focus, :focus-visible { outline: none; }
```

它把**键盘用户的焦点视觉整个删掉了**，而原注释的理由只成立半条（"图表获焦描粉"）。
现在拆成两条：

```css
canvas:focus, svg:focus { outline: none; }   /* ① 原意图的收窄版：图表不吃 Tab 焦点 */
:focus-visible { outline: var(--focus-ring); outline-offset: 2px; }   /* ② 其余给品牌环 */
```

⚠️ **与计划的字面有一处偏差，如实记下**：计划 14b 预期"摘掉之后 `.type-chip` / `.filter-chip` /
`.view-btn` / `.lc-cell` … 一整族原生控件会冒出**浏览器默认 outline**，得逐个走查"。
我的做法是**同时补上 ②**：给全局 `:focus-visible` 一个品牌环 ⇒ 浏览器默认环永远不会露出来，
走查负担从"逐个控件补救"降到"看一眼环是否可见"。代价是**全站焦点视觉统一成主色**（这是刻意的）。

另外补了两个自适应块：
- `@media (forced-colors: active)` → 用系统色 `Highlight`（高对比模式下不该被品牌色压掉）；
- `@media (prefers-contrast: more)` → 加粗到 3px、去掉偏移（更醒目）。

## 三、判据（`tests/test_focus_contract.py`，3 条）

⚠️ 为什么是"扫源码"而不是"看浏览器"：`:focus-visible` 靠**真实键盘交互**匹配，而
`ui_probe.py` 只能派发合成事件（`el.focus()` 不产生 `:focus-visible`）⇒ 无头探针里
"环有没有画出来"量不准。所以机器判据钉**契约**，"看不看得见"留在人工走查（TODO §1.3）。

1. **全局那条规则必须不在**，且必须有全局品牌环（走令牌）与 `canvas:focus, svg:focus` 的收窄规则；
2. **焦点规则里不许再出现散落色**（`var(--ring)` / `var(--c-primary-deep)` / `var(--pill-ring)` /
   硬编码 `#fff`）—— 扫的是**规则块**（先剥注释：判据自己举的例子就写在注释里，§6.x 那个坑）；
3. `forced-colors` / `prefers-contrast` 两块在，且前者用了系统色。

**反向验证四刀全红**：把全局 `:focus, :focus-visible { outline: none }` 加回去 ⇒ ①红；
删掉品牌环 ⇒ ①红；某处改回 `var(--ring)` ⇒ ②红；删掉 `forced-colors` 块 ⇒ ③红。

# 733-20261028-切页签卡片消失 + 图表动画丢失

## 一、拖过区间再切页签 ⇒ 图表卡片消失

**根因两条叠加：**

1. `onTab` **无条件** `loadRanked`。用户刚拖过区间 ⇒ 上一次结果对应的参数已经过期 ⇒
   这次请求在后端是**冷算**（几十秒）；
2. 图表区受 `rankedTab === tab` 门控：请求在途时 `rankedTab` 还是旧值 ⇒ 渲染
   `<div className="wb-charts-pending">`（**空占位，没有卡片**）——
   这就是"卡片直接不见了"。

**修法：**

| 改动 | 说明 |
|---|---|
| 删掉 `rankedTab === tab` 门控（连 `rankedTab` 这个 state 一起删） | 图表数据（`charts`/`pool`）**与排序口径 `by` 无关**，切页签直接沿用旧结果即可；原来的门控只是想避免"挂图两次闪动"，代价却是"空屏" |
| 新增 `rankedBasisRef`：记录"当前结果基于哪一组参数"（窗口 + 区间 + 场次清单） | `loadRanked` 成功时写入 |
| `onTab` 改为**按参数是否变化**决定：<br>· 参数没变 ⇒ 照旧取数（命中结果包，毫秒级）<br>· 参数变了 ⇒ **只切 UI** + `setRankedStale(true)` | 绝不在用户没点「分析」时偷偷跑几十秒的重算 |

## 二、图表动画又不见了

**根因（两个，都是我在前几批改出来的）：**

1. `dataStamp`（决定卡片**重挂载**的键）里把 `by` 去掉了 —— 而重挂载正是入场动画的
   唯一触发点（`EChart` 只在挂载时"先喂空数据、下一帧喂真数据"）。去掉后切页签不再
   重挂载 ⇒ 永远不播动画；
2. `EChart` 的初始化现在可能发生在 **ResizeObserver 回调**里（宽度 0 被推迟初始化）。
   原来只等**一帧**就喂真数据，空数据那一步可能还没真正绘制就被覆盖 ⇒ ECharts 认为
   "没有从空到有" ⇒ 动画不播。

**修法：**

- `dataStamp` 恢复成 `${sessions}-${total_in_pool}-${by}`，并在注释里写明"**别再去掉 `by`**"；
- 初始化改成**两次 rAF** 再喂真数据，且用 `setOption(option, true)`（notMerge）确保整份替换。

## 四、一个没测到的角落（诚实记录）

"拖过区间 → 切页签不重算"这条**没有自动化用例**：jsdom 里滑杆的档位按钮因为容器宽度为 0
而全部 disabled，无法在测试里模拟拖动。逻辑本身是纯判断（比较参数字符串），
已按上面的方式实现并在 devlog 里写清；后续若要覆盖，得给 `WindowSlider` 加个测试用的
`onWindow` 直通，属于测试基建，不在这次范围。

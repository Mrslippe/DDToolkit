# 562-20261019-选中区多算了一个间距：左右把手不对称

用户放大截图指出：**左手柄贴着柱子，右手柄却落在缝隙里**。

## 根因：带子比"包含的柱子"宽了 `GAP`

柱子 `i` 占据：

```
[PAD + i*step,  PAD + i*step + (step - GAP)]
```

而选中区的宽度原来是 `size * step`，于是右缘落在：

```
PAD + start*step + size*step = PAD + (start+size)*step
```

这正好是**下一根柱子的左缘** —— 比最后一根柱子的右缘多出一个 `GAP`（2px）。

所以左手柄贴在第一根柱的左缘（对齐），右手柄却落在最后一根柱右侧的**缝隙里**（错位）。
两端参考系不同，看起来就"相对位置不一致"。

## 改法

```ts
width: Math.max(4, size * step - GAP)
```

带子两端现在都落在**柱子边缘**上：左缘 = 首柱左缘，右缘 = 末柱右缘，把手各内缩 1px ⇒ 对称。

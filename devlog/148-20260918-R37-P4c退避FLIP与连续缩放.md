## 二、退避动画怎么做的（规格 §5.2）

FLIP 四步，关键是**第一步与第二步必须落在同一帧**：

1. **F**irst：`applyLayout()` 在改 DOM **之前**量下所有卡的位置（`captureRects`）；
2. **L**ast：React 提交新布局；
3. **I**nvert：`useLayoutEffect`（**DOM 变更后、绘制前**同步执行）里量新位置、给位移变了的卡打上
   `transform: translate(dx,dy)` + `transition: none` —— 与新布局同帧 ⇒ 看不到中间态；
4. **P**lay：下一帧撤掉补偿并登记 `transition: transform <ms> var(--ease-standard)`
   ⇒ 卡片从旧位置滑到新位置。

拖动中的那张卡**不参与**（它由跟手位移驱动，两条动画打架会看出"被拽回去"）；
**归位**走的是同一条路（补偿量反向）—— 这正是用户拍板要的那一半。

**时长由距离决定**：一行内 220ms、跨 ≥2 行 320ms（`flipDurationMs`，有单测）。

## 三、两个真 bug（都是新护栏先红抓出来的）

### 1. `cellsFromPx` 的列/行口径不一致 ⇒ 拖一点点就跨格

`cellsFromPx(dxPx, dyPx, colW, ROW_H + GAP)`：x 除的是**列宽**（58.83）、y 除的是**格距**（96）。
于是一个真实网格下"拖 45% 的列宽"（26.5px）被算成 `round(26.5 / 58.83) = 0`…… 等等，
真正出问题的是**拖 45% 的格距**（31.9px）：`round(31.9 / 58.83) = 1` ⇒ 模型提前一格。
探针的原话是「拖不到半格时模型尺寸就变了（5×3 → 6×3）」。

修法：两个参数统一成**格距**，参数名改成 `colPitch` / `rowPitch` —— 传错的人在调用处就看得见。
⚠️ 单测**抓不到**这个错（函数本身怎么除都对，错在调用方传什么），所以护栏必须长在探针那一侧：
它量的是"拖 45% 的格距之后模型格数有没有变"。

### 2. "拖出去再拖回来"模型不回退 ⇒ 松手时卡片凭空跳一格

原来判"要不要重算布局"是 `if (dx || dy)`（指针有没有跨过格线）。而拖回原点时 `dx = dy = 0`
⇒ 分支不进 ⇒ 模型**停在被拖出去的那一格**，可视觉上卡片已经跟着手回到了原位。
松手落库时它才"啪"地跳回去一格。

修法：拿**目标格位**跟**当前模型格位**比（`live.x !== tx || live.y !== ty`），而不是看指针跨没跨线。
抓到它的还是新护栏：**归位**那一段（"把拖动卡挪回去后，邻居没有归位动画"——
其实是因为模型压根没回去，邻居也就没动）。

## 四、尺子又补了一课（`settleTransforms`）

P4b 已经知道"虚拟时间下 CSS 过渡不推进"（`getAnimations().currentTime` 恒 0）。
本批发现它的**第二个后果**：既然过渡停在起点，`getBoundingClientRect()` 量到的是
**动画起点**而不是布局位置 —— 被挤开的卡看着还停在原位。`--board` 的"零重叠"断言
因此误判了一次（"拖动后 anniversary 与 top-posts 重叠（推开口径没生效）"，其实推开了，
只是卡片还冻在补偿位移那一帧）。

修法：探针里加 `settleTransforms()` —— 量几何之前把所有在飞的过渡 `Animation.finish()`
推到终点。**"归位"那一段也必须先推**：不推的话卡片看着没动，算出来的补偿量是 0，
测的就不是归位了。没有过渡时它是空操作，所以可以无脑先调。

## 五、护栏（`--motion-cards` 扩了三段）

| 段 | 判据 |
|---|---|
| 退避 | 跨格后被挤开的卡有 `data-flip`，**登记了过渡**，且补偿量是**格距 / 行距的整数倍**（差一点就说明算式里少了 gap 或拿错了单位）；拖动卡**不许有** |
| 归位 | 把拖动卡挪回原处 ⇒ 邻居出现**正 dy** 的补偿（升回去也有动画） |
| 收敛 | 落定后所有卡的 `data-flip` 与内联 `transform` 都清干净 |
| 缩放 | 拖 45% 的格距 ⇒ 实渲染尺寸跟着变而**模型格数不变**；拖过一格 ⇒ 模型 +1；松手后内联尺寸清干净、模型尺寸 = 拖到的那个 |
| reduced-motion | 整套 FLIP **跳过**（没有 `data-flip`），而缩放的跟手仍在 |

**反向验证**：先把这三段断言写进去跑 → **2 红**（"没有 FLIP 补偿位移" + "拖不到半格模型尺寸就变了"），
实现后归零；随后"归位"那一段又抓出 §三.2 的模型不回退。

# 456-20261010-截图里看出来的四处：说明条比面板宽 / Tab 标签自相矛盾 / 能力闸门 / 扩展缺弹窗

用户 2026-10-08 发来登录浮窗的截图（我做 455 那批之后）。

## 〇、那条说明比面板宽 43px（用户点名"弹窗的宽度和文字内容的宽度对不上"）

我第一版只量了"面板自身有没有被撑宽 + 最深一层文字有没有被裁"，**量不到这一类**。
这次按像素量了用户那张图（自己解 PNG + 按颜色分段，仓里没有 Pillow）：

| 元素 | 右缘 x |
|---|---|
| 面板（白底） | **510** |
| 「账号凭据（Cookie）…」说明条（浅粉 `--sel-bg-hover`） | **553** ← 越出面板 **43px**，盖在暗色遮罩上 |

**病根不是文字断行，是 grid 轨道被撑宽**：`DialogContent` 是 `grid`，grid 子项的 `min-width:auto`
⇒ 只要里面有**不可断的长内容**，**轨道**就被撑宽，于是**面板里每一个块**一起溢出面板。
那条"不可断的长内容"是**扩展目录那一行**：`\\?\E:\…\target\debug\extension`
（`truncate` = `white-space: nowrap`，整条路径的宽度就是它的 min-content）。

探针此前复现不出来的原因：它跑在浏览器里，`extensionDir()` 拿不到壳的路径 ⇒ 那一行是短文案。
**修法与判据**（两条都进了 A 档门禁的 `--first-run`）：

- 修：登录浮窗的 `DialogContent` 加 `[&>*]:min-w-0`（子项不许比轨道宽；里面那行本来就是
  `min-w-0 flex-1 truncate` ⇒ 改成省略号截断）；`.lc-ms`（B2 的手动弹窗，flex 列）用 CSS 写同一条。
- 判据一：`measureDialogs` 新增 **`childrenOverflow`** —— 直接子元素 vs 面板**内容盒**
  （`rect.w - padding`），排除绝对定位的关闭钮。
- 判据二（**正对照，这次的关键**）：把「扩展目录」那行**种成真机长度的长路径**再量一遍。
  实测不修 ⇒ 每个子元素 498px vs 内容盒 464px（越出 35px，与用户截图的 43px 同机制）；修后 ⇒ 0 溢出。
  ⚠️ 顺带补第三条噪声豁免：`text-overflow: ellipsis`（**省略号截断是长内容的正规处置**，
  扩展目录那行靠它 + `title` 露出全值）—— 不豁免的话修完反而会红。

## 一、Tab 标签与正文打架（用户直接看到的那处）

截图里同时写着「**B 站 · 已登录**」和「**B 站登录已失效**」。原因：Tab 后缀只判 `status.logged_in`，
而 B 站的 `logged_in` 语义是**凭据还在不在**（`is_logged_in`），"能不能用"另在 `needs_login` 里
（维护循环 `nav` 的结论）。B 站是唯一一个这两件事会分岔的平台 —— 会话被平台吊销后：
凭据在（`logged_in` 真）、已经被判失效（`needs_login` 真）。

修法：**Tab 后缀抽成 `utils/platformLogin.ts::authTabSuffix` 一处判定**（四档：能用 ⇒ 已登录/已配置、
有凭据但失效 ⇒ **已失效**、没配过 ⇒ 无后缀），组件只调它；判据 6 条（含"正对照：同一份凭据 + 会话有效
⇒ 已登录"与"老后端不带 `configured` 时退回 `logged_in`"）。

## 二、能力闸门对 B 站只问"凭据在不在"——**这处危害最大**

同一类错误在更深处还有两处（`capabilities.py`）：

| 消费方 | 只问凭据存在性的后果 |
|---|---|
| `snapshot()`（能力矩阵） | 会话吊销后照写"完整可用"，用户看不到任何提示 |
| `content_fetch_allowed()`（内容闸门） | **会话失效仍放行内容请求** ⇒ 按不变量 23，未授权内容请求先激起平台 `-352`、再升级成 **HTTP 412（IP 级、会持续）** |

⚠️ 用户日志里那 14 条 `❌ B站错误码 -352, 消息: 风控校验失败`（22:35 起，会话 22:34 被判死）
**正是这个形状** —— 那个"抓取失败"不是网络问题，是我们在用一条死会话敲门。微博那支一直是
`and not needs_login`，B 站漏了。现在三处统一（口径与小红书 `and not invalidated` 一致）。

⚠️ 途中我自己踩了一次：B 站的 `needs_login` 是**方法**（微博那个是 property），漏括号让条件**恒假**
⇒ 会把 B 站内容抓取**全部挡死**。是**正对照那条断言**当场抓住的（"同一份凭据 + 会话有效 ⇒ 放行"）——
只写"失效时拒绝"的话，这个错法能一路绿到用户手里。

## 三、按界面给的路径加载扩展 ⇒ 点图标什么都不出来

截图里「扩展目录」显示 `…\src-tauri\target\debug\extension`（打包版是 `<安装目录>\extension`），
而那份产物**没有 `popup.html`**：`manifest.json` 的 `action.default_popup` 正指着它，
而暂存白名单 `ITEMS` 里只有 `manifest.json` + `src` + `icons` + `README.md` ——
token 输入框与「同步」按钮都在那个弹窗里，所以症状是"装得上、点了没反应"。

修法：`ITEMS` 补 `popup.html`/`popup.css`；`assert_loadable()` 现在会**逐个核对 manifest 引用到的
每一个文件**（含弹窗 HTML 自己引用的 css/js）在不在、以及**在不在白名单里**；判据 5 条，其中两条是
**反例**（白名单漏一个 ⇒ 必须拦下；源里根本没有 popup.html ⇒ 必须拦下）—— 少了反例，
"产物齐全"这条绿分不清"真的没漏"与"检查没牙"。顺手把开发构建与 release 那两份产物重暂存了一遍。

## 四、一处口径更正（455 那篇）

455 里我写"真机数据目录副本、四个 Tab 逐个点过"——**不准确**：探针的 `--capabilities` 档按设计
**删掉 `.env`**（它要的是"有数据但未登录"那个现场），所以那次量的是**未配置态**，用户截图里
"已登录 / 已失效"那几屏没被覆盖到。`overflow-wrap` 是根上继承的 CSS 性质、与登录态无关，
注入法仍然成立，但那句话已改。

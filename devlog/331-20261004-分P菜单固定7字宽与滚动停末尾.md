# 331-20261004 分P 菜单：固定 7 字宽 + 左对齐 + 过长滚一次停在末尾

> 用户截图（`devlog/329` 之后）：分P 弹出栏里**只有 P1…P7、没有标题**。
> 口径：「同一行显示：P1 标题，然后居中展示，上拉栏宽度固定在 7 个字符宽度，如果标题过长就在
> hover 的时候滚动展示」→ 随后修正为「**向左对齐**，滚动结束就在结束位置**停住**，不用返回滚动」。

## 一、根因不在数据，在 CSS（一个 grid 的坑）

先查数据：上游 `view.pages[].part` 七条**都在**（`第一章沐霂（男主）视角` … `第五章结局`），
我们的映射也带得出来 ⇒ 标题是被**布局**吃掉的：

`.vp-menu` 是 `display: grid`，而我给 grid 项（按钮）自己加了 `overflow: hidden` ——
**滚动容器的 min-content 贡献是 0** ⇒ 自动轨道（`auto` = `minmax(min-content, max-content)`）
可以一路缩到容器宽度（`.vp-rate` ≈ 按钮宽 ≈ 2 个字符）⇒ 标题被裁光，只剩 `P1`…`P7`。

⚠️ 对照：清晰度菜单**没有** `overflow: hidden`，所以它一直好好的（`nowrap` 让 min-content
= max-content，轨道不会被压缩）。**这条规矩记下来：要在弹层里裁切，宽度写在弹层上，
裁切交给内层元素 —— 别把 `overflow` 挂在 grid 项自己身上。**

## 二、按用户口径重做

```css
.vp-menu--page { --vp-page-w: 7em; --vp-page-pad: 4px; width: var(--vp-page-w); }
.vp-menu--page .vp-menu-item { padding: 3px 0; display: block; text-align: left; overflow: hidden; }
.vp-menu--page .vp-page-label { display: inline-block; white-space: nowrap; }
.vp-menu--page .vp-menu-item:hover .vp-page-label {
  animation: vp-page-scroll 3s linear .35s 1 forwards;   /* 一次，停在末尾 */
}
@keyframes vp-page-scroll {
  from { transform: translateX(0); }
  to   { transform: translateX(min(0em, calc(var(--vp-page-w) - var(--vp-page-pad) * 2 - 100%))); }
}
```

- 一行 `P1 标题`、**左对齐**；菜单**固定 7 个字符宽**（`7em`，CJK 一字 ≈ 1em）；
- 标题超出 ⇒ hover 时**滚一次、停在末尾**（`forwards`，不 `alternate`/`infinite`）；
  鼠标离开动画即取消（规则挂在 `:hover` 上），下次 hover 从头再来；
- `min(0em, …)`：短标题位移取 0 —— **短标题不会被推着跑**；
  `translateX` 的百分比按元素自身宽度算 ⇒ `100%` 就是文字宽度；
- `prefers-reduced-motion` 下不动（`animation: none`），完整标题仍可从 `title` 悬停提示读。

## 三、判据

- 组件级：分P 菜单每项的文字是 `P1 第一章` 这种**整行**，并包在 `.vp-page-label` 里
  （只有 `P1`…`P7` 正是塌宽那次的形状）。
- CSS 级（读 `posts.css` 文本，照 `VideoPlayer.menus.test.tsx` 既有的做法）：宽度必须是
  `--vp-page-w: 7em` + `width: var(--vp-page-w)` 且**不许**用 `max-width` 兜（兜不住塌宽）；
  裁切在**内层 span**、整行 `text-align: left`（且**不许**回到居中那版）；
  hover 规则必须 `forwards`、**不许** `alternate`/`infinite`；关键帧位移是
  `min(0em, calc(var(--vp-page-w)…))`；reduced-motion 有关闭。

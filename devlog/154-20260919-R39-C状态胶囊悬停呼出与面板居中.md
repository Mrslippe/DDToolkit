# 154-20260919-R39-C状态胶囊悬停呼出与面板居中

> 用户 2026-09-19 四条前端改动里的第 ③ 条：
> 「顶栏状态栏呼出下拉栏的逻辑**改为鼠标 hover 就呼出，离开就收起**，并且**下拉栏居中**」。
> 拍板：**带延迟 + 保留点击**（进 120ms / 出 200ms）+ **相对胶囊居中**。

---

## 一、口径（每条都对应一种"做错了也看着能用"的错法）

| 项 | 取值 | 拦的是什么错法 |
|---|---|---|
| 悬停进入 | **120ms 后展开** | 鼠标从顶栏扫过时弹面板 —— 最烦人的那一种（探针：60ms 内进出**不许**弹） |
| 悬停离开 | **200ms 后收起** | 指针从胶囊移进面板必然跨过间隙 ⇒ 没有宽限的话"还没碰到就没了" |
| 点击 / Enter | **钉住**（`data-pinned="1"`） | 否则"点开细看"做不到（鼠标一移开就收）；hover 是快捷方式、点击是钉住，两者不互相顶掉 |
| 收起通道 | Esc / **点面板与胶囊之外** / 条目清空 / ttl | 钉住不能退化成"只能按 Esc"（新增 outside-pointerdown） |
| 锚点 | 面板**水平中心对齐胶囊中心**（越界夹进视口） | 原来是**左缘**对齐 ⇒ 胶囊越靠右面板越偏（探针量到偏 7px） |
| 胶囊自身 | 仍然不许位移/缩放 | 借灵动岛的语法，不借它的存在感（规格 §9 反模式不变） |

## 二、规格同步（这条改动动了 R38 的既定口径）

`docs/design-status-island.md` §13 原本写的默认是「形变触发：**只在信息变化时形变；hover 只提亮**」，
备选才是「hover 也展开」。用户这次选的就是那个备选 ⇒ **新增 §13.1 口径变更**，把新口径写死，
免得 R38 批 2（胶囊形变）按旧口径做、两边打架。同时：

- §9 反模式的「hover 只允许轻微提亮」补一句：**hover 展开面板是允许的，但胶囊自身仍不许位移/缩放**；
- §10 不变量表补两行并标实装状态：**锚点稳定/居中**（≤1.5px）与 **hover 四条**（掠过不弹 / 悬停必弹 /
  移入保持 / 离开必收 / 点击钉住）—— 顺带给全表加了「实装」列，一眼看得出哪几条还等 R38。

## 三、护栏（先红后绿）

探针 `--status-island` 新增一段，**合成 pointerover/pointerout** 走真实路径（`relatedTarget: body`）：

| 判据 | 反向验证（实现前） |
|---|---|
| 60ms 内进出 ⇒ **不许**弹 | （实现前压根不弹 ⇒ 这条"恰好"过 —— 所以它必须与下一条一起看） |
| 悬停 280ms ⇒ **必须**弹 | ❌ 红 |
| 指针移进面板 ⇒ **不许**收 | ❌ 红 |
| 指针离开面板 ⇒ **必须**收 | （同上） |
| 点击 ⇒ 打开且**钉住**（移开仍开） | ❌ 红 |
| 面板中心与胶囊中心 **≤1.5px**（被夹除外） | ❌ 红（实测偏 **7px**） |

**反向验证 3 红 → 0**；原有断言（点开 / 条目可命中 / 不挤动右栏 / Esc 收起 / 入场动画 / chevron 翻转 /
ttl 回空闲）全部照旧通过 —— 说明 hover 没有顶掉既有行为。

# 002-20260804-v0.1.1-已知问题修复

## 概述

对 v0.1.0 中记录的 6 项已知问题进行修复，并新增测试覆盖。

## 修复清单

### 1. requirements.txt 依赖固化

整理并写入项目全部依赖，含版本下限：

```
fastapi>=0.115.0
uvicorn[standard]>=0.30.0
sqlalchemy>=2.0.0
httpx>=0.27.0
tenacity>=8.0.0
apscheduler>=3.10.0
flet>=0.22.0
alembic>=1.13.0
python-dotenv>=1.0.0
pytest>=7.0.0
```

### 2. 安全：凭证文件保护

- 新增 [.gitignore](.gitignore) — 排除 `.env`、`*.db`、`__pycache__/`、`logs/` 等
- 新增 [.env.example](.env.example) — 提供凭证模板，方便新开发者配置

### 3. 配置集中化（[app/core/config.py](app/core/config.py)）

将散落在各模块的硬编码常量统一收拢到 `Settings` 类：

| 配置项 | 原位置 | 说明 |
|--------|--------|------|
| `DATABASE_URL` | `database.py` | 数据库连接串 |
| `BILI_*` | `wbi.py` | B站 Cookie 凭证 |
| `FETCH_INTERVAL_MINUTES` | `scheduler.py` | 抓取间隔 |
| `FETCH_JITTER_SECONDS` | `scheduler.py` | 随机抖动 |
| `REQUEST_INTERVAL_*` | `scheduler.py` | 请求间隔 |
| `LOG_LEVEL` / `LOG_FILE` | 新增 | 日志配置 |

所有模块不再直接 `os.getenv()`，改为从 `from app.core.config import settings` 读取。

### 4. 修复 API 路由参数类型错误（[app/routers/vtuber.py](app/routers/vtuber.py)）

| 端点 | 修复前 | 修复后 |
|------|--------|--------|
| `POST /vtuber` | `vtuber: VTuberOut` | `vtuber: VTuberCreate` |
| `PUT /vtuber/{id}` | `vtuber: VTuberOut` | `vtuber: VTuberUpdate` |

同时修正 [app/schemas/vtuber.py](app/schemas/vtuber.py) 中 `VTuberCreate` 和 `VTuberUpdate` 的字段类型：
- `is_live`: `str | None` → `bool`（Create）/ `bool | None`（Update）
- `fans_count`（Update）: `str | None` → `int | None`

### 5. 日志文件持久化（[app/main.py](app/main.py)）

在 FastAPI 启动时配置双通道日志：
- `StreamHandler` → 控制台输出（保留）
- `FileHandler` → `logs/app.log`（新增，UTF-8 编码）

同时将 `main.py` 中的 `print()` 调用替换为 `logger.info()`。

### 6. 单元测试（[tests/test_vtuber_api.py](tests/test_vtuber_api.py)）

新增 7 个 API 测试用例，基于 FastAPI `TestClient` + `pytest`：

| 测试用例 | 状态 |
|----------|------|
| `test_list_vtubers_empty` — 空表返回空列表 | PASS |
| `test_create_and_get_vtuber` — 创建后查询 | PASS |
| `test_update_vtuber` — 更新字段 | PASS |
| `test_delete_vtuber` — 删除后查不到 | PASS |
| `test_get_nonexistent_vtuber` — 查不存在 ID 返回 404 | PASS |
| `test_update_nonexistent_vtuber` — 更新不存在 ID 返回 404 | PASS |
| `test_delete_nonexistent_vtuber` — 删除不存在 ID 返回 404 | PASS |

### 额外修复

- [app/dependencies/get_db.py](app/dependencies/get_db.py) — 从空文件改为 re-export `core.database.get_db`
- [app/core/database.py](app/core/database.py) — `declarative_base` 改用 SQLAlchemy 2.0 新路径 `sqlalchemy.orm.declarative_base`

# 034-20260906-v0.9.0-直播日历按设计稿重构（docs/design/react-LiveCalendar Frame101）

## 背景（用户 2026-09-06）

提供 `docs/design/react-LiveCalendar`（Pixso 导出 Frame101 设计稿），
要求严格按该设计稿重构直播日历卡片。用户决策：

1. **月历**，上/下月多出的天数按设计稿补位格处理；
2. 格子只显示**首场**，其余场次放在 **hover 浮层**；
3. 阴影保持项目柔和（`--shadow-dialog`，不采用设计稿 0.4 黑重阴影）；
4. 字号整体放大一档（设计稿 8/9px → 9.5/11.5px）。

## 实现

- **LiveCalendar.tsx 重写**：
  - 月历 grid：`cells` 计算月初补位（startWeekday 前的上月日）+ 当月 28~31 天 + 月末补位（填满 7 的倍数）；`inMonth=false` = 补位格；
  - 状态机：有场次=live（tone-类型）；已过去无场次=rest；今天/未来无场次=tbd；
  - 格子仅渲染首场（时间 `8 PM` 12 小时制 + 标题单行截断）+ `+N 场` 角标；
  - hover 浮层：内嵌格子 `.live-day-pop`（CSS hover 显示，无 React 状态竞态），渲染当日全量场次（类型/起止/时长/礼物）；多场或礼物时才有浮层；浮层向下展开；
  - 月份胶囊导航（`CalendarDays` + `2026年09月`）+ 统计行保留（共 N 场 + 类型计数）；
  - 删除了周行列表实现（anchor/翻周/休息角标等），`liveType.ts` 9 类不变。
- **posts.css**：
  - `.live-calendar-nav*`（胶囊导航）、`.live-calendar-weekdays`（Mon.~Sun.）、`.live-calendar-grid`（7 列 10px 间距）；
  - `.live-calendar-cell` 58px/6px 圆角 + `tone-*` 8 类色系 + `rest/tbd/pad` 灰态 + `today` 红描边；
  - `.live-type` 改设计稿浅底深字胶囊（radius 74px），新增 `live-type--rest/tbd`，9 类配色改浅底深字；
  - `.live-day-pop` 改格子内嵌绝对定位（top:100%+4px 向下展开，hover 显示）。

## 一、按问答落地的四条

| 问题 | 用户的选择 |
|---|---|
| 右上角按钮清哪些 | **会自动过期的 + 需要处理的**；「正在进行」**不动** |
| 哪些点击算已读 | **点正文/空白** = 已读；**点动作按钮只执行动作**（不顺手消掉） |
| 顶上来怎么动 | **与滑出同时**（不是"先滑完再顶"） |
| 滑出时长 | 按推荐（220ms，与面板入场同拍）|

实现：

- 「全部已读」移到 `.si-panel-head` 右上角（原来是组标题右侧），**取代**那句来源提示
  （`href`）—— 那行字与每条自带的 `.si-item-meta`（「注意 · 能力矩阵 · …」）重复，白占最顺手的位置；
- **清的范围抽成 `ackAllIds()`**（`noticeBoard.ts`）：只清 `recent` / `todo` 两组。
  ⚠️ 状态类（`doing`）**不给清**：它们的消失应当是**事实变了**（任务结束/冷却结束/重新登录），
  而且后端第二道防线也会拒收 —— 更实际的是"清了下一轮又回来"，那正是用户上一轮报的
  "点了没反应"。范围**只有一处**（面板与 `TopBar` 同用它），不许两边各写一份；
- 点条目 = `onAction('dismiss', n)`（走已有的已读路径）。**状态类不给点**（`can-ack` 类名控制
  指针与悬停反馈），动作按钮 `stopPropagation`。

## 二、③④ 的动画：滑出与顶上来必须**同拍**

原来退场条目挂在另一个 `<ul class="si-list-leaving">` 里 —— 两个后果：
**它跳到整列最下面**，而且剩下的条目**要等它 220ms 动画放完**才可能上移（流内位置还占着）。

改法：

1. **退场条目留在它原来那一组**、并**浮起来**（`position:absolute` + 锁定 `top`/`height`，
   容器同时锁高）⇒ 流内位置**当场空出**，下面的条目**同时**开始上移；
2. **FLIP**（First-Last-Invert-Play）让"上移"有缓动：改 DOM **前**记矩形 →
   改完把每条**瞬时**挪回旧位置（反向 `transform`）→ 下一帧撤掉 ⇒ CSS 过渡平滑落位。
   `.si-item` 的 `transition: transform` 就是那条过渡（只碰 transform，不动布局）。

> ⚠️ 三个坑都是实测撞出来的（`StatusIsland.test.tsx` 与全量 `vitest run` 各抓到一部分）：
> ① `useLayoutEffect` 里 `setState` 会被排到**下一次渲染**才落地，跑得密时那条渲染可能落在
> 退场动画之后 ⇒ 浮动坐标改用 **`useEffect`** 补（幂等：已有坐标不动）；
> ② 退场条目若只按 `groupOf` 归属，**整组只剩它时那一组根本不渲染**（它已不是 live）⇒
> 它静默消失、没有动画。现在 `groupRows` 统一算"活着的 + 本组退场的"，另有 `orphans` 兜底；
> ③ 单测里 `Date.now()` 是**真实**时间而通知锚在 `NOW` ⇒ 一上来全被判过期；
> 夹具已 `vi.setSystemTime(NOW)`。

## 三、⚠️ 一处**行为变化**（"最近提顶"的连带，用户知情）

三组顺序改为 **最近 → 需要处理 → 正在进行**（`GROUP_ORDER`）。连带变化：
胶囊上那句话（`pickHeadline` / `capsuleText` 取**第一组第一条**）**现在优先显示最近发生的事**
（开播、完成回执），而不是"正在进行的任务进度"。这正是"最实时"的含义，但它**改掉了
`devlog/089` 以来"进度占胶囊"的行为** —— 记在这里，改顺序的人要能看到这一条。
（只有状态时胶囊照旧显示状态："现在有什么在跑"仍是它的看家职责，有用例钉着。）

## 四、顺带修掉一条**定时炸弹式判据**（与本批无关，但它在门禁里红了）

`tests/test_assets.py::_age` 原来写死基准日 `datetime(2026, 9, 29, 12, 0)`，于是"1 天前"是
**相对那个固定日期**算的 ⇒ 跑到 10-06 之后，`days=1` 的那份距"现在"已 ≥8 天、越过默认 7 天窗口，
`test_verify_skips_fresh_and_checks_old` **从那天起恒定红**。
验证是"不是回归"：把本批改动 `git stash` 掉，它一样红。
修法：基准改成 `datetime.now(timezone.utc)`（往回推 N 天）—— **哪一天跑都对**。

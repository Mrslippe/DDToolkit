# 670-20261027-为什么折线有动画、饼图没有

## 原因

两帧重播是「值全 0 → 真值」。对**折线/柱状**没问题：数据 0 也占位置，ECharts 是在同一组点上做数值过渡。

但**饼图**不同：`value = 0` 的扇区**不占角度**，视觉上等于不存在。
ECharts 默认的 `animationType: 'expansion'` 依赖"数据项增多"的增量语义，
遇到"0 → 有值"会把它当成**新增扇区**直接画出来，不做过渡 —— 于是饼图看起来是"瞬间出现"。

## 修法

给饼图显式指定按半径缩放的动画，并给每个扇区稳定 `id`：

```ts
series: [{
  type: 'pie',
  animationType: 'scale',     // 0 → 正常半径，一定有过渡
  animationDuration: 700,
  animationEasing: 'cubicOut',
  data: data.map((d, i) => ({ ...d, id: d.name, itemStyle: {...} })),
}]
```

- `scale` 是整体半径缩放，与"值是否为 0"无关；
- `id` 让 ECharts 认出"同一块扇区"，而不是每帧都当成新数据。

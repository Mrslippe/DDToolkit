## 二、做法：复用 `<FloatPill>`，不新造样式

`FloatPill` 是全站唯一的交互层元件（UI-MAP §C2/§C5）：原生 `<button class="float-pill …">`，
斜切白卡 + 3px 圆角 + `--pill-shadow` 全挂在 `::before` 上。所以这批**没有一行新 CSS**，
只是把六处按钮换过来，并删掉两个自绘副本（`.ah-close`、`.cap-login-cta`）。
主操作用 `active`（`.on` = 主色深填白字），页脚因此有明确的主次。

## 三、护栏：行为断言 + 迁移完整性，两者都要

「把 N 个地方改成同一种样式」这类活儿，**漏一个在界面上几乎看不出来**，所以分两层守：

**① 行为层（探针，真界面）** —— 四个模式各断言自己那个弹窗：

| 模式 | 断言 |
|---|---|
| `--app-settings` | 页脚恰好 2 个按钮、都是 `.float-pill`、**带 `.on` 的是第 2 个（保存）**、都能命中 |
| `--capabilities` | 「去登录」是 `.float-pill` + `.on` + 可命中 |
| `--close-ask` | 询问框页脚的「取消」是 `.float-pill` + 可命中 |
| `--settings`（档案设置流） | 历史弹窗页脚是 `.float-pill`（原来那条"点关闭真的关掉了"顺带证明它可命中） |

**② 完整性层（新的 vitest，纯静态扫描）** —— `utils/dialogFoot.test.ts`：
每个"有页脚"的弹窗必须出现浮片；**弹窗清单是冻结的**（`WITH_FOOT` ∪ `NO_FOOT` = 目录里所有
`*Dialog.tsx` + `CapabilityLimits.tsx`），以后新增一个弹窗必须在这里被判一次，否则用例红。
它明确**不替代**探针（只证明"代码里有浮片"，坐标与命中由探针量）。

## 四、踩到的坑（tsc 抓的）

`hits` / `rectOf` 是**每个探针模式内部各自定义的局部函数**，我把新测量插进 `--capabilities`
与 `--close-ask` 两个块时，那两个作用域里没有它们 ⇒ `tsc` 直接报 `Cannot find name`。
改成就地量（`getBoundingClientRect` + `document.elementFromPoint`）。
**教训**：探针文件里"看着像公共工具"的函数其实是各模式的私货，跨模式复制代码要先看作用域。

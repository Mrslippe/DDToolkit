# 435-20261007-左栏白底遮住工具栏 + 让位改滑动退场

用户两条（附截图）：

> 1. 如图，左工具栏是这个白色
> 2. 界面元素的隐藏和重现的动画更明显一点：隐藏时让背景遮罩渐隐、界面元素**下滑**同时渐隐；
>    重现时遮罩渐显、界面元素**上滑**出现

## 第 1 条：不是"工具栏没出来"，是它被**左栏的白底盖住**了

负外边距那套"藏"法有个几何后果：左栏（`.sidebar-shell`，宽 492、`margin-left: -492`）的盒子
实际横跨 `[-442, 50]` —— 它的**右缘正好落在 x=50**。于是：

- 全部收起时两栏都在 x<0，看不见 ✓；
- 一旦唤出工具栏（`margin-left: 0`，占 `[0,50]`），左栏那块白底就和它**重叠**，
  而左栏在 DOM 里**在后面** ⇒ 按绘制顺序**盖住工具栏** ⇒ 用户看到的"左工具栏是白色"。

⇒ 修法：`.app-shell[data-solo='1'] .icon-rail { position: relative; z-index: 2 }` ——
唤出的那一栏压在左栏上面。加了 CSS 契约（`z-index` 必须有值 + `position: relative`），
**反向验证过**（去掉 ⇒ 那条红）。

## 第 2 条：让位/回来带上位移

- 让位：界面元素 **下滑 26px + 渐隐到 0**，白纱罩**渐隐到 0**（背景图完全显现）；
- 回来：**上滑到 0 + 渐显**，纱罩**渐显**。
- 两个旋钮在 `layout.css` 的 `:root`：`--solo-hide-shift: 26px`、`--solo-hide-ms: 560ms`。
- 顺手把上一版留下的 `--solo-a-content/-veil/-delay` 三个中间变量**删掉**（直接用字面量 0/1），
  并把"恢复要瞬时"那条 `transition: none` 撤掉 —— 那条是为"元素判定的闪动"打的补丁，
  而闪动的真因（判定依据）在 `433` 已经换掉了，现在留着它只会让动画看不出来。

## 判据（净 +1：CSS 7 条）

★唤出的工具栏必须**压住左栏**（新增，反向验证过）· ★让位 = 只在 cards 视图 + **闲置**
（`data-idle`）且带**位移**（`translateY(var(--solo-hide-shift))`）· ★**不许**再把面板内容挂到
`data-peek` 上（上一版弄丢自动隐藏的就是这一条，配了正对照）· 两个旋钮存在。

## 记一条几何教训

**"用负外边距把东西藏起来"会让盒子仍然横跨原来的位置** —— 它只是移出了视口，
一旦邻居朝里挪，两者的盒子就会重叠，而**谁盖住谁由 DOM 顺序决定**，不受"谁被唤出"影响。
要么给唤出者 `z-index`（这次的做法），要么别用负外边距（改成 `width: 0` 或 `display: none`
—— 但那两样**不能动画**，正是当初选它的理由）。这是个取舍，不是单纯的对错。

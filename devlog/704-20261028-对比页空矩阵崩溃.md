# 704-20261028-控制台报错：对比页 matrix 为空时 `[i].map` 崩溃

## 现象

用户：控制台报错了（对比页）。

## 复现

后端在"可分析的主播不足 2 个"时返回：

```json
{ "vtubers": [ {…} ], "matrix": [], "pairs": [], "needs_analysis": ["不存在"] }
```

而 `ComparePanel` 无条件渲染矩阵表并执行 `data.matrix[i].map(...)`：
`matrix` 是空数组 ⇒ `data.matrix[0]` 是 `undefined` ⇒ **TypeError: Cannot read properties of undefined (reading 'map')**。

## 修法

1. 只有 `matrix.length === vtubers.length && matrix.length > 0` 才渲染矩阵表；
2. 单元格循环加护栏 `(data.matrix[i] ?? [])`；
3. 缺分析的主播仍由黄条提示（`needs_analysis`），并给出「采集并分析」。

## 回归

新增用例「只有 1 个主播可分析时不崩」：断言出现 `compare-missing`、不出现 `compare-matrix`。
前端 **1589 passed**、eslint 干净、build 成功。

# 614-20261024-详情图表改 ECharts（含横向滚动）

用户定案：换 ECharts、不加 `dataZoom`、场次多时横向滚动。

## 为什么换几乎没有成本

`echarts` 早就进了包（`FanTrendChart` 3 个实例 + `ResultCharts` 按需引入 Pie/Line/Bar）。
主包 1,223 KB 已含它 ⇒ **详情再画两张柱图，下载量 +0 KB**。
运行时是两实例约 1–2 MB 内存、20–60 ms 初始化，卸载 `dispose()` 释放。

## 实现

`SessionChart`（替换原 SVG `Spark`）：

- 容器宽度 = `max(360, 场次 × 14)px`，外层 `.wb-chart-scroll` 横向滚动 —— **不加 dataZoom**；
- tooltip 一次给四项：**时间 / 弹幕 / 付费 / 入场**；
- x 轴标签按场次数自适应抽稀（最多约 8 个）；
- `animation: false`（弹窗里不需要入场动画，省一帧开销）；
- 卸载 `dispose()`；jsdom 无 canvas 时直接跳过（测试环境不炸）。

前端 1,580 passed；`tsc` 干净；`npm run build` 成功。

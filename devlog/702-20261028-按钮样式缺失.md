# 702-20261028-导出/抓取按钮"图标压文字"的真因：`wb-btn` 从未定义

## 现象

- 名单工具条的「导出 CSV」：图标在上、文字在下，还带一圈边框；
- 对比页「开始抓取」：图标 24×24 撑开，把文字顶到角落。

## 原因

我在这两处用了 `.wb-btn` / `.wb-btn-ghost`，但**这两个类在 `workbench.css` 里根本没有规则**
（`grep -c '.wb-btn' → 0`）。于是 `<button>` 退回浏览器默认样式，
而 lucide 的 `<svg>` 是块级 24×24 —— 自然把文字压到下面。

## 修法

补一组通用按钮（与现有 `.wb-tagfilter-btn` 的尺寸语言一致）：

```css
.wb-btn { display:inline-flex; align-items:center; gap:6px; height:32px;
          padding:0 12px; border-radius:999px; ... }
.wb-btn-ghost { background:#fff; border:1px solid var(--c-border); }
.wb-btn > svg { width:14px; height:14px; flex:0 0 auto; }   /* 不写死就会被 24×24 撑开 */
```

## 顺带核对

把本轮新引入的类名逐个数了一遍规则数（`.wb-chip/.wb-seg/.wb-kpi/.wb-cov/.wb-matrix/.wb-venn/.wb-missing/.wb-check` …）
—— 只有 `wb-btn` 是 0，其余都有。构建产物也确认含 `.wb-btn`。

## 教训

**用了没定义的类名不会报错，只会静默退回浏览器默认样式。**
新组件引入新类名时，加完样式立刻 `grep -c '\.类名'` 数一下，比看截图快。

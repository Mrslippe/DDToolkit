# 706-20261028-`code=-352` 与"只抓到 3 条"的真因：评论区要登录态

## 三个坑叠在一起

| 现象 | 真因 |
|---|---|
| `code=-352`（风控校验失败） | 请求没带 `buvid3` 设备指纹 |
| 带了 buvid 后 `code=0`，但**每页只有 3 条且 `is_end=true`** | **未登录**：评论区只返回"热门预览"3 条 |
| 老接口 `/x/v2/reply` 返回 0 | 该接口已废弃（上一轮已改 `reply/main`） |

## 修法

1. **buvid 指纹**：`x/frontend/finger/spi` 取 `b_3/b_4` → `buvid3=…; buvid4=…; b_nut=…`，
   进程内缓存 12 小时；不带它直接 -352；
2. **登录态**：复用 `app/services/auth.py` 的 `auth_manager.cookie_str()`（含 `SESSDATA`），
   cookie 优先级 = 调用方传入 → 应用登录态 → 只有 buvid；
3. **未登录时给可读错误**：`"未登录 B 站：评论区接口只返回热门预览（3 条）。请在设置里登录 B 站账号后再抓取。"`
   —— 不让它看起来像"这个帖子只有 3 条评论"。

## 实测（同一视频 1453 条评论）

| 状态 | 结果 |
|---|---|
| 无 cookie | `-352` |
| 仅 buvid | `code=0`，3 条，`is_end=true` |
| **buvid + 登录态** | **20 条/页**，`is_end=false`，游标翻页正常（3 页 60 条 / 2.8s） |

38 passed（bili_replies + fan_api）。

## 一、R15① 顶栏标题粗体

`.topbar-title`：`font-weight: 400 → 700`。

**只改字重**（字距沿用原设计的 5px —— 用户没要求动字距，我一度想改成 4px，最后按"不做没被要求的重新设计"退回）。

## 二、R15② 筛选钮文字居中 —— 先量，结果和"常识"不一样

第一版判据量的是 `range.selectNodeContents(button)`，得出"左 21.5 / 右 3，偏 18.5px"。
**这个测量本身是错的**：`selectNodeContents` 把**绝对定位的 caret** 也算进 range，
右间隙量到的是"caret 到右缘的 3px"。

改成量**纯文本节点**后事实翻转：

| 量什么 | 结果 |
|---|---|
| 文字左/右间隙 | 21.5 / 21.5 —— **差 0，文字本来就居中** |
| caret 位置 | `position: absolute; right: 3px`（钉在最右角） |
| 「文字 + caret」这一组 | 左 21.5 / 右 3 → **组中心右偏 9.25px** |

所以用户看到的"没居中"是真的，但**偏的是整组**，不是文字：label 居中 + 箭头挂在最右角 =
视觉重心右移。修法（只作用于列表筛选钮）：

```css
.pfilter-btn { padding: 0 12px; }              /* 原 16px：caret 进流后内容变宽，收回内距保宽度 */
.pfilter-btn .pill-caret { position: static; } /* 覆盖 layout.css 的绝对定位；gap:4px 由 .float-pill 提供 */
```

实测结果：组左 = 组右 = **16.2px（差 0）**，文字中心偏移 −5.3px（半个箭头宽，属正常观感），
整体宽度仍被 `min-width: 68px` 兜住 ⇒ **工具行几何不变**。
⚠️ 侧栏 `VtuberSidebar` 那枚 `.pill-caret` 仍是绝对定位，覆盖刻意只写 `.pfilter-btn .pill-caret`。

## 三、R15③ 徽标「+」不 hover 时不占位（用户标为高优先级）

真因（读代码就清楚）：`.hero` 是**纵向 flex（gap 10px）**，`.pill-add`（37×37）是它的一个子元素
⇒ 未 hover 时虽然 `opacity: 0`，但**照样占着 37px + 10px 的 gap**，所以徽章离分割线 **57px**。

修法：空闲时**净占位 0**，hover 时展开回 37px（"hover 才占位"正是用户要的）：

```css
.pill-add { height: 0; margin-top: -10px;      /* 抵消列 gap ⇒ 净占位 0 */
            opacity: 0; pointer-events: none; /* 看不见就不该能点 */
            overflow: hidden; transition: height .18s, margin-top .18s, opacity .18s; }
.stat-sets:hover .pill-add,
.stat-sets[data-hover='1'] .pill-add { height: 37px; margin-top: 0; opacity: .75; pointer-events: auto; }
```

实测：空闲 高度 **0** / `opacity 0` / `pointer-events: none` / **不可命中** / **徽标→分割线 = 10px**
（原来 57px）；hover 后 37px / `opacity .75` / **可命中**；指针离开复位。

### 为什么要给 `.stat-sets` 加 `data-hover`（React state）

CSS `:hover` **在 `--dump-dom` 里无法模拟**（没有真实指针）⇒ "hover 后能看见、能点"这条
根本没法机器断言。所以 `HeroCardsView` 维护一个 `pillHover` state 并挂 `data-hover`，
样式里 `:hover` 与 `[data-hover='1']` **两条都写**（真人走前者、探针走后者），
探针派发 `pointerover/pointerout` 即可量到两个状态。

> ⚠️ 这个属性**只为可测性存在**，不是冗余：删掉它，`--polish` 的 hover 断言就会退化成空转。

# 653-20261026-图表栏撑满宽度

截图里两列卡片只占了约 60% 宽度，右侧一大片空白。

## 原因

`.wb-charts-pages` 是 `display: flex`，但**没有显式宽度** —— flex 容器按内容收缩，
于是每页 `flex: 0 0 100%` 的"100%"是相对这个收缩后的宽度算的，
`grid-template-columns: 1fr 1fr` 自然也就只有内容那么宽。

## 修法

1. 全链路显式 100%：`.wb-charts` / `.wb-charts-viewport` / `.wb-charts-pages` 都加 `width: 100%`，
   `.wb-charts-page` 加 `min-width: 0`（允许 grid 子项收缩）；
2. 顺带修另一个隐患：ECharts 可能在**窄容器**里初始化（轮播页先挂载后布局），
   之后不会自己变宽 —— 加 `ResizeObserver`，容器尺寸变化时 `resize()`。

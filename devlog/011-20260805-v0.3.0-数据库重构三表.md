# 011-20260805-v0.3.0-数据库重构为三表结构

## 概述

从单表 `vtubers` 拆分为 `vtubers` + `accounts` + `posts` 三表，支持多平台 VTuber 追踪。

## 新表结构

```
vtubers (1) ──< accounts (N) ──< posts (N)
```

### vtubers — 虚拟主播本体（平台无关）

| 列 | 类型 | 说明 |
|----|------|------|
| id, name, birthday, debut_date, setting, avatar, notes | | |
| created_at, updated_at | DATETIME | |

### accounts — 各平台账号

| 列 | 类型 | 说明 |
|----|------|------|
| vtuber_id | FK → vtubers.id | 所属 VTuber |
| platform, platform_uid, display_name, avatar_url, sign, url | | |
| followers_count, room_id, live_status, live_title, live_url | | |
| last_fetched_at | DATETIME | 上次抓取时间 |
| UNIQUE(platform, platform_uid) | | 去重 |

### posts — 动态/投稿

| 列 | 类型 | 说明 |
|----|------|------|
| account_id | FK → accounts.id | 所属账号 |
| platform_post_id, type, title, content, cover_url, url | | |
| published_at, stats_json, raw_json | | raw_json 兜底平台差异 |
| UNIQUE(account_id, platform_post_id) | | 去重 |

## 新增 API

| 端点 | 说明 |
|------|------|
| `GET /vtuber/{id}/accounts` | 查看 VTuber 的账号列表 |
| `POST /vtuber/{id}/accounts` | 为 VTuber 添加账号 |
| `PUT /account/{id}` | 更新账号 |
| `DELETE /account/{id}` | 删除账号 |
| `GET /account/{id}/posts` | 查看账号的帖子 |
| `POST /account/{id}/posts` | 添加帖子 |
| `PUT /post/{id}` | 更新帖子 |
| `DELETE /post/{id}` | 删除帖子 |

保留原有 VTuber CRUD 和 `/vtuber/fetch`。

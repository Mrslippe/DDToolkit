# 665-20261026-贡献榜饼图、互动改版、动画双播真因

## ① 切页签动画播两次 —— 真因是 ResizeObserver

不是 React 重复渲染，也不是 `run` 计数重复：

新建实例后，`ResizeObserver` 的**首次回调**立刻触发 `api.current.resize()`，
而 ECharts 在初始动画进行中收到 resize 会**重启动画** —— 观感就是"播两遍"。

修法：observer 的**首次回调跳过**，只在真正的尺寸变化时 resize。

## ② 付费页三色轴"不见了"

后端返回是好的（实测某鲸鱼 `guard_amt 19998 / sc_amt 2830 / gift_amt 0`）。
真正的问题是**老数据里 `g/gd/sc` 三项为空**时，`payMixBar` 直接返回 `—`，
整列看起来就像"功能没了"。

修法：分类金额全为 0 但 `pay_total > 0` 时，退化成**单色总额条**（带 tooltip"缺分类金额（老数据）"），
至少能看出这人花了多少；字段齐全时仍是三色轴。

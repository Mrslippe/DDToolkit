# 603-20261024-结果名单改版：头像/昵称/分位列 + 切页签不跳顶

用户提了两条：页签切换重排并跳回顶部；名单列要改成 序号/头像/昵称/强度/三分位/标签。

## 一、跳顶的根因

结果区的渲染条件是 `running || busy ? 进度块 : ranked ? 结果`。切页签会触发一次请求，
`busy=true` ⇒ **整个结果被替换成进度块** ⇒ 内容高度塌陷 ⇒ 浏览器把滚动位置弹回顶部。

修法：**只有"还没有结果"时才显示进度块**（`busy && !ranked`）；切页签/翻页时保留结果，
只给面板加 `.is-loading`（半透明）。面板加 `min-height: 560px` + 180ms 淡入，
高度不再塌陷，滚动位置自然保持。

## 二、昵称与头像

- **昵称**：弹幕记录里有 `uName`（没有头像）。采集时按用户落第一条非空 `uName` 到 `raw[uid]["n"]`，
  loader 带进 `UserFact.name`，`/ranked` 行里返回 `name`。
- **头像**：danmakus 前端用的是 `https://workers.vrp.moe/api/bilibili/avatar/<uid>?size=22`。
  实测**服务端请求返回 403**（Cloudflare），所以：
  1. 前端优先用这个 CDN（浏览器侧可能能过）；
  2. 失败退回本地代理 `/fan/avatar/<uid>`（后端打 B 站 `web-interface/card`，已验证 200，落盘缓存）；
  3. 再失败显示昵称首字。
- `/fan/avatar/` 加进公开路径：`<img src>` 带不了 `X-DDToolkit-Token`；端点只接受纯数字 uid、
  只代理 B 站头像并缓存，不转发任意 URL。

## 三、名单列

固定列：**序号 / 头像 / 昵称 / 强度（高亮）/ 出席分位 / 弹幕分位 / 付费分位 / 标签**。

- **总览页**：不显示细节列，直接看三个分位与强度；
- **出席/互动/付费页**：额外插一列该轴的**原始细节**（出席场次、弹幕条数、付费金额），
  分位是"算出来的加数"，细节是"加数背后的实数"。

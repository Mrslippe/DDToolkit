# 613-20261024-详情弹窗：限高可滚、栏目分隔、图表 hover

用户三条反馈，都是纯前端。

## 一、弹窗太长

`.wb-member-dialog` 加 `max-height: 78vh` + 内部 `overflow-y: auto`（正文滚动、头部固定），
`overscroll-behavior: contain` 防止滚到尽头后带着页面一起滚。

## 二、栏目分不清

`.wb-drawer-sec`（行为/付费/独轮车判定/逐场趋势/三轴/标签）：
- 字号 12.5px → **13px、字重 600**；
- 上方加**半透明发丝线**（`rgba(210,216,222,0.55)`）+ 14px 内边距；
- 第一栏去掉上边线，避免和头部重复。

## 三、图表 hover

两张迷你柱图（弹幕数 / 付费）每根柱子包一个 `<title>`：
hover 显示「2026-09-01 20:00 · 1,234 条 / 元」。用原生 `title` 而不是自定义 tooltip ——
不引图表库、不占内存、也天然支持键盘/读屏。

前端 1,580 passed；`tsc` 干净；`npm run build` 成功。

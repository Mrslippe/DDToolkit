# 446-20261008-v1.2.0 发布

v1.1.1（2026-10-06 16:06）之后积了 **74 个提交** —— 一次功能版：单推模式、背景取景与背景视频、
左栏自定义排序、播放器全屏卡顿定案，以及「小 V 加不上」等修复。本篇是**发布批次**的记录。

## 为什么这次必须发（不只是"攒够了"）

GitHub issue #1（`yuuka-hayase`，2026-09-24）报的「不在本地候选池的小主播无法添加」，
真因是 **B 站新 mid 是 16 位**、而两侧判据卡在 12 位（`devlog/378`）：
16 位输入被当关键词搜 ⇒ B 站搜索搜不到 uid ⇒ 界面表现为"搜得到、点添加没反应"。
库里第三方索引 9141 条里 **2206 条（24%）** 是这种长度 ⇒ 约四分之一的池外新 V 加不上。

⚠️ **那条修复的提交时间（10-06 20:39）比 v1.1.1 的 tag 晚 4 小时** ⇒ 它在 `main` 上、
**不在任何已发布版本里**。报告者用的正是 v1.1.1 ⇒ 不发行这一版，issue 关不掉也不会好。

## 本版内容（发布说明 `docs/releases/v1.2.0.md` 是全文）

- 单推模式（`devlog/429`–`445`）：分段收起 + 停手 5s 让位给背景 + 贴边唤出 + 拉手常驻；
- 背景：视频当背景、取景（拖/滚轮）、图片与视频取景互不相干且用首帧预览；
- 播放器：全屏卡顿定案到**硬件视频解码器**（关掉那一刀），键盘改由指针移入接管 + 移出 Tab 序；
- 左栏：按住 350ms 拖动重排 + 筛选浮窗排序栏；
- 修复：16 位 mid（issue #1）、切 V 闪白、通知让位时机、单推那串视觉/层级问题。

## 顺带清掉的一处仓库缺陷（发布前）

单推那批代码里有 **16 处指向 `devlog/430` / `devlog/434` 的悬空指针** —— 这两个编号
**从未存在过**（`git log --all -- devlog/430* devlog/434*` 无输出）。按内容归位：
`430` → **431**（沉浸视觉那篇）、`434` → **435**（435 里正好记着"挂在 `data-peek` 上就弄丢
自动隐藏"那条坑）；第四版那一轮**当时就没写 devlog**，注释里如实写明，不事后补造。
⇒ **教训**：devlog 编号是**跳着用的**，写交叉引用时**先确认那个文件在不在** ——
门禁只管"文件名重号"，**不管指针指向的文件是否存在**。

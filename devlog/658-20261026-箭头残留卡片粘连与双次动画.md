# 658-20261026-箭头残留、卡片粘连、翻页动画播两次

## ① 不 hover 时还有一侧箭头隐约可见

` .wb-charts-arrow:disabled { opacity: 0.3 }` 的**特异性高于**基础的 `opacity: 0`
（一个类 + 一个伪类 > 一个类），所以禁用的箭头永远半透明地停在画面上。

修法：把 `:disabled` 的透明度规则**也限定在可见态**（`.is-left/.is-right/.is-flash` 之下），
隐藏态仍然是 `opacity: 0`。

## ② 右侧卡片粘连 + 能看到下一页的一条边

每页 `flex: 0 0 100%` 且 `gap: 16px`，但页面本身没有内边距 ——
卡片阴影贴着 viewport 边缘，相邻页的卡片边缘就透了进来。

修法：`.wb-charts-page` 加 `padding-right: 12px; box-sizing: border-box`，
让每页自带右侧余量，下一页从余量之后开始。

## ③ 一次翻页动画播两遍

`run` 每次 +1 都会 `dispose()` + `init()` 一次；但同一个 `run` 可能触发**两次 effect**
（StrictMode 或连续 render），于是重建两次、动画播两遍。

修法：`EChart` 记住上一次真正渲染的 `(run, option)` 快照，
相同就**直接 return** —— 一个 `run` 只重建一次实例。

# 542-20261019-热力图浮窗偏移 + 逐场明细

用户：① 浮窗明显偏移；② 浮窗里要显示**场次名称、时长、弹幕量**等库里已有的数据。

## 一、偏移的真因：`position: fixed` 被祖先的 `transform` 劫持

浮窗原本直接放在卡片里，用 `clientX/clientY` + `position: fixed`。看起来天经地义，
但 **`transform` 会给 `position: fixed` 造一个新的包含块** —— 一旦祖先带 transform，
`fixed` 就退化成"相对那个祖先定位"，`clientX` 是相对视口的坐标，于是整体偏移。

这个页面的入场动画 `rise-in-page` 就在祖先 `transform` 上 —— 动画结束后计算值仍是
transform（`animation-fill-mode` 保留），所以**整屏都处于被劫持状态**。

修法：**用 `createPortal` 挂到 `document.body`** —— body 之上没有 transform 祖先。
`left: x + 14 / top: y + 16` 于是真的相对视口。

## 二、逐场明细（后端）

`/activity` 新增 `detail`：`{日期: [{title, at, dur, m}]}`，取**代表行**的
`title / start_at / end_at / danmakus_count`。实测 936 天、942 场。

- `dur` = `end_at - start_at` 的分钟数；**`end_at` 缺失就是 `null`，不猜**。
- `2026-10-02 → [{"title": "国庆快乐~看欧布0.0", "dur": null, "m": 28438}]`
  —— 这场正好没有 `end_at`，所以时长显示为省略（不编一个数字出来）。

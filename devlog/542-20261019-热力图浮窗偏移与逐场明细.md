# 542-20261019-热力图浮窗偏移 + 逐场明细

用户：① 浮窗明显偏移；② 浮窗要显示**场次名称、时长、弹幕量**等库里已有的数据。

## 一、偏移真因：`transform` 劫持了 `position: fixed`

浮窗用 `clientX/clientY` + `position: fixed` 看着天经地义，但 **`transform` 会给 fixed
造新的包含块**。本页入场动画 `rise-in-page` 在祖先上留有 transform ⇒ fixed 退化成
"相对那个祖先定位"，而 `clientX` 是相对视口的 ⇒ 整体偏移。

修法：`createPortal` 挂到 `document.body`（body 之上没有 transform 祖先）。

## 二、时长显示不出来 —— 我自己的 `except` 吞掉的

用户拿日历卡片对出来：10-02 明明 5 小时 15 分，浮窗却是空。

我先怀疑"代表行 `end_at` 为空"——**错了**：942 条代表行**没有一条** `end_at` 是空。
真因是这一行：

```python
dur = max(0, int((end_at - start_at).total_seconds() // 60))
```

原生 SQL 返回的是**字符串**，两串相减抛 `TypeError`，被 `except (TypeError, ValueError)`
**静默吞成 `None`** ⇒ "有数据"变成"没有时长"。

> 教训：兜底可以，但**不能把"解析失败"和"业务上没有"混成同一个 `None`** ——
> 那会让数据缺失看起来像事实缺失。

## 三、顺带修时区

库里存 UTC（10:59），日历显示本地（18:59）。原来直接透传 UTC 字符串 ⇒ 浮窗会显示 10:59。
现在 `_as_utc()` 按 UTC 解析后 `.astimezone()`，与日历一致。

实测 detail：

```json
[{"title":"国庆快乐~看欧布0.0","at":"2026-10-02 18:59","end":"00:14","dur":315,
  "m":28438,"income":5307.9,"peak":2153,"area":"虚拟主播 / 虚拟日常"}]
```

与用户的日历卡片逐项对上（18:59–00:14 / 5 小时 15 分 / ¥5,307.9 / 峰值 2,153 / 弹幕 28,438）。

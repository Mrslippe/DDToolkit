# 677-20261027-图例昵称"截断"的真因：后端 `[:8]`

上一版我以为是 CSS 宽度导致省略号，改成换行后**依旧被截** —— 说明截断不在前端。

## 真因

`/ranked` 的贡献榜标签是这么拼的：

```python
labels = [f"{(users[u].name or u)[:8]}" for u, _ in head]
```

**后端把昵称硬截到 8 个字符**。`AoineKo青貓` 恰好 9 个字符，于是变成 `AoineKo青` ——
看起来就像"前端把最后一个字裁了"。

而 `好想rua土豆啊` 只有 7 个字符，不受影响 —— 这也解释了"为什么更长的没被截"。

## 修法

后端不再截断，**截断/换行交给前端 CSS**（图例已支持换行 + 滚动）。
验证：`AoineKo青貓`（9 字）与 `折折子zz`（5 字）都完整返回，最长 10 字。

## 教训

这类"看起来像样式问题"的现象，**先确认数据本身有没有被改过** ——
查一次接口返回的字符串长度，比调 CSS 快得多。

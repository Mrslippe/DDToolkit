# 621-20261024-筛选一致性、固定列宽、行进入动画

用户三条：刷新时整块重排闪动；标签筛选结果多出/漏掉；小众标签筛选后右侧列被挤压。

## 一、筛选结果不对（真 bug）

`loadRanked` 只有在**显式传参**时才带 `tags`，而几处调用没传：

| 调用点 | 后果 |
|---|---|
| `onLoadMore`（懒加载） | 追加的一页**没有筛选** → 多出条目 |
| `onTab`（切页签） | 筛选丢失 → 看起来"漏掉" |
| 分析按钮 | 同上 |

修法：`tagFilterRef` 保存实时筛选，`loadRanked` 的 `tags` 参数默认取 ref，
所有调用点天然带上；筛选变化时先更新 ref 再拉数据。

验证：星瞳「全勤」分页拉完 → **2 人**（`list_total=2`），**无重复、无未命中**。

## 二、刷新闪动

- 不再先 `setRows([])` 清空再填（那会让表格先塌成空再长回来）；
- 只有 **`<tr>` 做依次淡入**（`wb-row-in`，延迟按行号 18ms 递增，最多 12 行），
  容器与两张图表完全不参与动画；
- 尊重 `prefers-reduced-motion`。

## 三、列宽被挤

`table-layout: fixed` + `<colgroup>` 显式列宽（#44 / 头像52 / 昵称210 / 强度84 /
三分位各92 / 细节150 / 标签吃剩余），标签多少不再影响其他列位置；单元格统一
`ellipsis`，标签列例外（要放下「+N」）。

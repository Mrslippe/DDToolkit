# 660-20261026-裁剪框外扩：卡片左右对齐 + 阴影不被裁

用户要求两件事同时成立：图表卡的左右边缘与下方名单卡对齐，且四边阴影都不被裁。

## 几何设计

```
裁剪框（margin: -16px -24px; padding: 16px 0; overflow: hidden）
  └ 页（padding: 0 24px，宽 = 裁剪框内容宽）
      └ 卡片（边框正好落在面板左右边缘）
```

| 元素 | 位置 |
|---|---|
| 裁剪框边框盒 | 面板左右各外扩 **24px**、上下各 **16px** |
| 裁剪框内容盒 | 同样外扩（padding 横向为 0） |
| 卡片左边框 | 面板左边缘 —— 与名单卡对齐 |
| 卡片阴影 | 落在裁剪框那 24px 带子里 —— 不被裁 |
| 下一页 | 从裁剪框右缘**正开始** —— 被一刀切掉，不露边 |

## 与上一版失败的区别

上一版把 padding 放在**裁剪框**上、再用负 margin 抵消 → 边框盒外扩、但**内容盒反而变窄**，
下一页从面板内部开始 ⇒ 露边。

这一版 padding 放在**页**里，裁剪框 padding 横向为 0 ⇒ 内容盒与边框盒一起外扩，两端都成立。

## 约束（写进这里的意义：以后改之前先看）

- 外扩量（24px）必须 **≥ 卡片横向阴影溢出**（当前 `0 8px 24px` 一档约 16–20px）；
- 上下 16px 同理，阴影更强时要一起调；
- 裁剪框两侧的 24px 带子露出的是**页面背景**（`--c-bg-page`），与卡片区同色，视觉无差；
  若以后给卡片区加底色，这里要重新看。

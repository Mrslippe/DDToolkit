# 639-20261025-分页清单各自成表、出席分布改画场次数

用户四条的前端改动。

## ① 出席分布为什么那么平

横轴是**分位**（排名）。排名天生均匀分布 —— 每根柱子必然差不多高。
这不是数据问题，是"用排名画直方图"本身没有信息量。

**改法**：改为「**出席场次数**分布」—— 横轴 = 来了几场，纵轴 = 人数。
后端 `/ranked` 新增 `att_bins: {max, counts}`（下标 = 出席场次，值 = 人数，分母是池）。

## ② 跳过场次：时间 + 标题，超量折叠

后端新增 `skipped: [{live_id, start_at, title}]`：时间取 `stats.start_at` 转东八区，
标题查库里的 `live_sessions`。前端只显示前 2 条，其余收进 `<details>`。

## ③ 名单按页签分列

| 页签 | 列 |
|---|---|
| 总览 | 序号 / 头像 / 昵称 / 强度 / 三分位 / 标签（不变） |
| 出席 | 序号 / 头像 / 昵称 / 强度 / **出席分位** / 出席率 / 平均时滞 / **出席明细图** |
| 互动 | 序号 / 头像 / 昵称 / 强度 / **互动分位** / 去重/总弹幕 / 场均弹幕 / 独轮车 |
| 付费 | 序号 / 头像 / 昵称 / 强度 / **付费分位** / 总付费 / 贡献占比 / 构成（舰/SC/礼） |

当前页签的关键分位列加了 `wb-th-key` 高亮。

## ④ 出席明细图

`AttendanceBits`：一排小方块（绿=出席、灰=缺席），**场次多时向下换行**，不横向滚动；
hover 弹自定义浮层，逐条列「时间 + 标题 + 出席与否」，浮层自身纵向滚动，鼠标离开即关。

`gift_amt / guard_amt / sc_amt`、`spam_level`。

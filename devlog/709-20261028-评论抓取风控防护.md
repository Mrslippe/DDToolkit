# 709-20261028-评论抓取的风控防护：单飞、限速、复用、冷却

## 为什么加

「同一帖反复抓 + 深分页 + 高频」是 B 站评论区最典型的风控特征：
重复的深分页序列很容易触发 `-352/-412`，而且可能连带影响同 IP 的其他请求（包括正在跑的采集）。

## 四道闸

| 闸 | 实现 | 参数 |
|---|---|---|
| **全局单飞 + 限速** | `_throttle()`：跨任务共享时间戳，保证相邻请求 ≥ `GLOBAL_GAP_S` | **1.2 s**（≈0.83 req/s） |
| **同帖复用** | `_compare/scans/index.json` 记 `kind:oid` 与 `input:原文` 两份；30 分钟内直接返回快照，**不打网络** | **30 min** |
| **风控冷却** | 收到 `-352/-412` → `RiskControl` 中止本轮，置全局冷却；期间新请求返回 **429** 并带剩余分钟数 | **15 min** |
| **深度三档** | 前端下拉：快速 3 页（60 条）/ 标准 150 页（3000 条）/ 深度 500 页（1 万条） | 默认标准 |

## 交互

- 复用时接口返回 `{"scan_id": …, "state": "done", "reused": true}`，前端照样走"取名单 + 重叠"；
- 冷却期内点「开始抓取」→ 直接弹「上游风控冷却中，请 N 分钟后再试」，**不硬碰**。

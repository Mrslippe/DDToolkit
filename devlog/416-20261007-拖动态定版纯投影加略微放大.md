# 416-20261007 拖动态定版：纯投影 + 略微放大 + 双向缓动

用户看完对比页（`E:\test\ddtoolkit-drag-demo.html`，五种候选并排、能真按住拖）之后定的口径：
**「就纯投影加略微放大一点，然后松手的时候恢复原大小，并且放大和缩小都有缓动动画」**。

## 落成什么

```css
/* 基础规则：⚠️ transform/box-shadow 的过渡**必须在这里**（见下） */
.vtuber-item { transition: background-color .12s ease,
                           transform .18s var(--ease-standard),
                           box-shadow .18s var(--ease-standard); }

.vtuber-item.dragging {
  transform: scale(1.03);
  transform-origin: left center;          /* 不是 center —— 见下 */
  box-shadow: 0 6px 16px rgba(15,23,42,.16);
  z-index: 1;                             /* 不抬层投影会被发丝线压住 */
  cursor: grabbing;
  transition: transform .18s var(--ease-pop), box-shadow .18s var(--ease-pop);
}
```

**去掉了第一版的 `opacity: .55` + `background: var(--sel-bg)`** —— 整行变淡是"禁用"的语言，
还会把头像和名字一起弄淡（左栏最吃的就是"一眼认头像"）。现在拖动那条**没有底色**，
纯靠投影 + 放大表达"拿起来了"。

## 三个技术点（都写进了 CSS 注释与判据）

1. **拿起与松手用**不同的**缓动**，靠的是 CSS 那条规则：**过渡取自"变化后"的计算样式**。
   ⇒ 加 `.dragging` 时用 `.dragging` 里那条（`--ease-pop`，本仓**唯一允许过冲**的曲线，
   令牌注释原话就是"只给'拿起'那一次 scale"）；摘 `.dragging` 时用基础规则里那条
   （`--ease-standard`，不回弹过冲）。**正好对上"放大和缩小都有缓动、但手感不同"。**
2. ⚠️ **`transition` 必须同时挂在基础规则上**。只写在 `.dragging` 里的话，松手那一拍
   class 已经摘掉 ⇒ 元素身上没有 transition ⇒ **回弹当场跳回去**（"放大有动画、缩小没有"）。
   这是**纯静态看不出来**的错，所以单独一条判据盯着。
3. **`transform-origin: left center`**：整行是**满宽**的，从中心放大会把**左缘那条 3px 选中竖条**
   推出容器被裁掉；从左边放大只往右长，而右边全是空白内边距 ⇒ 看不出来。
   `z-index: 1` 也是必需的：不抬层，投影会被相邻行的发丝分隔线压住，看着像没浮起来。

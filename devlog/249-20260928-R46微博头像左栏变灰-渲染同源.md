# 249-20260928-R46 微博头像在左栏变灰：同源有两条，漂的是渲染

用户 2026-09-28 报：card 视图的档案设置里选了**微博头像** ⇒ **右栏 hero 变了，左栏头像变成
灰底首字**。读代码当场定死机制（不是消息中心、不是缓存口径）：两处**渲染路不同**。

## 一、根因：devlog/135 只修了一半

2026-09-13（devlog/135，R33）修的是「**取哪张**头像」——左栏自己拼了一条
`bili.avatar_path ?? bili.avatar_url`，于是"设置里换过头像，卡片变了、左栏没变"。
那次抽出了 `utils/avatarSource.ts::resolveAvatar`，左右栏取值**同源**了。

**但"怎么渲染"没抽**：右栏 hero 在 R1（2026-09-13）换成了 `common/ProxyImage`
（直连 → `/img-proxy` → 占位三态链），左栏还留着 radix `Avatar` 的裸 `<img>` + `no-referrer`。
于是**同一个微博头像 URL**：

| | 渲染路 | 结果 |
|---|---|---|
| 右栏 hero | `ProxyImage`：`sinaimg` 命中"防盗链主机 ⇒ 首帧走代理" | 经 `/img-proxy`（带 `weibo.com` Referer）拿到图 ✓ |
| 左栏 | 裸 `<img>` 直连微博 CDN | 403 ⇒ `onError` ⇒ `AvatarFallback` 灰底首字 ✓ |

⚠️ **这个 bug 用 `data-src` 永远量不出来**：出事时左右栏的 `data-src`（解析出来的源 URL）
**一模一样**，`ui_probe --profile-sync` 那一组也在比它 ⇒ 一路绿灯。
差别只在"拿这个 URL 怎么渲染"，而虚拟时间下 radix 根本不挂 `<img>`（§DEV-LOOP 二·五 ③）。

## 二、修法：让"渲染器"也只剩一个

1. 抽取 `frontend/src/utils/imageHost.ts`：`needsProxyFromStart` / `initialImageSrc` /
   `proxiedImageSrc` —— "哪些主机必须走代理"这条规则的**唯一落点**；
2. `ProxyImage` 用它（组件里不再列主机名），并在输出节点上挂 **`data-render-src`** =
   **首帧决定用的那个 src**（与加载成败无关 ⇒ 回落到占位也读得到）；
3. **左栏改用 `ProxyImage`**（+ `.vtuber-avatar(.vtuber-avatar-fallback)`，照抄 hero 那套
   类名策略），`components/ui/avatar.tsx` 随之删除 —— "第二个渲染器"这个入口直接消失；
4. `data-src`（口径）移到 `.vtuber-item` 行上，与 `.hero[data-avatar-src]` 同一位置语义。

## 三、判据与反向验证

| 层 | 判据 |
|---|---|
| 口径 | `utils/imageHost.test.ts` 11 条（两个域名 / http 也认 / B 站不代理 / 空值不拼空代理 / `initialImageSrc` 先归一化再判主机） |
| 结构 | `utils/avatarRender.test.ts` 5 条：左右栏都必须 `<ProxyImage` · 全站不许有 `<AvatarImage` · **`imgProxyUrl(` 只许出现在 `imageHost.ts`** · `ProxyImage` 里不许再列主机名（注释行跳过 —— 本仓第 5 次踩"判据的说明文字命中判据自己"） |
| 接线 | 探针 `--profile-sync`：种子头像改成**微博图床占位地址**（原先种本地 `static/` URL，理由是"radix 要加载成功才挂 img" —— R46 之后这条理由失效，而**必须**用微博主机，否则这个 bug 永远量不到），断言左右栏 `data-render-src` **相等且落在 `/img-proxy` 上** |

**反向验证 5/5 全红**：① `imageHost` 去掉 `wbcdn.cn`；② `initialImageSrc` 对微博返回直连；
③ 左栏改回 `AvatarImage`；④ `ProxyImage` 里再写一遍主机名；⑤ 探针种子换回本地 URL
（`data-render-src` 两边都不是代理 ⇒ 第 3 条断言红）。

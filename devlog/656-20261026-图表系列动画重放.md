# 656-20261026-图表动画：要的是 ECharts 系列动画重放，不是 CSS 淡入

我上一版理解错了 —— 用户要的是**柱状图生长、饼图旋转填充**这种数据动画。

## 为什么之前没有

1. 图表在轮播页里**先挂载**（那一页可能不可见），动画在不可见时播完，翻到该页时已经静止；
2. `setOption(option, true)` 只在 option 变化时调用；翻页不改 option ⇒ 不会重播。

## 修法

`EChart` 增加 `run` 参数：`run` 变化时 **先 `clear()` 再 `setOption()`**，
ECharts 会把整段动画从头重放（柱子从 0 生长、饼图重新旋转填充）。

`run` 的触发点：

- **切页签**（`useEffect([tab])` 里 +1）；
- **翻页**（左右箭头点击时 +1）。

并把动画参数显式写进每个 option：

```ts
const ANIM = { animation: true, animationDuration: 700, animationEasing: 'cubicOut' }
```

避免以后有人在全局关掉动画时，这三个图表静默失效。

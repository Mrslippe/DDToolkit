# 617-20261024-标签体系重构：13 条 → 10 条，阈值统一池内分位

用户指定名称与对应的群体。

## 新标签（10 条）

| 标签 | 条件 |
|---|---|
| 舰长 | 持有舰长（不含提督/总督） |
| 提督 | 持有提督 |
| 总督 | 持有总督 |
| 黑听民 | 出席 ≥10 场，且场均弹幕在本池最低 5% |
| 互动民 | 场均弹幕在本池前 1% |
| 老头 | 累计付费在本池前 1% |
| sc民 | 在 ≥10 个不同场次打过 SC |
| 全勤 | 窗口内每场都出席 |
| 新人 | 首次出现落在窗口最后 25% |
| 独轮车 | 被独轮车判定命中（从 `spam` 并入标签） |

## 删掉的

常驻、几乎不言、纯黑听、话痨、每场SC、大额SC、千元户、提督+（拆成提督/总督）。

## 阈值改法

- 付费/弹幕类一律**池内分位**（p99 / p05），不再用绝对金额 —— 跨 V 可比；
- 身份类按 `guard_top` 精确匹配（舰长/提督/总督），互斥；
- 独轮车不再靠"标签外挂"，而是统一进 `tag_all`（`tags_for(..., spam=win.spam.get(uid))`）。

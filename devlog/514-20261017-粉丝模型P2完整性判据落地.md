## ★ 判据分两类，处置必须不同

```
C1 内部恒等式   → 不过 = DROPPED（唯一弃用理由）
C2~C4 外部一致  → 不过 = 只降级 / unverified，绝不弃用
```

这条**在代码里是不同分支**，不是靠注释提醒 —— 第一次事故就是把 C3 当成了弃用理由，
20 场完全可用的数据被判为"偏离"。

## 一、先出规格，再动代码

口径里"先设计方案，具体决策给我过目"是硬要求 —— 视觉与手感是"看着好不好"的事，
没有规格就只能靠来回改。所以先写了 **`docs/design-archive-cards.md`**（与 R38 的
`design-status-island.md` 同一种文档）：视觉令牌 / 五槽位卡片语法 / 三张卡的重排 /
动效时间轴 / 反模式 / **可断言的不变量** / 落地批次。**五个决策全部过用户拍板**：

| 决策 | 结果 |
|---|---|
| 卡片圆角 | **12px**（与弹窗族同档 ⇒ 全站只有"面板 4px / 卡片与弹窗 12px"两档） |
| 过冲强度 | **轻微**：只有长按拿起那一次 ≤5.5%，落位无回弹（借手机小组件的**编排**，不借它的**弹跳**） |
| 长按入口 | **长按 350ms = 拿起该卡并进入编辑态**，同时保留「编辑布局」按钮（与 Hero 平台药丸的长按重排同值：全站只教用户一个数字） |
| 批次顺序 | **P4a → P4b → P4c → P3b** |
| 动效实现路线 | 用户要求"先详细介绍一下再判断" ⇒ 规格 §9 补了**逐环节顺滑度对比**，随后拍板 **A：FLIP + 跟手偏移** |

§9 那条对比值得记一笔，因为它反直觉：**B（绝对定位画布）的"白送动画"是更贵的那一种** ——
`transition: left/top` 动的是布局属性，退避的 220ms 里每帧都要重新布局、交不到合成器；
A 的退避动的是 `transform`，反而更顺。A 唯一的真风险是"闪一帧"（补偿 transform 的时机若落在
绘制之后），而它有一个确定的解法：写在 `useLayoutEffect` 里，并用探针把"跨格那一帧卡片没有位移"钉死。

## 三、四个"错了也看着像设计选择"的地方（所以都要机器判）

1. **发丝边必须去掉**：低透明度描边配柔和阴影会显脏 —— 浮起卡只用**阴影**定边界
   （与 `.post-card` 同语言）。探针断言 `border-top-width === 0`。
2. **贴纸角标只放图标**：白图标在深档粉底上是 **2.4:1**，不达标；但它属装饰（旁边必有文字标题，
   沿用 UI-MAP 的 logo 类豁免口径），而**一旦带词就得过 4.5:1** ⇒ 干脆不做"带词的角标"，
   短词一律进卡内的 `.tone-chip`（浅底 + 深档字，实测 ≥4.5:1）。探针断言：22px 见方、有图标、
   `box-shadow` 里有 `255, 255, 255`（白环）、底色不是透明、**中心落在卡片右上象限**。
3. **骨架尺寸必须跟着内容改**（R36 口径的延长线）：封面从 46×30 变 56×36，骨架不跟着变就是
   "数据到达让卡片变高"；大事记骨架还补了**落点占位**（否则数据到达后整行右移 16px，看着就是"跳了一下"）。
4. **纪念日没有数字就不许有数字位**：hero 只在真有记录时渲染。摆一个空数字位会让人以为
   "有数据但没显示出来" —— 静默失败的另一种长相。探针双向判：两行都是「未记录」⇒ **必须没有** hero；
   否则**必须有**，且值要么是「今天」要么是数字。

## 四、护栏（反向验证 42 红 → 绿 0）

- **反向验证**：先把探针断言写进去再改样式，实跑 **42 处红**（三档宽度 × 三张卡 × 圆角/阴影/发丝边/角标/生动件），
  改完归零。红的样子正是它该有的样子：`卡片 anniversary 圆角 4px 不在 8–16 之间（0 = 还是旧的方形表面层）`。
- **单测 +13**：注册表 **4 → 7**（色调清单 / 缺图标 / 契约透传）· 纪念日 **14 → 20**
  （hero 取最近的 / 就是今天 / 无记录必须 null / 事实行不重复天数）· 大事记 **10 → 14**（chip 三态 + 边界）。
- **探针三档全绿**：`画布：3 张卡 · 容器 498/678/838px · 12 列 · 高度与模型一致、无重叠无越界、材质与贴纸角标到位`。
- **一个必须种的现场**：开发库里 V 的 `birthday / debut_date` **实测全是空**，不种的话"有记录时必须有 hero"
  那半条断言永远空转（空转的断言比没有断言更坏）。`ui_probe.py` 新增 `_seed_anniversary()`：
  往**数据目录副本**里写生日 `3月14日`（不给年份 ⇒ 验每年循环）与出道 `2023-09-17`（给年份 ⇒ 验第 N 周年）。
- **视觉存档**：新增 `--shot-board`（先走「重置默认」，再各截一张阅读态/编辑态）——
  动效与观感的评审得看图，不能只靠断言；截图落在 `_ui_probe_tmp/board-{read,edit}-1440.png`。

## 五、口径记录

- **"生动"来自层次，不来自色块面积**：卡面主体永远是白卡 + 中性文字，tone 只许出现在
  ≤22px 的角标与 ≤11px 的 chip 上。这条写进了规格 §3 与 `tokens.css` 注释 ——
  否则下一个加卡片的人很容易把整张卡铺成彩色（参考图里的彩色是**图标块**撑的，不是整卡铺色）。
- **12px 而不是数据视图的 4px**：数据视图那两张是 870 宽的"大面板"，4px 是面板语汇；
  档案卡是 280×276 量级的**小方块**，同样的 4px 会显得尖硬。规格 §2 记了理由，
  UI-MAP 的圆角/阴影豁免族从**三族改四族**（其余一律回方形总纲）。
- **不动数据视图**：本批只做档案视图（用户选的），两视图将来要不要统一记在规格 §11 的待定表里。
- **编辑态取消 hover 上浮**：那时位移语义归"拿起"所有（P4b），两套一起上会打架。

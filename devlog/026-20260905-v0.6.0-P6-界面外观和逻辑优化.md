# 026-20260905-v0.6.0-P6-界面外观和逻辑优化

## 概述

P6 三条全部落地：chips 切换滚动位置（真回顶）、详情抽屉 → 居中独立窗口、
二级窗口全面对设计 token 重绘（UI-MAP「二期待办」清零）。

## P6-1：筛选切换滚动位置

**根因**：筛选变化 → `setPage(1)` 整表替换，但滚动容器不重置 `scrollTop`——
内容高度变化后浏览器 clamp 把位置拽走，深内容处切类型表现为「直接到底/断层」。
此前 dcf05e9「按筛选指纹缓存+恢复」9285689 实测不达预期已 revert
（恢复位置对不上新内容）。

**定案（标准列表 UX）**：筛选切换 = 用户意图重置 → **立即滚回顶部**。
- 单一 effect 监听 `typeFilter/searchKw/dateFrom/dateTo/deletedOnly`
  （list 视图）→ `listScrollRef.scrollTo({ top: 0 })`；
- 触发即滚（不等重取完成）；追加加载（page>1 哨兵续载）不受影响；
- 不引入任何新的滚动位置记忆状态。

## P6-2：详情抽屉 → 居中独立窗口

- `PostDetailDrawer`：`Sheet(side=right)` → `Dialog`（居中，`sm:max-w-[720px]`，
  `max-h-[90vh]` 内容区滚动）；`lastPostRef` 末帧保留逻辑沿用；
- 动效**保留原规格无缝迁移**（UI-MAP「抽屉动效」专段）：进场 260ms
  淡入+**scale(0.97)**（替原右移 48px）、退场 200ms、遮罩同拍、
  radix animationend 卸载机制不动、reduced-motion 0.01ms；
  选择器 `[data-slot=sheet-content/overlay]` → `[data-slot=dialog-content/overlay]`。

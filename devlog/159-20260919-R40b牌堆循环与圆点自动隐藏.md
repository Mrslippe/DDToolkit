## 一、滚动成环

`clampIdx` → `wrapIdx`（取模）：末张向下回首张、首张向上回末张 ✓ 键盘同理（↓/PageUp/↑ 在首尾也循环）。
**到边回弹那套删掉了**（成环之后没有"边"）—— 顺带删掉 `bounce` 状态、两个 keyframes 与 reduced-motion 里那条。

⚠️ **一个只有两张卡时才会出现的几何问题**：环上 `next` 与 `prev` 会**撞成同一张** ✗
（index 0 的下一张与上一张都是 1）⇒ 那张卡没法同时停在"背后"和"下方" ✗。
解法：给它一个 **`both`** 位次（`translateY(16%) scale(0.97)` —— 偏后偏下的中间位），
两个方向都能从那里起步 ✓；**三张卡起 `next`/`prev` 各就各位**，方向语义才是完全体。

## 二、圆点：50% + 静止自动隐藏

- 静止：`opacity: 0` + **`pointer-events: none`**（⚠️ 隐藏时必须连指针一起关掉 —— 否则"看不见却点得着"，
  是最难查的一类 bug；探针专门判这条）；
- 亮起：`opacity: 0.5`（用户指定 50%）+ `pointer-events: auto`；
- 触发：滚轮 / 键盘 / 点圆点 ⇒ `flashDots()` 亮 **1.4s**；鼠标在牌堆上悬停期间**常显**（离开才收）。

## 三、修掉那条既有红（R36）

先加尺子：探针的 `sampleDialog()` 现在会逐段报高度（`.lc-dlg-sec`）+ 每个骨架盒子的高度 ✓
一跑就定位到 **第二段**（弹幕/词云那段）：**未到位 319 → 到位 310**，差 **−9px** ✓

根因：`.lc-skel--cloud` 写的是 `height: 210px; **margin-top: 10px**` —— 而真实词云**没有**那 10px
外边距（间距由 `.lc-dlg-body .os-scroll` 的 `gap: 12px` 管）⇒ 骨架段凭空高 10px，
再扣掉 1px 的容器差 ⇒ 净 +9px ✗ 数据一到窗口长度就变，正是 R36 要防的那件事。

修法：去掉那 10px、高度按实测补 1px（`211px`）⇒ `[ok] R36 弹窗高度零变化` ✓
（这条红在 R40 之前就存在 —— 我用 `git stash` 撤掉本批改动验证过，不是这次引入的。）

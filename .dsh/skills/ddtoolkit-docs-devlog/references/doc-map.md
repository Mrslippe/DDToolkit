## 二、归档与资产子目录（只加不改）

| 路径 | 规矩 |
|---|---|
| `docs/releases/` | 每次发版新增一份 `v<版本>.md`（Release notes 来源，`upload_release_assets.py` 直接读）；**新增后回填 `docs/README.md` 的 `releases/` 那一行**（`doc_check.py` 查这条） |

| `docs/reference/` | 外部接口/数据存档，**只读、勿手改** |
| `docs/tools/` `docs/diagrams/` | 文档生成脚本与它生成的架构图，改完重跑刷新 |
| `docs/design/` | 设计资产（LOGO 源、Pixso 导出稿、`screenshots/`）+ **带日期的专题调研**；体积大、按需查 |
